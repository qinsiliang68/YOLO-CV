# fig_hn_cross_capacity_slope_panel

1. This asset answers: Whether the HN direction from hn00 to hn02 is reproducible across the main and second models.
2. Source files:
   - research/results/stage1_formal/gate_hn_overview/table_hn_cross_capacity_compare.csv
   - research/results/stage1_formal/gate_hn_m_sweep/hn_sweep_summary.csv
   - research/results/stage1_formal/gate_hn_x_crosscheck/hn_sweep_summary.csv
3. Ranking/selection rule: The comparison uses the existing cross-capacity summary without any new inference run.
4. Key finding: The panel supports a directional cross-capacity validation rather than a claim of x-side full-sweep optimality.
5. Limitation: Only hn00 and hn02 are available for yolo11x in the current working set.
