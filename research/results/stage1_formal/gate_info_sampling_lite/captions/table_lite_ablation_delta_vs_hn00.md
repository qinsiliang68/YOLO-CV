# table_lite_ablation_delta_vs_hn00

1. This asset answers: How much each setting moves the formal gate metrics relative to the no-HN anchor.
2. Source files:
   - research/results/stage1_formal/gate_info_sampling_lite/derived/ablation_delta_vs_hn00.csv
3. Ranking/selection rule: All deltas are absolute differences against A0/hn00.
4. Key finding: The table isolates the gain attributable to uniform HN or weighted replay rather than backbone changes.
5. Limitation: Deltas do not encode statistical significance and should be interpreted as formal point estimates.
