# Stage-1 Formal Materials

This directory is reserved for **formal thesis-facing stage-1 materials**.

Only the following lines belong here:

- formal binary gate capacity scan
- formal six-class source capacity scan
- formal manifests required to reproduce checkpoint-level external evaluation

Subdirectories:

- `manifests/`: shared formal manifests and split definitions
- `gate_capacity/`: per-model binary gate formal evaluation materials
- `cls6_capacity/`: per-model six-class formal evaluation materials

Do not place exploratory RCIS, PTSG, HN, or ad-hoc pilot results here.
