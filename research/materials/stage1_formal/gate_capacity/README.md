# Formal Binary Gate Capacity Materials

One subdirectory per formal binary gate model should be written here, for example:

- `yolo11n_gate2_formal/`
- `yolo11s_gate2_formal/`
- `yolo11m_gate2_formal/`
- `yolo11l_gate2_formal/`
- `yolo11x_gate2_formal/`

Each per-model directory must eventually contain:

- `epoch_gate_summary.csv`
- `epoch_gate_summary.json`
- `epoch_gate_summary.md`
- `best_epoch_manifest.json`
- `all_checkpoints_index.csv`
