# Formal Six-Class Capacity Materials

One subdirectory per formal six-class source model should be written here, for example:

- `yolo11n_cls6_formal/`
- `yolo11s_cls6_formal/`
- `yolo11m_cls6_formal/`
- `yolo11l_cls6_formal/`
- `yolo11x_cls6_formal/`

Each per-model directory must eventually contain:

- `epoch_cls6_summary.csv`
- `epoch_cls6_summary.json`
- `epoch_cls6_summary.md`
- `best_epoch_manifest.json`
- `all_checkpoints_index.csv`
