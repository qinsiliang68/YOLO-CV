# Layer-1 单信号排序力分桶实验方案

## 一、实验目标

回答一个问题：**R、C、D 三个信号各自能不能独立把高价值困难样本排到前面？**

不涉及信号组合、不涉及加权公式。纯粹验证每台"检测仪"自身有没有排序能力。

## 三、信号定义

### 3.1 R：边界裕度（Boundary Margin）

教师模型：hn00 baseline（epoch 78），已校准温度 T=1.856125。

对候选样本 i，教师校准后异常概率为 p_i，部署阈值取 tau_r995 和 tau_r990。

```
R_i = max(
    exp(-|p_i - tau_r995| / s_R),
    exp(-|p_i - tau_r990| / s_R)
)
```

其中 s_R 为带宽超参，初始设为 tau_r995 与 tau_r990 的间距（|0.28 - 0.31| = 0.03）。

含义：越靠近任一部署阈值，R 越高。

> 注：R 信号基于 hn00 教师打分。候选池本身也来自 hn00 教师。这是故意的——Layer-1 测的是信号排序力，不是教师质量。教师质量是后续实验的变量。

### 3.2 C：TTA 一致性（Test-Time Augmentation Consistency）

对候选样本 i，施加 K=5 次语义保持的轻量增强：

| 增强编号 | 类型 |
|----------|------|
| t=0 | 原图（不增强） |
| t=1 | 亮度降低 |
| t=2 | 亮度提高 |
| t=3 | 对比度降低 |
| t=4 | 轻微模糊 |

收集 K 次推理的 logit 输出 z_i^(t)，计算：

```
v_i = Var(z_i^(0), z_i^(1), ..., z_i^(K-1))      # logit 方差
q_i = (1/K) * sum(1[side(p_i^(t), tau*) == side(p_i^(0), tau*)])  # 侧别一致性
C_i = q_i * exp(-v_i / s_C)
```

含义：扰动后预测越稳定、越不跨越阈值，C 越高。

### 3.3 D：邻域密度（Feature Space Density）

提取教师模型倒数第二层特征向量 e_i（L2 归一化后），对候选池内所有样本计算：

```
d_i = (1/k) * sum_{j in kNN(i)} cos(e_i, e_j)     # k=15
D_i = robust_zscore_then_minmax(d_i)               # 归一化到 [0, 1]
```

含义：在特征空间中有越多相似邻居，D 越高，越可能代表系统性困难模式。

## 四、分桶规则

### 4.1 分桶方法

对每个信号 S ∈ {R, C, D}：

1. 计算 250 个候选样本的 S_i 值
2. 按 S_i 从高到低排序
3. 等分为 5 个桶（每桶 50 个样本）：

| 桶 | 样本范围 | 含义 |
|----|----------|------|
| Q1 | 排名 1-50（S 最高 20%） | 该信号认为"最值钱"的 |
| Q2 | 排名 51-100 | |
| Q3 | 排名 101-150 | |
| Q4 | 排名 151-200 | |
| Q5 | 排名 201-250（S 最低 20%） | 该信号认为"最没价值"的 |

### 4.2 回流方法

对每个桶实验：

- 从该桶的 50 个样本中**均匀采样**填满 151 张预算（每样本约 3 份副本）
- 采样方式：`np.random.default_rng(seed).multinomial(151, uniform_prob_50)`
- 将副本以硬链接方式加入基础训练集的 Normal 子目录
- 训练集总量 = 7200 + 151 = 7351（与 hn14 完全一致）

### 4.3 桶内均匀的理由

桶内不加权。因为 Layer-1 测的是**桶之间的差异**（信号的排序力），不是桶内的加权方式。如果桶内也加权，会引入额外变量。

## 六、评估方法

每个实验训练完 200 epoch 后，执行 formal gate-aware 评估：

1. 对所有 200 个 checkpoint 逐一评估
2. 温度校准（在 cal split 上拟合 T）
3. 在 op split 上计算双阈值指标
4. 按排序规则选出 best epoch
5. 记录：best_epoch, spec_at_r995, spec_at_r990, prec_at_r990, ptr_at_r990, tau_r995, tau_r990, temperature_T

## 七、判定标准

### 7.1 信号有排序力的条件（至少满足 2/3）

1. **Q1 显著优于 Q5**：Spec@R99.5(Q1) - Spec@R99.5(Q5) > 0.03（约 2-3 个 TN 的差距）
2. **Q1 优于 G0 baseline**：Spec@R99.5(Q1) > Spec@R99.5(G0)
3. **大体单调**：Q1 ≥ Q2 ≥ Q3（允许 Q4/Q5 之间有波动，但高分端不能倒挂）

### 7.2 六种可能结果及解读

| 结果模式 | 解读 | 下一步 |
|----------|------|--------|
| Q1>>Q5，单调递减 | 信号有强排序力 | 进入 Layer-2 主线 |
| Q5>>Q1，单调递增 | 信号方向反了 | 翻转信号方向，重新排桶验证 |
| 全平（Q1≈Q5） | 信号无排序力 | 淘汰该信号，不进 Layer-2 |
| Q1 和 Q5 都好，Q3 最差 | U 型，信号捕捉到两类不同有价值样本 | 分析 Q1 和 Q5 样本特征差异 |
| Q1 最好但 Q2-Q5 全平 | 只有极端高分有用 | 考虑用阈值截断而不是连续加权 |
| Q3 最好（中间好两头差） | 中等难度最值钱 | 与 Moderate Coreset 结论一致，调整策略 |
