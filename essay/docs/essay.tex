\chapter*{摘要}
\addcontentsline{toc}{chapter}{摘要}
本文围绕地下排水管道 CCTV 图像中的缺陷检测问题，构建一条“前级高召回预筛 + 后级缺陷检测 + 跨域迁移”的两阶段研究主线。与早期 exploratory 阶段不同，当前论文主稿仅保留 thesis-facing 的问题定义、方法设计、formal 协议、formal 实验与论文级结论；阶段性试错、脚本改造、训练事故和方法演进过程则独立记录在 \texttt{report.tex} 中。

针对 sewer 场景中正常帧数量远高于缺陷帧、背景纹理复杂、误报极易累积的现实约束，本文首先将第一阶段重新定义为高召回 Normal/Abnormal gate，而不是普通默认阈值二分类器。第一阶段的正式目标不再是训练器中的 \texttt{acc/top1}，而是在 \formalmetric{Recall$\geq$99.5\%} 与 \formalmetric{Recall$\geq$99.0\%} 约束下，尽可能提高正常样本过滤能力。因此，本文建立了 stage-1 formal protocol：统一 \texttt{batch=24}、统一 \texttt{epochs=200}、每轮保存 checkpoint，并以外部 gate-aware evaluator 对所有 checkpoint 做温度校准与 operating point 排序。direct binary gate formal capacity scan 表明，\texttt{yolo11m-cls} 在 \formalmetric{Spec@R99.5}、\formalmetric{Spec@R99.0}、\formalmetric{Prec@R99.0} 和 \formalmetric{PTR@R99.0} 的综合排序下成为当前 formal high-recall leader，\texttt{yolo11x-cls} 为第二对照模型。

在此基础上，本文进一步将第二阶段定位为整篇工作的主创新承载区，围绕改进 YOLOv11 检测器、源域到目标域的跨域迁移训练、以及低标注约束下的弱监督候选区域构建展开研究。当前主稿已经完成两个 stage-1 formal capacity scan 的正式回填，并按 legacy 框架重组为“绪论—理论基础—数据与总体框架—前级高召回预筛—改进 YOLOv11 检测与迁移—实验结果与分析—结论与展望”的七章结构。待 formal HN / HardMix / RCIS 以及 detector 相关 formal 结果陆续回填后，即可进入最终定稿阶段。
\keywords{地下排水管道；YOLOv11；高召回门控；两阶段级联；跨域迁移；formal protocol}

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This thesis studies intelligent defect detection for underground drainage pipeline CCTV imagery under a two-stage cascade with cross-domain transfer. The current manuscript is thesis-facing: it keeps only formal problem definition, formal protocol, formal experiments, and thesis-level conclusions, while chronological trial-and-error records are moved to \texttt{report.tex}.

Stage-1 is explicitly redefined as a high-recall Normal/Abnormal gate rather than a default-threshold classifier. Its formal objective is no longer trainer-side \texttt{acc/top1}, but normal filtering under fixed high-recall operating points. A unified formal protocol is therefore established: \texttt{batch=24}, \texttt{epochs=200}, checkpoint saved every epoch, and external gate-aware evaluation with temperature scaling and operating-point ranking. The direct binary gate formal capacity scan shows that \texttt{yolo11m-cls} is the current high-recall leader, while \texttt{yolo11x-cls} serves as the second control model. Based on this gate front-end, stage-2 remains the main innovation carrier of the thesis, focusing on an improved YOLOv11 detector, source-to-target transfer, and weakly supervised candidate-region generation under limited annotation cost.
\engkeywords{underground drainage pipeline; YOLOv11; high-recall gate; two-stage cascade; cross-domain transfer; formal protocol}

\chapter{绪论}

\section{研究背景与意义}
地下排水管道的日常巡检高度依赖 CCTV 视频。与通用视觉任务不同，排水管道图像存在水膜反光、污渍附着、压缩噪声、局部遮挡、光照波动和类间纹理相似等问题，导致正常背景与真实缺陷之间存在强混淆。如果把全部帧直接交给后级检测器处理，一方面会浪费大量算力与人工复核资源，另一方面也会让误报在长视频中持续累积。因此，本文并不把“分类”“伪框”“检测”“迁移”视为彼此分离的独立任务，而是将其组织为一条以工程约束为驱动的两阶段识别链：前级负责高召回预筛，后级负责精细检测，跨域迁移负责把公开 sewer 数据上的表征能力迁移到本地目标域。

\section{国内外研究现状}
现有研究大致可以分为四条线。第一条是排水管道缺陷的直接分类与检测研究，重点回答公开 sewer 数据上的缺陷识别效果。第二条是基于 YOLO 系列检测器的工程落地研究，强调在复杂背景下的实时性与精度平衡。第三条是 CAM / Grad-CAM、伪框生成和低标注增强研究，用于在标注稀缺时降低 detector 启动成本。第四条是迁移学习与跨域适应研究，用于缓解源域公开数据与本地目标域之间的分布差异。总体来看，现有工作通常会分别讨论这些模块，但较少把“高召回 gate + detector + transfer”作为同一条工程主线统一组织。

\section{现有研究存在的问题}
从本文任务出发，当前研究至少存在三个不足。其一，许多工作把第一阶段分类器仍按普通默认阈值 accuracy 任务处理，没有把它明确提升为高召回门控问题，导致选模准则与真实工程目标脱节。其二，低标注 detector 链路往往把 CAM、伪框、迁移和 detector 本身分开讨论，缺少统一的证据链。其三，研究过程与论文定稿口径经常混在一起，训练日志里的 \texttt{best.pt}、临时 exploratory 结果和最终结论彼此污染，造成后期材料难以统一。

\section{研究内容与技术路线}
本文围绕上述问题组织四项研究内容：
\begin{enumerate}[label=\arabic*.]
    \item 将第一阶段重定义为高召回 Normal/Abnormal gate，并建立统一的 formal protocol，使其 best checkpoint 由外部 gate-aware evaluator 决定，而不是由 trainer 的 \texttt{acc/top1} 决定。
    \item 在统一 protocol 下重新完成 direct binary gate 五模型容量扫描，确认 formal high-recall leader 与第二对照模型，为后续 calibration、HN、HardMix 和信息量采样提供统一起点。
    \item 以改进 YOLOv11 为主体，组织 detector 的结构改进、损失优化与 source-to-target 迁移训练，并把弱监督候选区域构建纳入 detector 链路。
    \item 从系统级角度评估两阶段方案在误报控制、复核效率和跨域适应性上的综合收益。
\end{enumerate}

\section{本文主要创新点}
当前主稿阶段可稳定保留的创新表述包括：
\begin{enumerate}[label=\arabic*.]
    \item 将第一阶段从普通二分类重新定义为高召回 gate，并建立了外部 gate-aware 的 formal 选模协议；
    \item 构建以两阶段级联为主线的 sewer 缺陷识别体系，使前级预筛、弱监督候选区域与后级 detector 形成统一链路；
    \item 围绕改进 YOLOv11 与跨域迁移训练构建后级检测主创新框架。
\end{enumerate}
其中，第一点已经由 formal capacity scan 启动并产生正式结果；后两点将在 detector 与 transfer 正式实验全部回填后进一步收束。

\section{论文结构安排}
本文结构沿用 legacy 论文框架组织为七章。第 1 章说明研究背景、现状、不足与总体路线；第 2 章给出理论基础与关键技术；第 3 章说明数据集构建、任务定义与总体框架；第 4 章聚焦前级高召回预筛与弱监督标注增强；第 5 章聚焦改进 YOLOv11 检测器与跨域迁移策略；第 6 章给出实验结果与分析；第 7 章总结全文并展望后续工作。

\chapter{理论基础与关键技术}

\section{地下排水管道缺陷类型与图像特征}
地下排水管道缺陷既包括结构性异常，也包括表面性异常。不同缺陷在 CCTV 图像中的表现形式差异明显，例如裂缝与破裂更依赖细粒度边缘与纹理突变，渗漏与侵入则往往伴随局部形态与上下文环境共同变化。与此同时，大量正常图像仍可能因为水膜、污渍、反光和接缝纹理而表现出近似缺陷的局部模式。这一特征决定了本文必须区分“高召回 gate 的误报控制问题”和“后级 detector 的精细定位问题”。

\section{图像分类与目标检测评价指标}
本文涉及三类评价语义。第一类是第一阶段 gate 评价，其正式主排序固定为：\formalmetric{Spec@R99.5}、\formalmetric{Spec@R99.0}、\formalmetric{Prec@R99.0} 和 \formalmetric{PTR@R99.0}。第二类是 six-class source 的辅助参考排序，按 Accuracy、AUROC、AUPRC 组织。第三类是第二阶段检测评价，包括 Precision、Recall、F1、AP50 和 AP50-95 等。需要特别强调的是，第一阶段训练日志中的 \formalmetric{acc/top1/loss} 只承担训练健康监控功能，不承担正文正式选模功能。

\section{YOLO 系列与 YOLOv11 原理}
YOLO 系列方法强调一阶段端到端检测，在工程应用中具有较强的效率优势。YOLOv11 在结构表达能力、工程成熟度和推理效率之间提供了稳定的平台，适合作为本文两阶段体系中的分类与检测基础模型。本文并非简单替换 YOLOv11，而是在 stage-1 中把其分类能力改造为高召回 gate，在 stage-2 中围绕 detector 结构和迁移策略进行针对性增强。

\section{注意力机制、损失函数与框回归基础}
后级 detector 的结构增强将主要围绕三条线展开：注意力机制提高复杂背景下的判别聚焦能力，检测头改进改善小目标与细粒度结构异常的表达组织，损失函数设计则在类别不均衡与难样本学习之间实现更合理的优化折中。这些内容构成第 5 章 detector 改进的理论基础。

\section{迁移学习与弱监督定位基础}
本文同时采用源域预训练、目标域微调与弱监督候选区域生成。源域分类帮助模型学习 sewer-specific representation，目标域分类与 detector 微调缩小本地任务域差，CAM / Grad-CAM 则在低标注条件下生成 detector 所需的初始候选区域。三者并非平行实验，而是 detector 训练链中的前序支撑能力。

\section{本章小结}
本章统一了后文所需的理论口径：一是第一阶段的高召回 gate 评价语义，二是第二阶段 detector 与系统级评价语义，三是 YOLOv11、迁移学习与弱监督定位等关键技术的角色定位。这些基础内容共同支撑后续的数据组织、第一阶段 formal protocol 和第二阶段 detector 改进。

\chapter{数据集构建与总体研究框架}

\section{数据来源与总体说明}
本文当前涉及两类核心数据。第一类是 source 侧 sewer 分类数据，用于 six-class source 分类与 direct binary gate capacity scan；第二类是目标域结构化缺陷数据，用于 detector 训练、伪框增强与最终系统验证。为避免一个数据目录承担多种不兼容任务，本文分别构造 source six-class 视图和 direct binary gate 视图，并将 target-domain detector 数据单独组织。

\section{源域分类数据集构建}
第一阶段二分类 gate 并未引入新的图像来源，而是在 source 侧单标签六类分类数据上做任务重映射：将 \textrm{Normal} 保留为负类，其余五类统一映射为 \textrm{Abnormal} 正类。这样既保证了 source six-class 和 direct binary gate 的图像来源一致，又便于后续把 stage-1 表征能力与 detector 初始化、CAM 伪框生成和 target fine-tune 链接起来。

\section{目标域任务定义与标签映射}
目标域部分围绕最终检测类别组织。对于 detector 而言，本文最终关心的是结构性缺陷在目标域上的检测能力，而不是 source 侧 coarse gate 自身。因此，第一阶段和第二阶段在任务角色上严格区分：前者只负责高召回预筛，后者承担最终定位与类别识别。

\section{数据划分协议与 formal / exploratory 边界}
从 formalization 开始，第一阶段所有论文可引用材料都必须进入 \texttt{research/materials/stage1\_formal/} 与 \texttt{research/results/stage1\_formal/}。旧 exploratory 材料不再直接进入正文，只保留在 \texttt{research/archive/stage1\_preformal\_legacy/} 中作为方法演进痕迹。正式 gate capacity scan 进一步采用统一的 val-cal / val-op 口径：先在 val-cal 上拟合温度参数，再在 val-op 上执行 threshold sweep 和 operating point 排序。

\section{总体系统框架设计}
总体框架由前级高召回 gate、后级 detector 和 source-to-target transfer 三部分构成。第一阶段在高召回约束下尽可能过滤掉可以安全排除的 normal 帧；第二阶段对剩余高风险图像完成检测；迁移学习与弱监督候选区域生成则共同服务于 detector 的训练效率与目标域适配。

\section{评价协议与实验规范}
当前正式协议可概括为两条。对 direct binary gate，统一 \texttt{batch=24}、\texttt{epochs=200}、每轮保存 checkpoint，并以外部 gate-aware evaluator 统一排序；对 six-class source，同样统一 \texttt{batch=24} 和 \texttt{epochs=200}，但排序规则改为 Accuracy、AUROC、AUPRC。formal best checkpoint 一律不再由 trainer 内部 \texttt{best.pt} 决定，而由对应任务的外部 summary 选出。

\section{本章小结}
本章将数据来源、任务重映射、formal / exploratory 边界和两阶段总体框架统一到同一套研究语义下，为后续第 4 章的高召回 gate 与第 5 章的 detector / transfer 链路提供了共同的数据与协议基础。

\chapter{前级高召回预筛与弱监督标注增强策略}

\section{前级高召回预筛问题定义}
第一阶段的任务不是“尽量提高默认阈值 accuracy”的普通二分类，而是“在尽量不过漏异常图像的约束下，最大化对正常图像的过滤能力”的高召回 gate。也正因为如此，早期 exploratory 阶段习惯沿用的 \formalmetric{acc/top1} 停止与选模逻辑，在 formal 口径下被正式废止：\formalmetric{acc/top1/loss} 仅保留为训练健康信息，而 stage-1 的正文 best checkpoint 必须由外部 gate-aware summary 决定。

\section{基于同源图像重标注的二分类 gate 构建}
direct binary gate 建立在与 six-class source 相同的图像来源上，但任务语义不同。本文将 \textrm{Normal} 映射为负类，其余缺陷类别统一映射为正类，使第一阶段可以直接回答“哪些图像应该继续送入 detector，哪些图像可以被安全挡掉”。这一重定义的价值在于：它既保留了 source 侧表征学习的连续性，又让第一阶段与最终系统目标紧密对齐。

\section{direct binary gate formal capacity scan}
为正式确认第一阶段 backbone 的容量选择，本文在统一 formal protocol 下，对 \texttt{yolo11n-cls}、\texttt{yolo11s-cls}、\texttt{yolo11m-cls}、\texttt{yolo11l-cls} 和 \texttt{yolo11x-cls} 完成了 direct binary gate 五模型容量扫描。该轮实验统一采用 \texttt{batch=24}、\texttt{epochs=200}、每轮保存 checkpoint，并对每个 checkpoint 执行外部 gate-aware 评估：先在 val-cal 上拟合温度参数，再在 val-op 上完成 calibrated score、threshold sweep 与 operating point 排序。因此，本文报告的 best epoch 并不等同于 trainer 自动生成的 \texttt{best.pt}，而是按照 \formalmetric{Spec@R99.5 $\rightarrow$ Spec@R99.0 $\rightarrow$ Prec@R99.0 $\rightarrow$ PTR@R99.0} 这一正式规则重新选出的 gate-best checkpoint。

\section{Hard Negative Mining、HardMix 与信息量采样路线}
既然 formal capacity scan 已经将 stage-1 主模型固定为 \texttt{yolo11m-cls}，后续增强路线就不应再围绕旧的 exploratory 主线展开。更合理的顺序是：首先在 \texttt{yolo11m-cls} 上完成完整的 HN 比例扫描，并用 \texttt{yolo11x-cls} 做轻量 cross-capacity 验证；随后在新的 best HN ratio 上继续评估 HardMix、通用难样本损失与 RCIS 等信息量采样路线。换言之，capacity scan 在本文中的价值不仅是选择 backbone，更在于为后续所有训练侧增强提供统一且可追溯的起点。

第一阶段分类模型并不直接输出检测框，但其热力图响应可以为 detector 提供弱监督候选区域。本文后续将继续保留 CAM / Grad-CAM 伪框生成链路，用于在低标注条件下为 detector 初始化提供候选框来源。不过，这部分在当前主稿中的角色是“服务 detector”，而不是单独作为第一阶段的最终输出目标。

\chapter{实验结果与分析}

\section{实验设置}
为确保第一阶段容量扫描结果具备可比性与可追溯性，本文对 formal 实验阶段采用统一协议：第一阶段分类任务统一设定为 \texttt{batch=24}、\texttt{epochs=200}，并对全部 checkpoint 执行外部 gate-aware 评估。训练器内部输出的 \formalmetric{acc/top1/loss} 仅用于监控训练健康状态，不参与正文中的正式选模。第二阶段 detector 与系统级实验亦遵循相同的材料留档与 formal summary 管理规范，以保证后续跨阶段比较处于统一协议之下。

\section{第一阶段 direct binary gate formal capacity 结果分析}
表 \ref{tab:stage1-formal-gate-capacity} 给出了 direct binary gate 五模型在统一 formal protocol 下的容量扫描结果。可以看到，在 \formalmetric{Spec@R99.5}、\formalmetric{Spec@R99.0}、\formalmetric{Prec@R99.0} 和 \formalmetric{PTR@R99.0} 的联合排序规则下，\texttt{yolo11m-cls} 取得了最优综合表现，\texttt{yolo11x-cls} 位居第二，\texttt{yolo11l-cls} 则退居第三。这一排序与 exploratory 阶段基于经验直觉形成的 backbone 偏好并不一致，说明第一阶段主模型选择必须建立在正式 operating point 指标上，而不能继续依赖默认阈值分类印象。

进一步地，表 \ref{tab:stage1-formal-top1-vs-gatebest} 表明，五个模型的 trainer \formalmetric{top1-best} 与 gate-best 全部不一致。其中，\texttt{yolo11m-cls} 的 trainer 侧 \formalmetric{top1-best} 出现在第 197 轮，而 formal gate-best 出现在第 78 轮；\texttt{yolo11l-cls} 与 \texttt{yolo11x-cls} 也呈现出类似错位。这一结果说明，若仍以 \formalmetric{acc/top1} 作为第一阶段 checkpoint 选择依据，将系统性偏离高召回门控真正关心的工作点目标。换言之，第一阶段 formalization 的核心不只是延长训练周期或保存更多 checkpoint，而是把选模准则从训练器内部健康指标切回到高召回 gate 本身。

图 \ref{fig:stage1-formal-gate-bar}--图 \ref{fig:stage1-formal-gate-top1-mismatch} 进一步揭示了不同容量模型在主要工作点上的差异分布。首先，\texttt{yolo11m-cls} 并非仅在单个指标或单个 epoch 上偶然占优，而是在最关键的主排序锚点 \formalmetric{Spec@R99.5} 与 \formalmetric{Spec@R99.0} 上同时取得最优。其次，\texttt{yolo11x-cls} 虽然在长训练区间内表现出较强潜力，但其最终高召回过滤能力仍未超过 \texttt{yolo11m-cls}。最后，\texttt{yolo11n-cls} 与 \texttt{yolo11s-cls} 虽然能够达到可用水平，但在正式指标上与 \texttt{m/x} 之间仍存在明确差距。因此，第一阶段后续的 HN、HardMix 与 RCIS，均应以 \texttt{yolo11m-cls} 为统一主模型，并以 \texttt{yolo11x-cls} 作为容量对照模型。

\section{第一阶段 six-class source formal 结果分析}
表 \ref{tab:stage1-formal-cls6-capacity} 给出了 six-class source 五模型在统一 formal protocol 下的容量扫描结果。可以看到，\texttt{yolo11x-cls} 在 Accuracy、AUROC 与 AUPRC 的综合排序下成为 source-side six-class leader，\texttt{yolo11m-cls} 位居第二，\texttt{yolo11l-cls} 位居第三。该结果说明，在 source-side 多类分类视角下，较大容量模型仍具有优势；但其解释范围应被严格限定为 auxiliary representation view，而不能直接延伸为 stage-1 gate 的正式 backbone 选择依据。

\section{Cross-view 结果分析}
表 \ref{tab:stage1-formal-crossview-rank-gap} 与图 \ref{fig:stage1-formal-crossview-gap} 清楚表明，source six-class 排序不能替代 direct binary gate 排序。最关键的差异集中在 \texttt{yolo11m-cls} 与 \texttt{yolo11x-cls}：前者在 source six-class 中位居第二，却在 direct binary gate 中成为正式主模型；后者在 source six-class 中位居第一，却在 direct binary gate 中退居第二。这一错位说明，source-side 表征质量虽具有参考价值，但 stage-1 的正式 backbone 选择必须始终回到 recall-constrained gate objective 本身。

\section{formal HN、HardMix 与 RCIS 结果预留}

\begin{enumerate}[label=\arabic*.]
    \item formal HN：在 \texttt{yolo11m-cls} 上完成完整的 hard-negative ratio sweep，并用 \texttt{yolo11x-cls} 做轻量 cross-capacity 验证；
    \item formal HardMix：比较训练侧 hard positive 与 hard normal 联合暴露是否仍是最有效的净增益来源；

这些实验的共同目标并非再次回答“哪个 backbone 更强”，而是在 backbone 已被正式固定之后，继续评估样本组织与信息量采样能否在相同高召回约束下进一步提升 normal 过滤能力。

\chapter{结论与展望}

\section{研究结论}
综合当前已经完成的 formal 结果，本文可稳定得到如下结论：
\begin{enumerate}[label=\arabic*.]
    \item 地下排水管道缺陷识别更适合组织为“高召回 gate + 精细 detector”的两阶段级联系统，而不是直接对全部图像执行单阶段检测。这一组织方式更符合 sewer 场景中“正常样本占绝大多数、误报易于累积、人工复核成本高”的工程约束。
    \item 第一阶段必须被正式定义为 operating-point-driven 的高召回 gate，而不能继续视作默认阈值下的普通二分类任务。相应地，trainer 内部的 \formalmetric{acc/top1} 只能作为训练健康信息，而不能再充当 formal best checkpoint 的依据。
    \item 在统一 \texttt{batch=24}、\texttt{epochs=200}、每轮保存 checkpoint 与外部 gate-aware 评估的 protocol 下，direct binary gate formal capacity scan 已正式确认 \texttt{yolo11m-cls} 为当前 high-recall leader，\texttt{yolo11x-cls} 为第二对照模型；与此同时，source-side six-class formal capacity scan 则确认 \texttt{yolo11x-cls} 为辅助参考 leader。二者之间的排序错位进一步证明了：source six-class 排序不能替代 direct binary gate 的正式选模。
    \item 第二阶段 detector 与跨域迁移仍是全文主创新的主要承载区；第一阶段 formal capacity scan 的价值，在于为后续 HN、HardMix、RCIS 以及 detector 训练提供了统一且可追溯的前端起点。
\end{enumerate}

\section{不足之处}
当前主稿的主要不足不在于已有结论不成立，而在于后续 formal 实验尚未全部到齐。具体而言，围绕新 leader \texttt{yolo11m-cls} 的 formal HN、HardMix 与 RCIS 仍未全部重跑完成；第二阶段 detector 与跨域迁移实验也尚未完全按最新 formal 口径统一整理。因此，当前版本应被视为已经建立起正式证据主轴的论文主稿，而非最终定稿。

\section{展望}
后续工作的重点可概括为三方面。其一，围绕 \texttt{yolo11m-cls} 完成 stage-1 的 formal HN sweep，并以 \texttt{yolo11x-cls} 做轻量 cross-capacity 验证，从而在统一 calibrated protocol 下确认新的最佳 hard-negative 比例。其二，在新的主模型与 HN 比例固定之后，继续比较 HardMix 与 RCIS 等训练侧增强，确认哪些策略能够在统一高召回约束下带来净增益。其三，完成 detector 结构改进、跨域迁移训练与系统级验证的正式回填，使两阶段级联系统的整体贡献在统一证据链下闭环呈现。
