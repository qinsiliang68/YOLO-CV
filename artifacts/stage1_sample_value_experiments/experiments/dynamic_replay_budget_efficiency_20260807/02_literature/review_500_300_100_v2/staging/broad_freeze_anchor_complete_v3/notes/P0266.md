# P0266 - Continual Learning Strategy in One-Stage Object Detection Framework Based on Experience Replay for Autonomous Driving Vehicle

## 独立中文摘要

问题：自动驾驶检测增加新类时会遗忘旧类，需要在有限记忆中重放历史样本。 方法：方法在单阶段检测器中保留累积旧类 memory，与新类数据共同训练以实现持续学习。 结论：作者在 Pascal VOC 2007 报告相对全类联合训练 mAP 下降 4.3%，优于所列持续检测方法。

## 批判性小综述

对该研究的证据边界判断：它提供视觉 replay 的工程基线，但目标是抗遗忘，buffer 选择、容量和随机对照细节需筛读。 反向约束：不能把较小 mAP 下降解释为目标选样胜随机，也不能由检测 buffer 容量确定分类回流比例。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ6；其可迁移链条是：Stage1 可借鉴每个 logical arm 独立记录 base 与 replay 实际曝光，并把 no-replay 作为必要基线。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴每个 logical arm 独立记录 base 与 replay 实际曝光，并把 no-replay 作为必要基线。 禁止外推：不能把较小 mAP 下降解释为目标选样胜随机，也不能由检测 buffer 容量确定分类回流比例。
