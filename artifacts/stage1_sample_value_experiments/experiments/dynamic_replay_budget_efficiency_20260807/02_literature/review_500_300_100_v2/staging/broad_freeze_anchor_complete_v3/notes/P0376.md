# P0376 - Improved classification model for peptide identification based on self-paced learning

## 独立中文摘要

问题：肽谱匹配数据质量差且小样本训练易过拟合和不稳定，需要在固定错误发现率下提高可识别样本数。 方法：方法调整目标与 decoy 的损失权重，并在 CRanker 训练中加入 self-paced learning 以减少错误 PSM 的参与。 结论：作者报告相对原 CRanker 更稳定，并在相同 FDR 下识别更多 PSM，优于所比较方法。

## 批判性小综述

对该研究的证据边界判断：受约束错误率指标与 Stage1 相近，但损失重权和课程同时变化，无法仅由摘要归因给样本时机；seed 证据需筛读。 反向约束：不能把错误 PSM 一律视为高损失样本，也不能把 FDR 阈值直接转换为 FN95 阈值。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ6,RQ8；其可迁移链条是：Stage1 可借鉴在固定 FN 约束下比较可接受 normal 数，并将 Q 门控与类别损失权重分开消融。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴在固定 FN 约束下比较可接受 normal 数，并将 Q 门控与类别损失权重分开消融。 禁止外推：不能把错误 PSM 一律视为高损失样本，也不能把 FDR 阈值直接转换为 FN95 阈值。
