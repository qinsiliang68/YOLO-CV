# P0156 - Utility-Diversity Aware Online Batch Selection for LLM Supervised Fine-tuning

## 独立中文摘要

问题：在线 batch 选择若只优化单样本 utility 会忽略集合多样性，而且外部参考模型和额外反向传播可能抵消节省的训练成本。 方法：UDS 用 logits 矩阵核范数联合刻画样本效用和样本内多样性，并通过低维 embedding 与历史样本缓冲区估计样本间多样性。 结论：作者报告在多种监督微调任务和数据预算下优于所比较的在线选择方法，并缩短相对全量微调的训练时间。

## 批判性小综述

对该研究的证据边界判断：该方法直接对应 utility 与 diversity 联合以及历史覆盖，但核范数代理的语义、随机基线公平性和跨 seed 结果需全文筛读。 反向约束：不能把 LLM logits 核范数直接当作 CCTV 样本价值，也不能忽略额外打分和 embedding 计算成本。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5,RQ6；其可迁移链条是：Stage1 可把 D 独立于 R 实现为有记忆的覆盖选择器，并单独记录候选效用与最终集合边际覆盖。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 D 独立于 R 实现为有记忆的覆盖选择器，并单独记录候选效用与最终集合边际覆盖。 禁止外推：不能把 LLM logits 核范数直接当作 CCTV 样本价值，也不能忽略额外打分和 embedding 计算成本。
