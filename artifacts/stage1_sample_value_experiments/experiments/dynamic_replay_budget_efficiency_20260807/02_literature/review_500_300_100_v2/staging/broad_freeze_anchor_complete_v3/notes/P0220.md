# P0220 - Probe-Based Data Attribution: Discovering and Mitigating Undesirable Behaviors in LLM Post-Training

## 独立中文摘要

问题：需要把后训练模型的具体有害行为追溯到负责的训练数据，并以真实重训验证归因。 方法：方法计算行为 prompt 与 preference pair 的 activation-difference 向量余弦，排序和聚类责任数据，再过滤或改标签重训。 结论：作者在 OLMo 2 DPO 上报告过滤高归因点使有害行为降 63%，改标签降 78%，且优于梯度与 LLM judge。

## 批判性小综述

对该研究的证据边界判断：它针对偏好训练与行为探针，但最强之处是 attribution 后做定向 intervention，而非停在相关性分数。 反向约束：不能把 activation similarity 当因果价值，只有重训效应才可升级结论。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ4,RQ7；其可迁移链条是：Stage1 的 A/R 候选必须通过冻结样本集的 T/R1/R2 重训验证；可用 probe embedding 作低成本方向候选。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 A/R 候选必须通过冻结样本集的 T/R1/R2 重训验证；可用 probe embedding 作低成本方向候选。 禁止外推：不能把 activation similarity 当因果价值，只有重训效应才可升级结论。
