# P0496 - Dynamic Curriculum Learning for Great Ape Detection in the Wild

## 独立中文摘要

问题：论文研究野外类人猿检测的半监督训练中，伪标签数量、阈值、损失权重、增强和教师动量应如何随训练阶段变化。 方法：作者构建教师学生训练循环，以动态策略共同调度无标签样本量和伪标签可信门槛等变量，并设置固定、递增、递减及不同初始化的消融。 结论：线性增加并带 warmup 与 cooldown 的样本时序优于固定或递减方案；随机初始化可造成灾难性失败，说明相同数据的作用受初始化和阶段强烈调制。

## 批判性小综述

对该研究的证据边界判断：这是伪标签半监督检测，不是已标注样本 replay；主消融只在一个 fold，跨 seed 证据主要出现在迁移实验，不能夸大稳定性。 反向约束：不能照搬其线性增加策略，也不能推出 Stage1 的后期 replay 必然有害或某个比例最优。
