# P0060 - Unsupervised Domain Adaptation Via Data Pruning

## 独立中文摘要

问题：论文研究分布偏移下哪些源域训练样本与无标签目标域最相关，并通过删除远离目标分布的样本降低负迁移。 方法：AdaPrune 在源域预训练表征中以最大均值差异衡量候选子集与目标集的距离，将固定子集规模的选择写成二元整数二次规划。 结论：四个生物声学域的三次重复中，AdaPrune 平均优于 KMM 与 landmark 选择，并与 CORAL 互补；MMD 与目标测试精度呈中等负相关。

## 批判性小综述

对该研究的证据边界判断：方法使用目标域无标签数据构造选择规则，复杂度对训练样本数为三次方；若 Stage1 用 val_op 或 test 做目标分布，会直接造成开发泄漏。 反向约束：不能推出接近目标分布的样本在同分布 Stage1 replay 中更有价值，也不能在没有独立 val_target 时采用该方法。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ6；其可迁移链条是：可迁移的是在独立 val_target 上研究覆盖与分布相关性，并把目标集身份、划分和哈希列为 A 或 D 的前置合同。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是在独立 val_target 上研究覆盖与分布相关性，并把目标集身份、划分和哈希列为 A 或 D 的前置合同。 禁止外推：不能推出接近目标分布的样本在同分布 Stage1 replay 中更有价值，也不能在没有独立 val_target 时采用该方法。
