# P0397 - Training sample selection for deep learning of distributed data

## 独立中文摘要

问题：论文研究训练数据分散在带宽受限节点时，哪些本地样本值得传输给中心训练器以减少通信和学习时间。 方法：方法根据候选样本试跑结果构造 correctness 与 confidence 两种优先级，在通信预算下选择训练样本并与均匀采样比较。 结论：模拟实验报告 MNIST 可减少最高约十五倍带宽，CIFAR-10 可减少约四分之一学习时间，同时保持目标性能。

## 批判性小综述

对该研究的证据边界判断：它有均匀随机对照但优化目标是通信效率，候选评价依赖试跑结果；未证明被选样本在相同累计 optimizer exposure 下泛化更好。 反向约束：不能把 correctness 或 confidence 直接当作 RHO，也不能由带宽节省推断 TN_at_FN95 会改善。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ6,RQ7；其可迁移链条是：Stage1 可借鉴每轮基于当前状态更新候选和保留 global random，但必须把训练步数、唯一数和累计曝光完全匹配。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴每轮基于当前状态更新候选和保留 global random，但必须把训练步数、唯一数和累计曝光完全匹配。 禁止外推：不能把 correctness 或 confidence 直接当作 RHO，也不能由带宽节省推断 TN_at_FN95 会改善。
