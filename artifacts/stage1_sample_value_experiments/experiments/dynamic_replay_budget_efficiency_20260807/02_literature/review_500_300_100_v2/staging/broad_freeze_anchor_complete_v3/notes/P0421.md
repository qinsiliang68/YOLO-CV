# P0421 - Self-Paced Learning with Diversity

## 独立中文摘要

问题：传统自步学习偏好容易样本，却忽略已选集合内部重复，可能被少数同质模式占满。 方法：SPLD 在自步正则中同时编码易度与组间多样性，并给出对选择变量的高效全局求解。 结论：作者在三个真实数据集上报告优于普通 SPL，并在两个视频数据集取得较高 MAP。

## 批判性小综述

对该研究的证据边界判断：方法偏向 easy-to-hard curriculum，并未证明 hardest 或 highest-loss 样本有价值；随机覆盖基线需要进一步核实。 反向约束：不能从 MAP 结果推出 FN95 改善，也不能把 diversity 正则的系数无依据搬入新公式。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5,RQ6；其可迁移链条是：Stage1 的 D 层应与 R 层分开：先限定可学习候选，再对视频、管段或 embedding 群组限流。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 D 层应与 R 层分开：先限定可学习候选，再对视频、管段或 embedding 群组限流。 禁止外推：不能从 MAP 结果推出 FN95 改善，也不能把 diversity 正则的系数无依据搬入新公式。
