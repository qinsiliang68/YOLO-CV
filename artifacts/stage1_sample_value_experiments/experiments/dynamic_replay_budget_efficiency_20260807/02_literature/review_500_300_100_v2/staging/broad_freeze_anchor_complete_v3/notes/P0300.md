# P0300 - Exploring Learning Complexity for Efficient Downstream Dataset Pruning

## 独立中文摘要

问题：训练动态剪枝要求全量训练大型下游模型，且确定性 Top-K 会造成严重子集分布偏移。 方法：DLC 用轻量权重遮蔽估计样本以更少参数可学到的程度，FlexRand 再以带随机性的欠采样替代 Top-K。 结论：作者报告图像和指令剪枝中取得较好性能，图像选择时间缩短约三十五倍且 FlexRand 达到当时较优结果。

## 批判性小综述

对该研究的证据边界判断：它同时提供可学习复杂度和随机覆盖两个机制，十分贴近 HN 输随机的解释；具体随机分布、同预算和 seed 稳定性需精读。 反向约束：不能由 DLC 训练免费近似断言 OOF 动态无用，也不能把速度优势等同 FN95 效用。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5,RQ7；其可迁移链条是：Stage1 可固定同一 R 分数直接比较 Top-K、soft priority 与 FlexRand 式随机超池，隔离 score 与 sampler。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可固定同一 R 分数直接比较 Top-K、soft priority 与 FlexRand 式随机超池，隔离 score 与 sampler。 禁止外推：不能由 DLC 训练免费近似断言 OOF 动态无用，也不能把速度优势等同 FN95 效用。
