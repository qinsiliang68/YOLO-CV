# P0305 - Improved Deep Learning Model Based on Self-Paced Learning for Multiscale Short-Term Electricity Load Forecasting

## 独立中文摘要

问题：多尺度电力负荷融合会引入噪声，样本质量差还会让短时预测陷入局部最优。 方法：方法以稀疏深自编码器融合去噪，再用 self-paced learning 控制样本进入训练的顺序。 结论：作者报告相对既有短时负荷模型 MSE 改善超过百分之十五点八九。

## 批判性小综述

对该研究的证据边界判断：它支持先处理可靠性再安排课程，但自编码器与 SPL 同时改变，无法将提升只归给样本顺序。 反向约束：不能由时间序列 MSE 推出 FN95 改善，也不能把低 loss 样本永久定义为优先。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ6；其可迁移链条是：Stage1 可把 Q 门控和 R 课程分成独立臂，并保持基础模型、增强和损失不变。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 Q 门控和 R 课程分成独立臂，并保持基础模型、增强和损失不变。 禁止外推：不能由时间序列 MSE 推出 FN95 改善，也不能把低 loss 样本永久定义为优先。
