# P0280 - Step-resolved data attribution for looped transformers

## 独立中文摘要

问题：论文研究循环 Transformer 中普通归因把多个内部计算步骤压成一个数后，无法解释样本影响发生在何时。 方法：作者将 TracIn 分解为逐循环步骤的影响轨迹，并用 CountSketch 与 TensorSketch 压缩逐例梯度，使各步骤贡献之和严格回到普通 TracIn。 结论：实验显示同一样本的难度、记忆和影响峰值可发生在不同循环步骤，逐步轨迹能够揭示单一总分掩盖的时间结构。

## 批判性小综述

对该研究的证据边界判断：这里的 step 是模型内部循环而非训练 epoch；TracIn 仍是梯度相似度代理而非因果证书，并受优化器几何和截断反向传播影响。 反向约束：不能把内部循环步骤直接对应到 replay 阶段，也不能由 TracIn 守恒推出某个正贡献样本经过完整训练一定有益。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ6,RQ8；其可迁移链条是：Stage1 可迁移的是保存跨 epoch 或 checkpoint 的方向轨迹和峰值时机，并禁止只报告平均 alignment；计算上可先用分类头草图。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移的是保存跨 epoch 或 checkpoint 的方向轨迹和峰值时机，并禁止只报告平均 alignment；计算上可先用分类头草图。 禁止外推：不能把内部循环步骤直接对应到 replay 阶段，也不能由 TracIn 守恒推出某个正贡献样本经过完整训练一定有益。
