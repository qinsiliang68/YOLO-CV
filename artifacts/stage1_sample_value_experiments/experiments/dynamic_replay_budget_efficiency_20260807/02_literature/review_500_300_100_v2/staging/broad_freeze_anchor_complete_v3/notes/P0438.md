# P0438 - Training data selection for event classification in a highly variable environment

## 独立中文摘要

问题：核设施稀有事件发生环境差异大，用全部历史事件训练可能比选择与当前事件相似的子集更差。 方法：方法用动态时间规整、Jaccard 相似度与聚类为给定测试事件做 similitude assessment，并枚举独特训练事件组合比较预测。 结论：作者以 HFIR 启动功率预测验证按目标事件选择训练集是否优于全量训练。

## 批判性小综述

对该研究的证据边界判断：它是 target-conditional set utility 的直接设计，但按测试事件适配会在 Stage1 构成 test leakage，且事件数很小。 反向约束：不能用最终 test 样本逐个选训练集，也不能由事件相似度直接推断图像梯度方向。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5,RQ7；其可迁移链条是：Stage1 只能用独立 val_target 尾部定义相似性，冻结后再评 val_op/test，并报告集合组合而非单图值。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 只能用独立 val_target 尾部定义相似性，冻结后再评 val_op/test，并报告集合组合而非单图值。 禁止外推：不能用最终 test 样本逐个选训练集，也不能由事件相似度直接推断图像梯度方向。
