# P0198 - Witches' Brew: Industrial Scale Data Poisoning via Gradient Matching

## 独立中文摘要

问题：干净标签投毒要在随机初始化、从头训练和大规模数据下稳定操控指定测试图像，既要求影响方向正确又要求跨训练随机性有效。 方法：方法优化少量训练图像，使其训练梯度方向匹配恶意目标梯度，并加入面向随机初始化和现代训练流程的工程策略。 结论：作者报告该梯度匹配攻击可在完整 ImageNet 规模从头训练中诱发指定误分类，并指出既有防御存在局限。

## 批判性小综述

对该研究的证据边界判断：这是大梯度不等于正价值的强反例：方向对齐可以稳定产生有害目标；其攻击目标、像素优化和威胁模型不能等同普通样本选择。 反向约束：不能由攻击成功断言最后一层余弦足以预测自然样本效用，也不能把被优化的毒样本当成原始数据分布证据。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：Stage1 的 A 必须保留正负符号并绑定独立 FN95 目标，同时增加 negative-alignment 或 anti-critical 对照验证方向含义。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 A 必须保留正负符号并绑定独立 FN95 目标，同时增加 negative-alignment 或 anti-critical 对照验证方向含义。 禁止外推：不能由攻击成功断言最后一层余弦足以预测自然样本效用，也不能把被优化的毒样本当成原始数据分布证据。
