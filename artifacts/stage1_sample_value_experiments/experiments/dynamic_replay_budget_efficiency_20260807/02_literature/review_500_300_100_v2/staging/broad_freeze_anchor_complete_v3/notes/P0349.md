# P0349 - Distill on a Diet: Efficient Knowledge Distillation via Learnable Data Pruning

## 独立中文摘要

问题：论文研究知识蒸馏中固定 Top-K 数据剪枝为何随预算和蒸馏设置失效，以及能否学习一个比硬窗口更稳的选择分布。 方法：作者以验证集上的 SAM 微调、对角 Fisher 逆和影响近似构造 IF-FVM 分数，再用双层策略梯度学习作用于排名分位的 Beta 采样分布。 结论：在 CIFAR 与 ImageNet 的多种剪枝率、三个 seed 和随机基线下，学习分布通常优于随机及固定窗口；论文还发现随机替换固定最优窗口中的一部分样本有时会进一步改善。

## 批判性小综述

对该研究的证据边界判断：证据支持预算依赖和软分布优于刚性 Top-K，但目标是知识蒸馏，分数依赖验证目标和近似曲率；只有三个 seed，且不是固定基础集上的额外 replay。 反向约束：不能据此认定 IF-FVM 或 Beta 分布在 FN95 任务必然有效，也不能把蒸馏剪枝的同算力结论直接等价为额外曝光回流。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5,RQ7；其可迁移链条是：Stage1 可迁移的是把选择器与采样分布分开、按预算单独冻结，并设置随机探索或软优先采样，而非默认排序头部永久有效。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移的是把选择器与采样分布分开、按预算单独冻结，并设置随机探索或软优先采样，而非默认排序头部永久有效。 禁止外推：不能据此认定 IF-FVM 或 Beta 分布在 FN95 任务必然有效，也不能把蒸馏剪枝的同算力结论直接等价为额外曝光回流。
