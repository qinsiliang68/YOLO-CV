# P0364 - Co-teaching: Robust Training of Deep Neural Networks with Extremely Noisy Labels

## 独立中文摘要

问题：深网先学习较干净规律、随后记忆噪声，单模型自身 small-loss 选择会受确认偏差影响。 方法：Co-teaching 同时训练两个网络，每个 mini-batch 各自选择可能干净的低损失样本并交给另一网络反向传播。 结论：噪声 MNIST、CIFAR-10 和 CIFAR-100 上作者报告显著优于当时鲁棒训练方法。

## 批判性小综述

对该研究的证据边界判断：方法依赖噪声率日程和双模型差异，small-loss 可能漏掉 hard-clean；目标是标签鲁棒性而非额外 replay utility。 反向约束：不能由低损失被选中推出其剩余可学习性高，也不能把 Co-teaching 的互教直接改成回流排名。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6；其可迁移链条是：Stage1 可用独立 OOF 模型降低自身记忆泄漏，并把跨模型一致性作为 Q 字段，不能只看当前 run loss。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可用独立 OOF 模型降低自身记忆泄漏，并把跨模型一致性作为 Q 字段，不能只看当前 run loss。 禁止外推：不能由低损失被选中推出其剩余可学习性高，也不能把 Co-teaching 的互教直接改成回流排名。
