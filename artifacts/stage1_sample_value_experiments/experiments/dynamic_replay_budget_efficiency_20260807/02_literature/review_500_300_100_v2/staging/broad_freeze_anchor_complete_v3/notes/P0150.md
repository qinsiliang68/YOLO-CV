# P0150 - Data-driven method for training data selection for deep learning

## 独立中文摘要

问题：地震深度学习训练集若不能代表完整数据的统计变化，模型质量与迁移会受限。 方法：论文比较基于代理属性聚类且考虑到簇中心距离的选择，以及从初始集扫描全数据并增补训练点的方法。 结论：摘要结论主张代表完整变化和统计多样性的训练集对深度模型结果很关键。

## 批判性小综述

对该研究的证据边界判断：来源是会议扩展摘要，定量随机对照和独立 seed 信息有限，不能作为强效果证据。 反向约束：不能从地震数据经验确定聚类空间、每簇配额或动态 replay 刷新频率。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ5,RQ7；其可迁移链条是：Stage1 的 D 层应同时记录 cluster coverage 与到中心的分布，避免每簇只选最典型或只选最离群样本。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 D 层应同时记录 cluster coverage 与到中心的分布，避免每簇只选最典型或只选最离群样本。 禁止外推：不能从地震数据经验确定聚类空间、每簇配额或动态 replay 刷新频率。
