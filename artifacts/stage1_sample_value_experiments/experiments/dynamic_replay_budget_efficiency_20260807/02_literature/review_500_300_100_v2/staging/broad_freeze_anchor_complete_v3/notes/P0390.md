# P0390 - Latent State Models of Training Dynamics

## 独立中文摘要

问题：论文研究初始化与数据顺序随机性怎样形成不同训练轨迹，以及为何部分运行更慢或更差。 方法：方法从每个 checkpoint 提取十四种权重统计量，用 Gaussian HMM 在四十个 seed 的序列上学习离散训练状态和转移图。 结论：研究发现慢收敛 detour 状态与 seed 敏感性相关；架构和超参数稳定化后分叉轨迹可消失，且差异常在早期出现。

## 批判性小综述

对该研究的证据边界判断：分析单位是整条 run 而非单张样本，HMM 假设离散、线性、马尔可夫状态，不能自动解释样本 utility。 反向约束：不能从某个 run 的 detour 状态直接定位高价值照片，也不能把四十 seed 结果外推到当前架构而不复验。

## Stage1 直接相关链

该研究直接映射到 RQ8；其可迁移链条是：可迁移为 Stage1 过程调查：比较好坏 seed 的状态分叉、早期异常和后期 detour，而不只看 epoch200 终点。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移为 Stage1 过程调查：比较好坏 seed 的状态分叉、早期异常和后期 detour，而不只看 epoch200 终点。 禁止外推：不能从某个 run 的 detour 状态直接定位高价值照片，也不能把四十 seed 结果外推到当前架构而不复验。
