# P0069 - Bridging efficacy and efficiency: Innovations in Shapley value estimation for model-agnostic data valuation in machine learning

## 独立中文摘要

问题：Data Shapley 能估计训练数据边际价值但组合重训成本高，大数据上需在估值精度与计算量间折中。 方法：论文提出经验 batch 估计策略，调节训练 batch 与测试子集，并比较多种 Shapley 近似及不同模型、训练阶段。 结论：作者强调 TMC-Shapley 的估值效果和模型无关适应性，并声称批方法能提高效率同时保持精度。

## 批判性小综述

对该研究的证据边界判断：仅有元数据摘要，缺少精确随机基线、ground-truth valuation 和 seed 证据，不能进入 screened 层。 反向约束：不能把 Shapley 近似当作真实 replay 效用，也不能在未验证方差时给 120k 样本做单点排名。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ7；其可迁移链条是：可支持 utility 应由加入/移除后的边际作用定义，并把训练阶段作为估值条件。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可支持 utility 应由加入/移除后的边际作用定义，并把训练阶段作为估值条件。 禁止外推：不能把 Shapley 近似当作真实 replay 效用，也不能在未验证方差时给 120k 样本做单点排名。
