# P0023 - Selectivity Drives Productivity: Efficient Dataset Pruning for Enhanced Transfer Learning

## 独立中文摘要

问题：为目标任务预训练时，通用剪枝分数忽略源类到目标域的映射，可能保留难但无关的数据。 方法：论文分别在监督和自监督预训练中用 label mapping 与 feature mapping 做 source-target 定向剪枝。 结论：作者报告源数据类别可删百分之四十至八十而不损下游性能，并使预训练加速两至五倍。

## 批判性小综述

对该研究的证据边界判断：它强调 worth learning 必须绑定目标域，而非仅 learnable；target mapping 若使用最终评价集会泄漏。 反向约束：不能用最终 test 域选择源数据，也不能由 transfer lossless 推出 replay 会提升安全前沿。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5,RQ7；其可迁移链条是：Stage1 的 A/R 只能使用独立 val_target 和 OOF，映射规则冻结后才打开 val_op/test。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 A/R 只能使用独立 val_target 和 OOF，映射规则冻结后才打开 val_op/test。 禁止外推：不能用最终 test 域选择源数据，也不能由 transfer lossless 推出 replay 会提升安全前沿。
