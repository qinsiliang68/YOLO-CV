# P0233 - Self-Paced Learning and Privileged Information based Cascaded Multi-column Classification algorithm for ASD diagnosis

## 独立中文摘要

问题：ASD 多模态 privileged information 难采集，单模态小数据需要逐步利用更难样本。 方法：方法以单模态 RVFL 初层输出作为后续层 privileged information，在级联过程中按 loss 由易到难选择样本直到全纳入。 结论：作者报告 ASD 与正常对照分类准确率高于所比较方法。

## 批判性小综述

对该研究的证据边界判断：模型级联、privileged output 和 SPL 三者混合，无法从 broad 证据确认课程的独立作用或随机稳定性。 反向约束：不能把上一层输出当标签真值，也不能由医学准确率确定 high-recall replay 队列。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6；其可迁移链条是：Stage1 可将 OOF 参考预测视为只训练期可用的辅助信息，但正式推理不得依赖它。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将 OOF 参考预测视为只训练期可用的辅助信息，但正式推理不得依赖它。 禁止外推：不能把上一层输出当标签真值，也不能由医学准确率确定 high-recall replay 队列。
