# P0113 - ANNE: Adaptive Nearest Neighbors and Eigenvector-based Sample Selection for Robust Learning with Noisy Labels

## 独立中文摘要

问题：单一小损失或特征离群规则在不同噪声率下表现不稳定，无法可靠区分困难干净样本与错标样本。 方法：ANNE 先按损失分高低组，在低损失组用 FINE 特征特征向量筛选，在高损失组用自适应 KNN，再接入 SSR+ 训练。 结论：作者在合成与真实噪声数据上报告多数设置优于已有方法，并保持可接受训练成本。

## 批判性小综述

对该研究的证据边界判断：组合规则仍依赖噪声场景与超参数，且提升来自过滤与鲁棒训练共同作用；跨 seed 和高召回尾部证据需另验。 反向约束：不能把 clean/noisy 判别概率直接当 replay utility，也不能假设所有高损失样本都应排除。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ7；其可迁移链条是：Stage1 的 Q 层应联合 OOF reference loss、邻域一致性和表示离群，而不是把最大 loss 直接当价值。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 Q 层应联合 OOF reference loss、邻域一致性和表示离群，而不是把最大 loss 直接当价值。 禁止外推：不能把 clean/noisy 判别概率直接当 replay utility，也不能假设所有高损失样本都应排除。
