# P0487 - Towards Efficient Data Valuation Based on the Shapley Value

## 独立中文摘要

问题：训练数据价值具有集合条件性，但精确 Shapley 值需要枚举大量联盟，计算通常呈指数增长。 方法：论文以合作博弈 Shapley 值定义训练实例边际价值，并提出一组近似算法降低估值成本，再在基准数据上展示实例价值。 结论：作者报告近似方法可用于多类数据估值任务，并强调 Shapley 公理给出一致的收益分配语义。

## 批判性小综述

对该研究的证据边界判断：它为 V_i(S) 而非固定 V_i 提供理论参照，但价值依赖效用函数、训练算法和采样联盟，近似噪声及深网规模成本需筛读。 反向约束：不能把 Shapley 公理转化为任意线性权重，也不能以计算出的代理值替代未见 seed 的真实回流结果。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ3,RQ7；其可迁移链条是：Stage1 可用小规模随机纳入实验审计组级边际价值，并把 seed 和 replay context 纳入效用定义。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可用小规模随机纳入实验审计组级边际价值，并把 seed 和 replay context 纳入效用定义。 禁止外推：不能把 Shapley 公理转化为任意线性权重，也不能以计算出的代理值替代未见 seed 的真实回流结果。
