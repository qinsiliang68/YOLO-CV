# P0407 - Attentive Experience Replay

## 独立中文摘要

问题：策略持续变化后，过去 buffer 中很少再访问的状态即使误差大，优化它也未必提升当前策略。 方法：AER 按历史状态与当前智能体状态的相似性优先采样 replay transition，并与多种 off-policy 算法组合。 结论：OpenAI Gym 任务上作者报告相对各基础算法的一致改善。

## 批判性小综述

对该研究的证据边界判断：RL 状态访问分布与监督数据不同，但论文明确说明价值依赖当前策略而非历史样本固有难度。 反向约束：不能由状态相似度推出图像特征相似度越高越值得回流，也不能把策略回报等同 FN95。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ6,RQ7；其可迁移链条是：Stage1 可将 value 写成条件于当前 θ 与目标尾部的量，并把 stale exposure/当前相关性作为机制字段。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将 value 写成条件于当前 θ 与目标尾部的量，并把 stale exposure/当前相关性作为机制字段。 禁止外推：不能由状态相似度推出图像特征相似度越高越值得回流，也不能把策略回报等同 FN95。
