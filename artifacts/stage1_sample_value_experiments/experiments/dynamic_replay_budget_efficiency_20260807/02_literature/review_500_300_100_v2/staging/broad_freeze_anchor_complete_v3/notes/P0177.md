# P0177 - Probably Approximate Shapley Fairness with Applications in Machine Learning

## 独立中文摘要

问题：精确 Shapley value 不可计算时，Monte Carlo 近似值未必保留原有公平公理，估值排名本身具有随机误差。 方法：论文把精确公平推广为 probably approximate Shapley fairness，定义 fidelity score 衡量估计波动，并用 greedy active estimation 最大化最低 fidelity。 结论：理论和多种真实 ML 场景实验显示 GAE 比常规 Monte Carlo 更能保证近似公平，同时保持有竞争力的估计准确度。

## 批判性小综述

对该研究的证据边界判断：它解决估值近似的公平/方差，不验证被高估值样本训练后是否有益；Shapley 的 coalition 目标与 Stage1 动态 replay 成本很高。 反向约束：不能由 fidelity 高推出 TN_at_FN95 utility 高，也不能把近似公平当作跨 seed 稳定改善。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ7；其可迁移链条是：Stage1 若试验 Data Shapley，必须同时报告估值不确定性、重复抽样与排名稳定性，不能输出一个无误差条的静态 value。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 若试验 Data Shapley，必须同时报告估值不确定性、重复抽样与排名稳定性，不能输出一个无误差条的静态 value。 禁止外推：不能由 fidelity 高推出 TN_at_FN95 utility 高，也不能把近似公平当作跨 seed 稳定改善。
