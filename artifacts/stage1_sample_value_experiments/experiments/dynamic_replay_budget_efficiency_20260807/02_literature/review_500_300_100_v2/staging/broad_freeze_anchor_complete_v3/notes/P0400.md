# P0400 - A Study on Training Data Selection Method for EEG Emotion Analysis using Machine Learning Algorithm

## 独立中文摘要

问题：EEG 情感模型的收敛和识别率依赖训练数据配置，有限通道与主观标签使训练集选择成为独立变量。 方法：论文从 DEAP 的 FP1、FP2 通道提取 FFT 功率谱，并按 Valence 和 Arousal 选择训练数据，比较 ANN、KNN 和 SVM。 结论：作者将实验用于分析不同训练数据集合对三类情感分类模型的影响。

## 批判性小综述

对该研究的证据边界判断：它直接改变训练集合但摘要缺少随机匹配、预算、seed 和具体结果，证据强度较弱，只适合 broad 候选。 反向约束：不能从 EEG 自评坐标选择推断图像可学习性，也不能在缺少结果定位时声称其方法有效。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5；其可迁移链条是：Stage1 可借鉴在类别外增加状态或来源分层，但必须用更严格的同预算随机和配对 seed。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴在类别外增加状态或来源分层，但必须用更严格的同预算随机和配对 seed。 禁止外推：不能从 EEG 自评坐标选择推断图像可学习性，也不能在缺少结果定位时声称其方法有效。
