# P0015 - Learning with Noisy Labels Revisited: A Study Using Real-World Human Annotations

## 独立中文摘要

问题：论文研究合成标签噪声是否能代表真实人工标注噪声，并建立可用于检验噪声鲁棒学习的数据与诊断。 方法：作者发布 CIFAR-10N 与 CIFAR-100N 多标注版本，比较真实噪声和合成噪声的类别、实例、难度与记忆动态，并复测多种鲁棒训练方法。 结论：五次运行结果显示人工噪声具有更强实例与特征依赖、类别不均衡和不同记忆轨迹，多种在合成噪声有效的方法在真实噪声下排名变化。

## 批判性小综述

对该研究的证据边界判断：该研究提供噪声机制与训练动态证据，但没有把筛出的样本按固定 replay 预算重新加入，也没有 FN95 局部目标。 反向约束：不能把高 loss、低 AUM 或频繁遗忘直接判为错标签，也不能推出过滤这些样本必然改善 Stage1。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ8；其可迁移链条是：可迁移的是 Q 必须利用全轨迹、跨标注或跨模型一致性并保留 hard-clean 类型，不能用一种合成翻转假设替代真实审查。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是 Q 必须利用全轨迹、跨标注或跨模型一致性并保留 hard-clean 类型，不能用一种合成翻转假设替代真实审查。 禁止外推：不能把高 loss、低 AUM 或频繁遗忘直接判为错标签，也不能推出过滤这些样本必然改善 Stage1。
