# P0327 - Data-efficient flood depth prediction through domain-aware coreset selection and tabular foundation models

## 独立中文摘要

问题：跨流域洪深代理需要海量网格训练行且外推困难，随机小子集可能漏掉稀有风暴和关键空间。 方法：管线按重现期和受影响流域分层风暴，再用目标感知空间选择器抽取六边形，供表格基础模型推理。 结论：仅用每流域百分之零点七训练池，九个流域平均 R2 达监督参考的百分之九十八点五，并能迁移未见流域。

## 批判性小综述

对该研究的证据边界判断：目标感知 selector 和预训练基础模型共同贡献；2026 预印本及极小预算结果需核验随机方差。 反向约束：不能把空间六边形覆盖迁移为视频帧配额，也不能由 R2 保持推出 FN 约束。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ7,RQ8；其可迁移链条是：可支持按 tail severity 与 source domain 双重分层的 D 设计，并测试极低 replay cap。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可支持按 tail severity 与 source domain 双重分层的 D 设计，并测试极低 replay cap。 禁止外推：不能把空间六边形覆盖迁移为视频帧配额，也不能由 R2 保持推出 FN 约束。
