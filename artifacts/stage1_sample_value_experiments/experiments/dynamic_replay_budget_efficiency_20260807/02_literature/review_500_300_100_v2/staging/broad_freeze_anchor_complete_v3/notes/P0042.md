# P0042 - Adaptive Second Order Coresets for Data-efficient Machine Learning

## 独立中文摘要

问题：一阶 coreset 未考虑损失曲率，可能无法近似全量数据上的真实参数更新。 方法：AdaCore 以指数滑动 Hessian 估计动态近似曲率，选择加权子集来匹配 Hessian 预条件后的全梯度，并给出收敛保证。 结论：作者报告在 logistic regression 和神经网络上较全量训练加速超过 2.9 倍、较随机子集超过 4.5 倍。

## 批判性小综述

对该研究的证据边界判断：它说明方向应考虑模型局部曲率而非裸余弦，但 Hessian 近似昂贵且优化近似不保证泛化或 FN95。 反向约束：不能把梯度匹配误写成业务效用，也不能由收敛定理推出跨 seed 稳压随机。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：Stage1 可在小候选池比较 head-gradient 与低秩曲率预条件对齐，先估计算力再决定是否晋级。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可在小候选池比较 head-gradient 与低秩曲率预条件对齐，先估计算力再决定是否晋级。 禁止外推：不能把梯度匹配误写成业务效用，也不能由收敛定理推出跨 seed 稳压随机。
