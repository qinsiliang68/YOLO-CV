# P0162 - Data Pruning via Moving-one-Sample-out

## 独立中文摘要

问题：高损失、entropy、forgetting 或梯度范数会把噪声与真正重要样本混在一起，收敛终点分数也忽略训练阶段。 方法：MoSo 以移除单样本对最优经验风险的影响定义重要性，并用多个训练阶段中样本梯度与全体平均梯度持续一致性做一阶近似。 结论：作者报告在 CIFAR-100、Tiny-ImageNet 和 ImageNet-1K 高剪枝率下缓解性能下降，并具跨架构与噪声鲁棒性。

## 批判性小综述

对该研究的证据边界判断：目标是保留全局经验风险而非独立 FN95 尾部；平均训练梯度同向可能保护多数模式，却伤害少数缺陷尾部，剪枝也不等于 replay。 反向约束：不能由与全梯度一致推出与业务目标一致，也不能在没有真实 replay 干预时称高 MoSo 样本有正价值。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ4,RQ7；其可迁移链条是：Stage1 可把跨 checkpoint 梯度方向一致性作为 A 的候选字段，但目标梯度应换成独立 FN95 critical set，并与 gradient norm 和负对齐作析因。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把跨 checkpoint 梯度方向一致性作为 A 的候选字段，但目标梯度应换成独立 FN95 critical set，并与 gradient norm 和负对齐作析因。 禁止外推：不能由与全梯度一致推出与业务目标一致，也不能在没有真实 replay 干预时称高 MoSo 样本有正价值。
