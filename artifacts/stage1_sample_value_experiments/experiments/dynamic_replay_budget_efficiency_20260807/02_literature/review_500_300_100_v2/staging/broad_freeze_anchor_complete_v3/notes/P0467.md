# P0467 - Denoising Neural Machine Translation Training with Trusted Data and Online Data Selection

## 独立中文摘要

问题：大规模平行语料含严重噪声，静态域相关性或 confidence 不能充分表示训练过程中数据质量。 方法：方法用小规模 trusted data 比较模型对样本的相对拟合，并通过在线 data-selection curriculum 动态改变训练数据。 结论：内在和外在评估均显示在重噪声 NMT 上有显著效果，优于传统域选择与基线。

## 批判性小综述

对该研究的证据边界判断：trusted data 的定义、语言生成损失和噪声结构与 Stage1 不同；在线选择还会改变优化路径和累计曝光。 反向约束：不能把可信集差分称为 Bayes 可约损失，也不能忽略 matched-random 与总预算控制。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ4,RQ5,RQ6,RQ7；其可迁移链条是：Stage1 可用独立 val_target/OOF reference 构造 R/Q，并严格记录每轮实际曝光与时间表。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可用独立 val_target/OOF reference 构造 R/Q，并严格记录每轮实际曝光与时间表。 禁止外推：不能把可信集差分称为 Bayes 可约损失，也不能忽略 matched-random 与总预算控制。
