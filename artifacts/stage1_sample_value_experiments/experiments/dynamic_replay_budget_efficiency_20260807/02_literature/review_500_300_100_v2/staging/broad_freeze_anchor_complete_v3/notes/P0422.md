# P0422 - Understanding Black-box Predictions via Influence Functions

## 独立中文摘要

问题：传统深度模型难以解释某个训练样本对特定测试预测和验证损失的方向性影响。 方法：论文用经典 influence function 近似上调或移除训练样本对参数和目标预测的影响，并用于调试错误与攻击分析。 结论：实验展示该近似可定位有害训练点、解释预测并构造训练集攻击。

## 批判性小综述

对该研究的证据边界判断：方法依赖局部二阶近似、Hessian 逆向量积和优化收敛假设；影响估计本身不是 replay 干预结果。 反向约束：不能把大 influence、梯度范数或对单个 probe 的作用直接称为跨 seed 高价值。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ3,RQ4,RQ7；其可迁移链条是：Stage1 的 A 必须相对于独立 FN95 局部目标定义，并通过实际加权或回流验证其符号与大小。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 A 必须相对于独立 FN95 局部目标定义，并通过实际加权或回流验证其符号与大小。 禁止外推：不能把大 influence、梯度范数或对单个 probe 的作用直接称为跨 seed 高价值。
