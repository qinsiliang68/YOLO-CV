# P0289 - Prioritized Training on Points that are Learnable, Worth Learning, and Not Yet Learnt

## 独立中文摘要

问题：高 loss 样本可能是噪声或任务无关，低 loss 样本又可能已经学会，两端都浪费有限训练预算。 方法：RHO-LOSS 以当前模型 loss 减去独立 holdout loss model 的参考损失，近似样本对泛化损失的可约部分并在线优先训练。 结论：作者报告跨 MLP、CNN、BERT 和多数据集少步训练并提高精度，Clothing-1M 少十八倍步数且最终精度高两个百分点。

## 批判性小综述

对该研究的证据边界判断：这是 R 的核心文献，但原方法用独立 holdout model 和候选 batch 在线选择；OOF late loss 的离线全局 replay 只是受启发适配。 反向约束：不能把 OOF reference 称 Bayes irreducible loss，也不能在缺 current checkpoint 时静默回退 slow-learning proxy。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ6,RQ7；其可迁移链条是：Stage1 必须区分 current loss、OOF-reference loss 和差值，并用 current-loss 对照检验参考扣除项的增量。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 必须区分 current loss、OOF-reference loss 和差值，并用 current-loss 对照检验参考扣除项的增量。 禁止外推：不能把 OOF reference 称 Bayes irreducible loss，也不能在缺 current checkpoint 时静默回退 slow-learning proxy。
