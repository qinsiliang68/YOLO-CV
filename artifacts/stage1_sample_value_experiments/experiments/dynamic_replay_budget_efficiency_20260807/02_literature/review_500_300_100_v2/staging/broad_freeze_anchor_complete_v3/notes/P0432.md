# P0432 - Asymmetric Co-teaching with Multi-view Consensus for Noisy Label Learning

## 独立中文摘要

问题：双模型 co-teaching 很快收敛到相同 clean 子集，small-loss 选择又会把已记忆噪声当 clean，形成确认偏差。 方法：AsyCo 用多类与多标签两种不对称训练维持预测分歧，再以训练标签和模型预测的多视图共识划分 clean/noisy 并重标。 结论：合成和真实噪声数据上作者报告超过所列先进方法。

## 批判性小综述

对该研究的证据边界判断：多视图共识依赖两套监督与重标策略，不能隔离样本选择贡献；摘要来源不支持跨 seed 细节。 反向约束：不能把一致性高直接等同值得 replay，也不能从 noisy-label 平均准确率推断 FN95 方向。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4；其可迁移链条是：Stage1 可将不同模型视角一致性作为 Q 字段，并监控候选池是否随 epoch 过快塌缩。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将不同模型视角一致性作为 Q 字段，并监控候选池是否随 epoch 过快塌缩。 禁止外推：不能把一致性高直接等同值得 replay，也不能从 noisy-label 平均准确率推断 FN95 方向。
