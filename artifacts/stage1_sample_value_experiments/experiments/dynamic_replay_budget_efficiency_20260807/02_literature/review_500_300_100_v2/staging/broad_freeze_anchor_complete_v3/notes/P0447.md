# P0447 - RCAP: Robust, Class-Aware, Probabilistic Dynamic Dataset Pruning

## 独立中文摘要

问题：动态 pruning 在高压缩率和不平衡数据上容易牺牲最差群体，单一全局比例会造成类别覆盖不足。 方法：RCAP 每 epoch 用类别聚合 loss 闭式估计各类保留比例，再以概率采样优先保留高 loss 样本。 结论：作者在六个数据集、五类模型和三种训练范式下报告较好 worst-group accuracy 与加速。

## 批判性小综述

对该研究的证据边界判断：类配额与高 loss 采样共同变化，且 2026 预印本需要核查随机基线、seed 和高压缩例外。 反向约束：不能从 worst-group pruning 直接得到 replay 最优比例，也不能把聚合 loss 当单样本效用。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5,RQ6,RQ7；其可迁移链条是：Stage1 可把动态 cap 拆成类别覆盖配额与 R 排序两个独立因素，并报告弱 defect 最差组。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把动态 cap 拆成类别覆盖配额与 R 排序两个独立因素，并报告弱 defect 最差组。 禁止外推：不能从 worst-group pruning 直接得到 replay 最优比例，也不能把聚合 loss 当单样本效用。
