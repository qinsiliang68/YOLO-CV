# P0130 - Reducing annotation effort in agricultural data: simple and fast unsupervised coreset selection with DINOv2 and K-means

## 独立中文摘要

问题：有限标注预算下，随机子集可能漏掉少数类别或类内外观模式，需要在特征空间覆盖完整变异。 方法：方法冻结 DINOv2 提取 embedding，用 K-means 形成与目标 coreset 大小相关的簇并取代表样本，与同规模随机缩减在农业和花卉数据上比较。 结论：较小 coreset 时方法普遍优于随机；Flowers 10% 数据的示例从随机 F1 0.67 提升到 0.75，并展示覆盖白色花等随机遗漏模式。

## 批判性小综述

对该研究的证据边界判断：这是减少训练集和标注成本，不是基础集全保留后的 replay；实验 seed 与严格 matched-random 细节不足以支持稳定优越性。 反向约束：不能据此断言 DINOv2 embedding 是 CCTV 缺陷语义的正确距离，也不能推出覆盖优于方向性或可靠性。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ7；其可迁移链条是：Stage1 应把视频、管段、duplicate group 与 embedding cluster coverage 作为 D 层集合产物，并与同分数 Top-K 和 global random 对照。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应把视频、管段、duplicate group 与 embedding cluster coverage 作为 D 层集合产物，并与同分数 Top-K 和 global random 对照。 禁止外推：不能据此断言 DINOv2 embedding 是 CCTV 缺陷语义的正确距离，也不能推出覆盖优于方向性或可靠性。
