# P0225 - Evolutionary Multiobjective Change Detection via Self-paced Learning and Fuzzy Clustering

## 独立中文摘要

问题：多目标模糊聚类评估 offspring 成本高，而训练代理回归器又缺少可靠样本。 方法：方法用 self-paced learning 逐步收集可靠训练样本来拟合回归代理，再由代理筛选多目标优化候选。 结论：三套遥感变化检测数据上作者报告准确率和鲁棒性超过所列方法。

## 批判性小综述

对该研究的证据边界判断：样本服务于进化算法代理而非最终图像分类器，选择可靠性与优化搜索紧密耦合；只有元数据级证据。 反向约束：不能把代理训练的可靠样本等同高召回 replay 样本，也不能迁移其 self-paced 阈值。
