# P0285 - How to measure uncertainty in uncertainty sampling for active learning

## 独立中文摘要

问题：论文追问主动学习中总不确定性、认知不确定性和偶然不确定性分别会选到什么样的样本以及何时有效。 方法：作者实例化多种概率与集合预测不确定性度量，在相同主动学习流程中比较其采样行为和实验性能。 结论：实验表明不同不确定性来源产生不同选择结果，显式分解并不在所有数据或阶段一致占优，度量选择依赖任务条件。

## 批判性小综述

对该研究的证据边界判断：它为 reducible 与 irreducible 分离提供直接概念依据，也提醒不确定性本身不是价值；主动标注仍不同于已有标签样本的额外曝光。 反向约束：不能把 epistemic uncertainty 直接等同于可回流收益，也不能从主动学习标注效率推出固定训练预算下的 replay 因果效应。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ4,RQ7；其可迁移链条是：Stage1 应把 current loss 与 OOF reference loss 分开记录，并设 current-loss 对照以检验 RHO 差值是否真有增量。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应把 current loss 与 OOF reference loss 分开记录，并设 current-loss 对照以检验 RHO 差值是否真有增量。 禁止外推：不能把 epistemic uncertainty 直接等同于可回流收益，也不能从主动学习标注效率推出固定训练预算下的 replay 因果效应。
