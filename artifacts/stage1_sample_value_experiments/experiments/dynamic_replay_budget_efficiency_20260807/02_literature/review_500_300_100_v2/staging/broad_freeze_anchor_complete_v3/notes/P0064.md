# P0064 - Navigating Towards Fairness with Data Selection

## 独立中文摘要

问题：不可靠标签会产生群体偏差，修改模型结构的公平方法难以在大数据上灵活部署。 方法：方法以 zero-shot predictor 模拟 clean holdout，并结合 peer predictions 选择训练数据而无需额外 holdout。 结论：作者报告跨数据集改善公平性且保持模态无关。

## 批判性小综述

对该研究的证据边界判断：目标效用是公平而非 FN95；zero-shot proxy 和 peer prediction 的可靠性依赖外部模型。 反向约束：不能把公平提升解释为总体样本效用，也不能引入未冻结外部模型而破坏实验身份。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ4,RQ5；其可迁移链条是：Stage1 可借鉴无需共享训练样本的 proxy-Q 思路，但正式 R/A 必须由 OOF 与独立 val_target 定义。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴无需共享训练样本的 proxy-Q 思路，但正式 R/A 必须由 OOF 与独立 val_target 定义。 禁止外推：不能把公平提升解释为总体样本效用，也不能引入未冻结外部模型而破坏实验身份。
