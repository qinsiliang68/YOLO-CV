# P0024 - Meta Label Correction for Noisy Label Learning

## 独立中文摘要

问题：实例重权重只能调节错标样本的强度，无法利用输入与原标签关系直接修复监督目标。 方法：MLC 把标签校正网络作为 meta-model，在双层优化中用 clean meta signal 生成校正标签，主模型再利用这些标签训练；论文直接比较 reweighting 与 correction。 结论：图像识别和文本分类的多种噪声类型/比例中，MLC 超过既有方法，并显示标签校正可弥补纯 reweighting 的限制。

## 批判性小综述

对该研究的证据边界判断：收益来自标签变化而非样本是否值得额外学习；meta set 的代表性与潜在泄漏决定结论，且没有有限 replay 对照。 反向约束：不能由 MLC 推出高 loss 样本是错标，也不能把 meta-gradient 权重解释为照片固有价值。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ4；其可迁移链条是：Stage1 可把高风险样本的 Q 结果分成保留、降权、人工复核，而非只做选或不选；但正式主线先不自动改标签。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把高风险样本的 Q 结果分成保留、降权、人工复核，而非只做选或不选；但正式主线先不自动改标签。 禁止外推：不能由 MLC 推出高 loss 样本是错标，也不能把 meta-gradient 权重解释为照片固有价值。
