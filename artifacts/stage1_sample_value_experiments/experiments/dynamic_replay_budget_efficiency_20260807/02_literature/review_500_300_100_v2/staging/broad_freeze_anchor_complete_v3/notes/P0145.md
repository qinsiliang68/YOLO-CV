# P0145 - Identifying Mislabeled Data using the Area Under the Margin Ranking

## 独立中文摘要

问题：过参数网络最终可记忆错标，单一终点 loss 难区分含糊、错标和干净样本，需要利用整个训练过程。 方法：AUM 累积真类 logit 与最高其他类 logit 的 margin，并加入人为错标 threshold samples 学习判别阈值，再移除低 AUM 样本。 结论：作者报告 WebVision50 移除百分之十七数据使测试错误率绝对下降一点六个百分点，CIFAR-100 移除百分之十三下降一点二个百分点。

## 批判性小综述

对该研究的证据边界判断：低 AUM 是噪声筛查证据而非正向 replay 效用；人为 threshold class 和多类 margin 在二分类 CCTV 中需重新定义，数据删除改变训练量。 反向约束：不能把低 AUM 全部删除或认定有害，也不能由清洗后平均准确率改善推出 FN95 安全前沿改善。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ7；其可迁移链条是：Stage1 可把 AUM、threshold crossing 和持续低 margin 纳入 Q 分型，明确 hard-clean 与疑似不可学尾部，再做同预算回流验证。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 AUM、threshold crossing 和持续低 margin 纳入 Q 分型，明确 hard-clean 与疑似不可学尾部，再做同预算回流验证。 禁止外推：不能把低 AUM 全部删除或认定有害，也不能由清洗后平均准确率改善推出 FN95 安全前沿改善。
