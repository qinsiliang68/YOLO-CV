# P0157 - Unsupervised feature selection via self-paced learning and low-redundant regularization

## 独立中文摘要

问题：论文研究无监督特征选择中噪声、冗余和不合理样本学习顺序造成的鲁棒性下降。 方法：SPLR 以当前重构损失给样本软权重，随年龄参数逐步纳入复杂样本，并联合子空间、局部流形和低冗余特征正则。 结论：九个数据集的聚类实验和收敛分析显示组合目标优于多数特征选择基线，但不同数据集并非全部占优。

## 批判性小综述

对该研究的证据边界判断：主要干预对象是特征而非有限预算训练照片，且样本课程与多个正则项耦合，没有同预算随机 replay。 反向约束：不能把该方法当作样本 replay 复现，也不能从聚类准确率推出 FN95 收益。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ5；其可迁移链条是：可迁移的是软门控优于硬阈值的候选思想，以及在 D 层显式惩罚冗余而非只排最高困难度。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是软门控优于硬阈值的候选思想，以及在 D 层显式惩罚冗余而非只排最高困难度。 禁止外推：不能把该方法当作样本 replay 复现，也不能从聚类准确率推出 FN95 收益。
