# P0367 - S-OHEM: Stratified Online Hard Example Mining for Object Detection

## 独立中文摘要

问题：普通 OHEM 将分类、定位及不同类别损失等权混合，忽略各损失分布随训练变化对 hard proposal 构成的影响。 方法：S-OHEM 在在线高损失 proposal 中做分层抽样，以不同损失类型和分布控制样本构成。 结论：VOC 与 KITTI 上作者报告相对 OHEM 小幅但一致的 AP/mAP 改善。

## 批判性小综述

对该研究的证据边界判断：检测 proposal 在一张图内大量相关，且提升幅度有限；分层和 hard mining 同时变化，未证明最难样本本身有价值。 反向约束：不能由 proposal AP 提升推断整图 replay 能改善 FN95，也不能省略全局和 matched random。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ5,RQ6；其可迁移链条是：可支持 D/分层覆盖优于纯 high-loss Top-K 的假设，并把损失类型、类别和来源组成写入 exposure ledger。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可支持 D/分层覆盖优于纯 high-loss Top-K 的假设，并把损失类型、类别和来源组成写入 exposure ledger。 禁止外推：不能由 proposal AP 提升推断整图 replay 能改善 FN95，也不能省略全局和 matched random。
