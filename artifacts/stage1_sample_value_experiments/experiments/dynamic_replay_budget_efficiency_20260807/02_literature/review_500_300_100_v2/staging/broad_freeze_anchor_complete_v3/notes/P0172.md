# P0172 - ToReMi: Topic-Aware Data Reweighting for Dynamic Pre-Training Data Selection

## 独立中文摘要

问题：只用总体质量或固定域混合比例会忽略训练样本之间的语义联系以及同一域内部质量差异。 方法：ToReMi 采用两阶段框架，根据主题关联和观察到的学习模式动态调整训练样本权重。 结论：作者报告多个预训练域上更快降低困惑度，并改善下游能力，相对常规预训练选择方法表现更好。

## 批判性小综述

对该研究的证据边界判断：它支持模型状态、主题覆盖和动态权重共同决定样本曝光；具体权重更新、总 token 预算和随机对照需全文筛读。 反向约束：不能把文本主题权重直接变成图像 replay 概率，也不能由困惑度下降推断高召回尾部改善。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5,RQ6；其可迁移链条是：Stage1 可将视频或特征簇视为主题，在固定累计曝光下按簇内 R 更新概率，并保留跨簇覆盖。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将视频或特征簇视为主题，在固定累计曝光下按簇内 R 更新概率，并保留跨簇覆盖。 禁止外推：不能把文本主题权重直接变成图像 replay 概率，也不能由困惑度下降推断高召回尾部改善。
