# P0295 - Enhancing Sample Selection Against Label Noise by Cutting Mislabeled Easy Examples

## 独立中文摘要

问题：错标样本的伤害并不只集中在高 loss 尾部，早期被模型正确预测的错标 easy examples 也可能特别有害。 方法：Early Cutting 用后期模型状态重新校准早期置信子集，移除早期误导性地被视为干净的 MEE。 结论：作者在 CIFAR、WebVision 和 ImageNet-1k 上报告减少 MEE 并改善样本选择与模型性能。

## 批判性小综述

对该研究的证据边界判断：该结果否定简单的低损失等于可靠；方法依赖已知噪声实验和后期状态，需检查真实标签噪声及 seed。 反向约束：不能把早期正确或低 loss 自动视为干净，也不能从过滤效果推断剩余样本适合高倍率 replay。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ7；其可迁移链条是：Stage1 的 Q 层要联合早晚轨迹、参考损失和邻域一致性，保留 mislabeled-easy 负对照。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 Q 层要联合早晚轨迹、参考损失和邻域一致性，保留 mislabeled-easy 负对照。 禁止外推：不能把早期正确或低 loss 自动视为干净，也不能从过滤效果推断剩余样本适合高倍率 replay。
