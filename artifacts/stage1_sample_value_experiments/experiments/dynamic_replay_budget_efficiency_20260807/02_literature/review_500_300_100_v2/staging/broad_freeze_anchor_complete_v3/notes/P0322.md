# P0322 - Improved Multi-Person 2D Human Pose Estimation Using Attention Mechanisms and Hard Example Mining

## 独立中文摘要

问题：姿态网络对手腕、脚踝等灵活关节点误差较大，平均所有关节点损失会稀释这些局部困难信号。 方法：作者在最后两个 refinement stage 中按关节点 heatmap loss 排序，只汇总每图最高的八个关节点损失，同时加入 SE-ResNet attention。 结论：组合方法在 COCO 上报告 AP 60.0，并在遮挡和灵活关节点示例中优于所比较网络；作者称 hard-joint mining 改善困难部位预测。

## 批判性小综述

对该研究的证据边界判断：干预单位是同一图像内部的关节点而非训练图片，且 attention 与 hard mining 同时改变；没有严格同预算随机关节点对照。 反向约束：不能由 AP 提升推断高 loss 图片可学习，更不能证明该方案在 FN95 尾部或跨 seed 稳定。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2；其可迁移链条是：Stage1 只能把它作为局部困难单元重加权的历史证据，并据此设置 Grad-Mag 与 Random 的消融，不能直接采用 top-loss 图片回流。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 只能把它作为局部困难单元重加权的历史证据，并据此设置 Grad-Mag 与 Random 的消融，不能直接采用 top-loss 图片回流。 禁止外推：不能由 AP 提升推断高 loss 图片可学习，更不能证明该方案在 FN95 尾部或跨 seed 稳定。
