# P0320 - Self-Paced Learning for Neural Machine Translation

## 独立中文摘要

问题：手工句长或词频课程依赖任务特征，不能随 NMT 模型实际掌握程度调整。 方法：方法让模型自动估计训练例学习置信，并在每步通过 loss 调节从易到难的学习。 结论：作者在多个翻译任务报告优于强基线和人工课程，提升翻译质量与收敛速度。

## 批判性小综述

对该研究的证据边界判断：它支持 current-state self-paced，但 model confidence 容易自我确认，随机探索和总 token 曝光需筛读。 反向约束：不能把翻译置信度直接等同 OOF reducibility，也不能由收敛快断言最终 FN95 更好。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6；其可迁移链条是：Stage1 可将动态分数转为软采样概率并保留 epsilon random，而非确定性 Top-K。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将动态分数转为软采样概率并保留 epsilon random，而非确定性 Top-K。 禁止外推：不能把翻译置信度直接等同 OOF reducibility，也不能由收敛快断言最终 FN95 更好。
