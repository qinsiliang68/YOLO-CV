# P0269 - MSPL: Multimodal Self-Paced Learning for Multi-Omics Feature Selection and Data Integration

## 独立中文摘要

问题：多组学数据维度高、样本少、模态异质且噪声重，直接联合训练容易受不可靠样本和特征支配。 方法：MSPL 在监督多模态整合中联合优化特征选择、分类与 self-paced 样本权重，并利用跨组学相关信息交互推荐高置信样本进入训练。 结论：模拟数据和五套多组学数据上，self-paced 版本在二分类与多分类中通常优于不含该组件的整合方法，并识别候选生物特征。

## 批判性小综述

对该研究的证据边界判断：样本权重与特征选择、模态融合同时改变，数据规模很小且任务目标不同；不能把高置信进入顺序看作 replay 因果证据。 反向约束：不能把多组学相关性或其 pace 参数迁移到视觉 OOF，也不能推出高置信样本具有剩余可学习性。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6；其可迁移链条是：Stage1 可借鉴 Q 门控与训练 pace 联动，但必须拆开 feature selection 与 sample scheduling，并保留所有基础样本曝光。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴 Q 门控与训练 pace 联动，但必须拆开 feature selection 与 sample scheduling，并保留所有基础样本曝光。 禁止外推：不能把多组学相关性或其 pace 参数迁移到视觉 OOF，也不能推出高置信样本具有剩余可学习性。
