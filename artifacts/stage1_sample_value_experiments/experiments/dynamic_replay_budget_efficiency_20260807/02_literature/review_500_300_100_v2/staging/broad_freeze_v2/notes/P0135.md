# P0135 - MODE: Multi-Objective Adaptive Coreset Selection

## 独立中文摘要

问题：静态 coreset 准则忽略了训练阶段变化：早期类平衡、中期表征覆盖和后期不确定性的价值可能不同。 方法：MODE 动态组合多个集合选择目标，随阶段调整 class balance、diversity 与 uncertainty 的权重，并给出近似保证。 结论：作者声称在降低内存时保持竞争精度，并提供数据效用随训练演化的可解释画像。

## 批判性小综述

对该研究的证据边界判断：摘要信息不完整，尚不能核实所有随机基线、seed 和预算公平性；多目标权重也可能引入新的任意性。 反向约束：不能由近似集合目标保证业务泛化，也不能把阶段权重直接设成 Stage1 公式。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ3,RQ5,RQ6；其可迁移链条是：Stage1 可据此预注册阶段化单机制切换，但应避免拟合一组自由权重，先做可证伪的分段策略。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。
