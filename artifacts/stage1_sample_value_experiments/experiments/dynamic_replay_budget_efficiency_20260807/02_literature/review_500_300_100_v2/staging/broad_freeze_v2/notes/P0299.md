# P0299 - MATES: Model-Aware Data Selection for Efficient Pretraining with Data Influence Models

## 独立中文摘要

问题：静态规则和大型参考模型无法跟随预训练模型随阶段变化的数据偏好。 方法：MATES 局部探测当前预训练模型得到 oracle influence，训练小型 influence model 近似，再为全语料预测并选择下一训练阶段数据。 结论：作者在 C4 上训练 410M 和 1B 模型时报告显著优于随机，较大型参考模型方法增益翻倍并减少达到目标性能的 FLOPs。

## 批判性小综述

对该研究的证据边界判断：它是 state-conditioned utility 加代理蒸馏的直接干预证据，但局部 probe 定义、累计 token 预算和跨 seed 稳定性需精读。 反向约束：不能把 influence model 输出视为因果真值，也不能使用 val_op 或 test 生成 probe 标签。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ3,RQ6,RQ7；其可迁移链条是：Stage1 可在小型候选池做真实一步 probe 训练 A/R 代理，再用大池在线筛选，并完整记录阶段与成本。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可在小型候选池做真实一步 probe 训练 A/R 代理，再用大池在线筛选，并完整记录阶段与成本。 禁止外推：不能把 influence model 输出视为因果真值，也不能使用 val_op 或 test 生成 probe 标签。
