# P0137 - AudioDER: A Deduplication-Enhanced Reasoning Dataset for Post-Training Large Audio-Language Models

## 独立中文摘要

问题：多个公开音频数据源存在重叠媒体和近重复声学模式，盲目增加数据量会造成重复曝光与收益递减。 方法：AudioDER 先做声学去重，再统一为多项选择与推理格式，最后做质量校验；保留数据训练 Qwen2-Audio，并与未过滤原始集和同规模随机子集比较。 结论：约 286k 样本的 AudioRE 在多类音频理解基准上超过使用更多未过滤数据的模型，表中明确将随机基线做成与 AudioRE 同规模。

## 批判性小综述

对该研究的证据边界判断：格式转换、CoT 生成、质量过滤与去重共同改变，不能把收益只归因于重复率；音频相似也不等于 CCTV 视频近重复。 反向约束：不能由音频去重结果推出视觉 pHash 或 embedding 阈值，也不能证明去重后的高 RHO 样本跨 seed 稳压随机。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ7；其可迁移链条是：Stage1 应把 duplicate group、视频来源、簇覆盖和重复曝光直方图作为 D 层硬约束，并用相同 unique count 的 random 检验去重价值。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应把 duplicate group、视频来源、簇覆盖和重复曝光直方图作为 D 层硬约束，并用相同 unique count 的 random 检验去重价值。 禁止外推：不能由音频去重结果推出视觉 pHash 或 embedding 阈值，也不能证明去重后的高 RHO 样本跨 seed 稳压随机。
