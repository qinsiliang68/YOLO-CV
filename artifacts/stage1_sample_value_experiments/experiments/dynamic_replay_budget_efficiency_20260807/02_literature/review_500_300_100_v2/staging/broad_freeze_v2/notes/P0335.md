# P0335 - Continual Safety Alignment via Gradient-Based Sample Selection

## 独立中文摘要

问题：大模型在良性新任务微调也可能破坏拒答、真实性等安全行为，样本对这种 drift 的贡献不相等。 方法：论文分析样本梯度，过滤导致安全退化的高梯度样本，保留中等梯度样本学习任务。 结论：多模型、任务顺序和攻击基准上作者报告保持任务表现同时显著保护安全对齐。

## 批判性小综述

对该研究的证据边界判断：它直接显示大梯度可有害，但安全目标与分类尾部不同；过滤高梯度和训练量变化需公平控制。 反向约束：不能把所有高梯度样本排除，也不能由 LLM 安全退化推断 normal/defect 的方向。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ6,RQ7；其可迁移链条是：Stage1 应测试 gradient-norm 极端尾部为风险而非价值，并用业务 target alignment 区分中等可学与强有害。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应测试 gradient-norm 极端尾部为风险而非价值，并用业务 target alignment 区分中等可学与强有害。 禁止外推：不能把所有高梯度样本排除，也不能由 LLM 安全退化推断 normal/defect 的方向。
