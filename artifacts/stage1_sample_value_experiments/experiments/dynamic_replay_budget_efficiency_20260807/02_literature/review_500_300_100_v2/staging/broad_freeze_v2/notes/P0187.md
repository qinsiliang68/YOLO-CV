# P0187 - Robust Learning for Text Classification with Multi-source Noise Simulation and Hard Example Mining

## 独立中文摘要

问题：OCR 会给下游文本引入多源真实噪声，而通常只有干净标签文本，直接人工构造带噪数据成本高。 方法：框架从干净文本模拟多种 OCR 噪声，从大量合成候选中迭代挖掘困难样本，并用 stability loss 学习噪声不变表示。 结论：三个真实数据集上作者报告明显提升预训练文本模型对 OCR 噪声的鲁棒性。

## 批判性小综述

对该研究的证据边界判断：噪声模拟、hard mining 与稳定损失同时作用，选择池是人工生成样本；没有证明原始真实 hard 样本单独优于随机。 反向约束：不能由合成 OCR hard mining 证明 CCTV 极端图像值得重复，也不能忽略生成候选数量带来的搜索优势。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6；其可迁移链条是：Stage1 可把增强/污染 seed 与样本 ID 分开审计，并测试困难样本是否只是特定增强下瞬时高损失。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把增强/污染 seed 与样本 ID 分开审计，并测试困难样本是否只是特定增强下瞬时高损失。 禁止外推：不能由合成 OCR hard mining 证明 CCTV 极端图像值得重复，也不能忽略生成候选数量带来的搜索优势。
