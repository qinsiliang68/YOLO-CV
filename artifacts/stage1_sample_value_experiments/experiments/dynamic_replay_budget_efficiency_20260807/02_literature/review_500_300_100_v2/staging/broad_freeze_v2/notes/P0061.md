# P0061 - Learn the Time to Learn: Replay Scheduling in Continual Learning

## 独立中文摘要

问题：历史数据可以存储但受计算预算限制，固定平均 replay 不能决定何时重放哪个任务。 方法：论文先用 Monte Carlo tree search 找 replay schedule，再训练强化学习策略在不同时间选择任务。 结论：作者报告学习到的时间表在多种 continual-learning 设置中优于固定均匀 replay，且不增加计算成本。

## 批判性小综述

对该研究的证据边界判断：任务级调度与固定二分类样本级回流不同，搜索/强化学习策略也可能过拟合开发场景。 反向约束：不能直接采用其调度器，也不能把持续学习抗遗忘收益解释为 FN95 提升。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ6；其可迁移链条是：Stage1 应把 timing 视为独立干预变量，先用少自由度时间表验证因果，再考虑自适应 controller。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应把 timing 视为独立干预变量，先用少自由度时间表验证因果，再考虑自适应 controller。 禁止外推：不能直接采用其调度器，也不能把持续学习抗遗忘收益解释为 FN95 提升。
