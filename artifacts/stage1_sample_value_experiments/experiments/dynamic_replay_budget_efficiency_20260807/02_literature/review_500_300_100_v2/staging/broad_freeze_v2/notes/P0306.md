# P0306 - Curriculum self-paced learning for cross-domain object detection

## 独立中文摘要

问题：源域目标检测器在新域中受域偏移影响，目标域伪标签的可靠性与难度需要随适应过程控制。 方法：框架结合 CycleGAN 源到目标转换与自步伪标签学习，按设计的难度度量从易到难吸收目标域样本，并进行组件和难度度量消融。 结论：作者在四个跨域检测基准上报告优于当时方法，并称其难度量与性能相关且优于替代难度指标。

## 批判性小综述

对该研究的证据边界判断：图像转换、伪标签、自步课程同时变化，难度相关性并非 replay 因果效用；元数据级全文不足以核验跨 seed 与预算公平性。 反向约束：不能由跨域检测结果推出当前 OOF loss 高的原始已标注图像值得重复，也不能直接映射到 FN95 局部目标。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6,RQ7；其可迁移链条是：可支持 Stage1 先做 Q 可靠性门控再研究 R，并把课程时点作为独立因素，不把伪标签不确定性混成一个总分。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可支持 Stage1 先做 Q 可靠性门控再研究 R，并把课程时点作为独立因素，不把伪标签不确定性混成一个总分。 禁止外推：不能由跨域检测结果推出当前 OOF loss 高的原始已标注图像值得重复，也不能直接映射到 FN95 局部目标。
