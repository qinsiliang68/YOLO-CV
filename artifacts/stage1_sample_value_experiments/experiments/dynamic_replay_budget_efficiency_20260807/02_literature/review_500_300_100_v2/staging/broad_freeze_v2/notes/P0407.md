# P0407 - Federated Hard Example Mining for Defect Detection Under Statistical Heterogeneity

## 独立中文摘要

问题：多产线工业缺陷数据分散且统计异质，聚合模型难兼顾全局泛化与特定类别。 方法：FedHEM 从客户端收集类原型和困难特征，并生成对应伪样本在联邦训练中传递知识。 结论：作者报告在基准和工业缺陷任务上比异质联邦方法提高超过 10% 准确率。

## 批判性小综述

对该研究的证据边界判断：hard feature mining、prototype sharing 与伪样本生成同时发生；accuracy 目标和联邦异质性与 Stage1 不同。 反向约束：不能由平均 accuracy 宣称高置信 HN 有效，也不能迁移其伪样本生成结果。
