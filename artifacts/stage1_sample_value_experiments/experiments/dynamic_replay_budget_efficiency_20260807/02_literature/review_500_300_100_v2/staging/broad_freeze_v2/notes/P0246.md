# P0246 - Multi-Label Noise Robust Collaborative Learning for Remote Sensing Image Classification

## 独立中文摘要

问题：论文研究遥感多标签中缺失标签与错误标签并存时，如何动态识别并阻止高风险标签样本污染反向传播。 方法：RCML 用两个网络学习差异表征但保持预测一致，以 group-lasso 排名损失识别两类标签噪声，再交换排序并按估计噪声率自适应排除高风险样本。 结论：两个遥感基准的三次运行和模块消融表明，高噪声下动态排名与协同交换优于随机排除和固定排除率，作者报告平均识别超过六成五噪声样本。

## 批判性小综述

对该研究的证据边界判断：噪声为人工注入的多标签翻转，评估按最佳验证 mAP 网络选择；其排除样本而非额外 replay，且没有 Stage1 式严格匹配随机集合。 反向约束：不能推出低 AUM 或高 OOF loss 就是噪声，也不能直接把多标签 ranking loss 用于二分类 CCTV。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ5；其可迁移链条是：可迁移的是 Q 门控必须动态估计风险并保留随机排除对照，固定排除百分比会在低噪声时误删大量干净样本。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是 Q 门控必须动态估计风险并保留随机排除对照，固定排除百分比会在低噪声时误删大量干净样本。 禁止外推：不能推出低 AUM 或高 OOF loss 就是噪声，也不能直接把多标签 ranking loss 用于二分类 CCTV。
