# P0489 - Constraint-Data-Value-Maximization: Utilizing Data Attribution for Effective Data Pruning in Low-Data Environments

## 独立中文摘要

问题：Shapley 类单样本值在极低保留率下简单删除低值点并非最优，因为少量测试目标可能被单一训练点过度支配。 方法：CDVM 把剪枝写成约束优化，在最大化总 influence 的同时惩罚过大的 per-test contribution。 结论：作者在 OpenDataVal 上报告低数据环境中的较强性能和有竞争力运行时间。

## 批判性小综述

对该研究的证据边界判断：它支持目标方向必须配合贡献分散和覆盖，避免少数强影响样本统治集合；新方法的稳定性需精读。 反向约束：不能把 Shapley 或 attribution 数值当因果真值，也不能由 pruning 低预算结果确定 replay repeat cap。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ3,RQ5,RQ7；其可迁移链条是：Stage1 可限制任何视频、簇或 probe 对总目标贡献的上限，并与同分数 Top-K 比较。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可限制任何视频、簇或 probe 对总目标贡献的上限，并与同分数 Top-K 比较。 禁止外推：不能把 Shapley 或 attribution 数值当因果真值，也不能由 pruning 低预算结果确定 replay repeat cap。
