# P0205 - A Negative Result on Gradient Matching for Selective Backprop

## 独立中文摘要

问题：Selective Backprop 常按 mini-batch 高 loss 决定反传样本，但缺少简单随机基线，梯度匹配是否更优并不清楚。 方法：研究用最后一层梯度近似选择加权子集，使其匹配完整 mini-batch 平均梯度，并同时加入此前缺失的随机选择对照。 结论：实验发现 loss-based 与 gradient-matching 都不能持续超过随机基线。

## 批判性小综述

对该研究的证据边界判断：这是主问题的高价值负证据；但它优化训练加速的 batch 子集，不是额外 replay，目标梯度也是全批平均而非 FN95 critical target。 反向约束：不能由该负结果否定所有目标条件梯度方向，也不能声称最后一层 alignment 必然无效。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ7；其可迁移链条是：Stage1 必须把 gradient norm、全梯度匹配、FN95 positive alignment 和 random 做同预算析因，任何 proxy 都不得先称 utility。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 必须把 gradient norm、全梯度匹配、FN95 positive alignment 和 random 做同预算析因，任何 proxy 都不得先称 utility。 禁止外推：不能由该负结果否定所有目标条件梯度方向，也不能声称最后一层 alignment 必然无效。
