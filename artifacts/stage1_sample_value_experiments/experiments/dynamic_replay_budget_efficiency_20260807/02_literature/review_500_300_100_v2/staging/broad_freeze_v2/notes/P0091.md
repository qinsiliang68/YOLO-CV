# P0091 - Rethinking Data Selection at Scale: Random Selection is Almost All You Need

## 独立中文摘要

问题：许多数据选择方法只在小候选池中验证，放大到百万级 SFT 后可能不再优于随机。 方法：论文在两个百万级数据池复现多种无需外部模型的 self-scoring 选择法，并比较随机、质量、长度和多样性。 结论：多数方法未显著胜随机；结果显示多样性比单纯高质量更关键，按 token 长度过滤是较稳定的廉价策略。

## 批判性小综述

对该研究的证据边界判断：LLM 指令微调与视觉 replay 不同，但它直接警告尺度、随机基线和覆盖优势；需核对多 seed 与预算公平。 反向约束：不能断言 random 永远足够，也不能把 token 长度迁移成图像价值指标。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ5,RQ6,RQ7；其可迁移链条是：Stage1 必须把 R1/R2 当主要对照，并优先测试 D 层是否解释旧 HN 输给随机。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。
