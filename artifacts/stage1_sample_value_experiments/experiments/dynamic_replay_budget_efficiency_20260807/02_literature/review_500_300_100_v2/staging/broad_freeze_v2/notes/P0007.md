# P0007 - A Multi-Label Classification Algorithm Based on Self-paced Learning and LDA

## 独立中文摘要

问题：固定由易到难的自步学习容易只按损失控制进入顺序，忽略类间可分性。 方法：方法把线性判别分析的信息加入 self-paced 正则或样本权重更新，使课程兼顾损失与判别结构。 结论：作者报告在分类实验中相对传统 self-paced 方法的改进。
