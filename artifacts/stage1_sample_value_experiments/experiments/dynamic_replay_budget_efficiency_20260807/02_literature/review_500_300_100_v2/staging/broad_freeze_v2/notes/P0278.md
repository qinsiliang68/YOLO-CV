# P0278 - Smartwatch-Based Eating Detection: Data Selection for Machine Learning from Imbalanced Data with Imperfect Labels

## 独立中文摘要

问题：真实腕部传感器进食数据类别极不平衡且标签不完美，直接切窗训练会产生大量无效或错误样本。 方法：方法构造专门训练数据选择流程，并融合原始与虚拟传感器模态训练深度和经典模型。 结论：十二名受试者野外数据上报告 person-independent precision 0.85、recall 0.81、F1 0.82。

## 批判性小综述

对该研究的证据边界判断：多模态融合与数据选择共同作用，样本量和跨受试者随机性有限；摘要无法隔离 selection 的边际贡献。 反向约束：不能把腕部传感窗口选择规则迁移为 CCTV 帧回流，也不能由 F1 证明 FN95 约束达标。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ5,RQ7；其可迁移链条是：可作为视频/时序事件边界、标签可靠性和个体来源分组的重要旁证，要求按 session 分割防泄漏。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可作为视频/时序事件边界、标签可靠性和个体来源分组的重要旁证，要求按 session 分割防泄漏。 禁止外推：不能把腕部传感窗口选择规则迁移为 CCTV 帧回流，也不能由 F1 证明 FN95 约束达标。
