# P0120 - A Comprehensive Empirical Evaluation on Online Continual Learning

## 独立中文摘要

问题：在线持续学习方法众多，但不同实现、预算和终点指标可能让复杂方法看似胜出。 方法：研究在 Split-CIFAR100 和 Split-TinyImageNet 统一比较多种方法，记录准确率、遗忘、稳定性及表征质量并对齐计算预算。 结论：作者发现多数方法存在稳定性和欠拟合，没有清晰赢家；正确调优的基础 ER 是非常强的基线。

## 批判性小综述

对该研究的证据边界判断：这是防止弱随机对照的关键负结果，虽是持续学习而非重复训练，公平实现原则直接可迁移。 反向约束：不能由无赢家否定所有条件性 replay，也不能把持续学习平均准确率替代安全前沿。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ6,RQ7；其可迁移链条是：Stage1 的 Random 与 no-replay 必须同 seed、顺序、augmentation、steps 和 k_t，不能把工程较弱基线当科学胜利。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 Random 与 no-replay 必须同 seed、顺序、augmentation、steps 和 k_t，不能把工程较弱基线当科学胜利。 禁止外推：不能由无赢家否定所有条件性 replay，也不能把持续学习平均准确率替代安全前沿。
