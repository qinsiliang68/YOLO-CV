# P0157 - A Class Imbalance Loss for Imbalanced Object Recognition

## 独立中文摘要

问题：类别不平衡会使多数类主导总损失和梯度，少数类在参数更新中获得不足的下降机会。 方法：论文定义 imbalance degree 并据此构造 CI loss，增加少数类相对多数类的梯度作用；在 few-shot 分类和遥感目标检测中与 CE、Focal 等比较。 结论：MiniImageNet、MNIST/MSTAR 不平衡构造和 15 类船舶检测结果均报告 CI loss 改善，说明组成失衡会改变梯度预算。

## 批判性小综述

对该研究的证据边界判断：这是类级损失重标定而非逐样本价值估计；改损失本身也会改变优化目标，不能与固定 CE 的选样效果混为一谈。 反向约束：不能据此推出 defect guard 的最佳比例，也不能把类别级重权重效果解释为某张缺陷图有高价值。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ4；其可迁移链条是：Stage1 必须记录动态队列的 normal/defect 角色和实际梯度占比，并在 weak-defect 尾部检查 normal replay 是否形成梯度支配。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 必须记录动态队列的 normal/defect 角色和实际梯度占比，并在 weak-defect 尾部检查 normal replay 是否形成梯度支配。 禁止外推：不能据此推出 defect guard 的最佳比例，也不能把类别级重权重效果解释为某张缺陷图有高价值。
