# P0121 - Data Shapley: Equitable Valuation of Data for Machine Learning

## 独立中文摘要

问题：训练数据价值应由其对给定学习算法和评价效用的边际贡献定义，而非样本自身静态属性。 方法：Data Shapley 对所有训练子集排列上的边际效用取平均，并用 Monte Carlo 与梯度近似降低估计成本。 结论：作者报告其比 leave-one-out 和 leverage 更能识别损坏/离群数据，并能指导新数据获取。

## 批判性小综述

对该研究的证据边界判断：精确计算代价极高，估值依赖学习算法、效用函数和周围样本；近似排序仍可能受 seed 方差影响。 反向约束：不能把单次近似 Shapley 当永久真值，也不能在未固定 FN95 效用时计算所谓价值。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：它为 Stage1 定义提供底线：价值是条件化集合干预效应；可先做样本族/集合级随机纳入估计。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。
