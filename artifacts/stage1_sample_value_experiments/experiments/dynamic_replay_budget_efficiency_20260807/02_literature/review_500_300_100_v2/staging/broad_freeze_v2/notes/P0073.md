# P0073 - PDAC: Efficient Coreset Selection for Continual Learning via Probability Density Awareness

## 独立中文摘要

问题：持续学习 replay buffer 很小，复杂双层 coreset 虽可选代表样本却计算昂贵，且不同区域样本对误差抑制作用不等。 方法：作者从局部误差分解分析 buffer 模型与 Bayes-optimal 模型的 MSE，主张高概率密度区域贡献更大；PDAC 用 projected GMM 估计联合密度，SPDAC 再用流式 EM 更新。 结论：多种持续学习设置中，PDAC/SPDAC 在选择效率和准确率上超过所列基线，并用高密度、均匀和低密度重采样做机制比较。

## 批判性小综述

对该研究的证据边界判断：理论目标是全局 MSE 与记忆保持，不是高召回尾部；密度高可能偏向多数容易模式，也未等于样本额外曝光的正方向。 反向约束：不能由高密度误差界推出 high-density normal 对 TN_at_FN95 有利，也不能把 continual forgetting 等同于当前 run 的剩余可学习性。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：Stage1 可增加 density-stratified random 和低密度负对照，检查覆盖中心与边界尾部在不同预算下的作用，而不把密度并入固定加权分。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可增加 density-stratified random 和低密度负对照，检查覆盖中心与边界尾部在不同预算下的作用，而不把密度并入固定加权分。 禁止外推：不能由高密度误差界推出 high-density normal 对 TN_at_FN95 有利，也不能把 continual forgetting 等同于当前 run 的剩余可学习性。
