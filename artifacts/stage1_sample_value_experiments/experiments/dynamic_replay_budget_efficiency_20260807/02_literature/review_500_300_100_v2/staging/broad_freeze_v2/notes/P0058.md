# P0058 - Cross-Platform Chinese Offensive Comment Detection via Dual-Threshold Hard Example Mining

## 独立中文摘要

问题：跨平台域偏移会使源域文本分类器退化，单一置信阈值难同时覆盖不同类型的错误候选。 方法：方法从无标签目标平台语料中按高低双阈值筛出易错候选，经少量人工标注后做二次微调，并与原始二分类基线比较。 结论：论文报告在微博、小红书、贴吧和知乎测试上以少量标注困难样本取得跨平台性能提升。

## 批判性小综述

对该研究的证据边界判断：它同时引入目标域数据、人工标签和二次微调，不能分离 hard mining 与域适配的贡献；当前为新近预印本，跨 seed 和等预算随机证据需要进一步核验。 反向约束：不能把文本双阈值直接映射成 normal q68 或 FN95 阈值，也不能声称 confidence band 已稳压同预算随机回流。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ7；其可迁移链条是：可作为阈值窗口而非单端极值选样的干预案例，并提醒 Stage1 对边界两侧候选分别记录来源域与标签可靠性。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可作为阈值窗口而非单端极值选样的干预案例，并提醒 Stage1 对边界两侧候选分别记录来源域与标签可靠性。 禁止外推：不能把文本双阈值直接映射成 normal q68 或 FN95 阈值，也不能声称 confidence band 已稳压同预算随机回流。
