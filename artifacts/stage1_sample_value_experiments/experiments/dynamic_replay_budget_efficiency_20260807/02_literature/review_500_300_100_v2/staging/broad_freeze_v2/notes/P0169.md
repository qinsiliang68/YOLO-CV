# P0169 - Accuracy Improvement by Training Data Selection in Automatic Test Cases Generation Method

## 独立中文摘要

问题：自然语言需求生成测试用例时，全部候选训练数据可能包含与目标测试不相关的信息，增加数据不一定提高准确率。 方法：方法按训练文本与测试文本的余弦相似度选样，并加入基于标准差的适用性判断，以较少训练数据寻找最高生成准确率。 结论：作者报告两种选择改进有效，并能在减少训练数据时取得最高准确率。

## 批判性小综述

对该研究的证据边界判断：公开摘要没有说明神经模型、随机重复、seed 或严格同预算基线；按测试样本相似度选训练数据也可能直接适配评估目标。 反向约束：不能由测试用例生成准确率推断 CCTV 样本可学习性，也不能在使用 test 相似度时声称无泄漏。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ7；其可迁移链条是：可作为目标条件相似性与集合预算的跨行业机制线索，但只能放在 D/目标相关候选层，并要求独立 val_target。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可作为目标条件相似性与集合预算的跨行业机制线索，但只能放在 D/目标相关候选层，并要求独立 val_target。 禁止外推：不能由测试用例生成准确率推断 CCTV 样本可学习性，也不能在使用 test 相似度时声称无泄漏。
