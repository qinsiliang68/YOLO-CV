# P0194 - Implicit Gradient Alignment in Distributed and Federated Learning

## 独立中文摘要

问题：异质客户端或 mini-batch 梯度不对齐会阻碍收敛，但 SGD 的顺序小批次又可能通过隐式正则改善泛化。 方法：论文分析顺序 SGD 如何诱导跨 batch 梯度对齐，并提出 GradAlign 在任意大 batch 下复制该隐式正则。 结论：作者在分布式和联邦学习设置中报告梯度对齐与测试精度改善。

## 批判性小综述

对该研究的证据边界判断：它说明 batch 顺序和梯度交互会改变泛化，单样本 A 不是独立可加；这里是 batch 级优化而非样本选择。 反向约束：不能由 batch gradient alignment 推断单图余弦的因果符号，也不能忽略优化器路径依赖。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ7；其可迁移链条是：Stage1 必须固定 base batch order 与 augmentation RNG，并记录 replay 插入位置，避免把顺序效应误认成样本效用。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 必须固定 base batch order 与 augmentation RNG，并记录 replay 插入位置，避免把顺序效应误认成样本效用。 禁止外推：不能由 batch gradient alignment 推断单图余弦的因果符号，也不能忽略优化器路径依赖。
