# P0167 - A CLIP-Powered Framework for Robust and Generalizable Data Selection

## 独立中文摘要

问题：大规模真实数据含冗余、噪声与损坏样本，单模态单样本分数容易误判代表性和影响。 方法：框架用 CLIP 多模态知识做数据集适配、样本评分和多目标选择优化，联合考虑质量与集合结构。 结论：作者在多套基准上报告持续超过数据选择基线，并能以更少数据去除噪声或损坏样本后提高性能。

## 批判性小综述

对该研究的证据边界判断：预训练 CLIP 带来外部知识，多目标优化的各项贡献和随机预算公平性需筛读核验；pruning 不等于 replay。 反向约束：不能由 CLIP pruning 收益推出模型自身 OOF 难样本值得回流，也不能声称多目标权重可迁移。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ5,RQ7；其可迁移链条是：可把跨模态一致性作为 Q、embedding 覆盖作为 D 的候选，但二者必须分层消融而非合成任意总分。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可把跨模态一致性作为 Q、embedding 覆盖作为 D 的候选，但二者必须分层消融而非合成任意总分。 禁止外推：不能由 CLIP pruning 收益推出模型自身 OOF 难样本值得回流，也不能声称多目标权重可迁移。
