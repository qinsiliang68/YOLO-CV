# P0041 - Accounting for Variance in Machine Learning Benchmarks

## 独立中文摘要

问题：机器学习基准结论同时受数据抽样、初始化、增强和超参数搜索方差影响，单次结果容易误判。 方法：论文系统分解常见 benchmark 的变异来源，并讨论重复、报告和比较设计。 结论：作者表明多种看似次要的随机性足以实质改变方法排序与结论。

## 批判性小综述

对该研究的证据边界判断：它不是选样算法，但直接解释同一 selection 跨 seed 反转；摘要层证据需在 300 层核对方差分解细节。 反向约束：不能从方差存在得出所有 selection 无效，也不能用更多 run 替代公平控制。

## Stage1 直接相关链

该研究直接映射到 RQ7,RQ8；其可迁移链条是：Stage1 必须配对 seed、固定 base order/augmentation RNG、报告最坏 seed 与成功比例，不能只报均值。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 必须配对 seed、固定 base order/augmentation RNG、报告最坏 seed 与成功比例，不能只报均值。 禁止外推：不能从方差存在得出所有 selection 无效，也不能用更多 run 替代公平控制。
