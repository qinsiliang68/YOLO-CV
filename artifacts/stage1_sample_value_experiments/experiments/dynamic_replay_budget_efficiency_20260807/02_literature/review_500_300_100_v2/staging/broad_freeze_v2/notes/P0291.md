# P0291 - If You Like Shapley Then You’ll Love the Core

## 独立中文摘要

问题：数据价值常默认使用 Shapley，但合作博弈还有反映联盟稳定性的 core/least-core，价值定义并不唯一。 方法：论文证明 least-core 可高效近似，同时给出 nucleolus 的不可能性，并用实验比较何时 least-core 更适合。 结论：作者用理论与实验挑战 Shapley 作为唯一数据归因准则的共识。

## 批判性小综述

对该研究的证据边界判断：它主要研究信用分配公理而非训练 replay，least-core 也依赖事先定义联盟效用。 反向约束：不能从博弈解概念直接构造可运行选样器，也不能绕过真实干预。
