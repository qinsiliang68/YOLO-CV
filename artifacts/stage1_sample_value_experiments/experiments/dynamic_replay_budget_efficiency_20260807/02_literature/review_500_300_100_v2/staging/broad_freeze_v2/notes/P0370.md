# P0370 - Remember More by Recalling Less: Investigating the Role of Batch Size in Continual Learning with Experience Replay (Student Abstract)

## 独立中文摘要

问题：论文研究持续学习中每次从记忆缓冲区回放多少样本，以及更多回放是否一定减少遗忘。 方法：作者固定缓冲区和在线批量，改变 buffer batch size，在 CIFAR、MNIST 和 mini-ImageNet 上各运行十次并检查学习率重权。 结论：大回放批量在困难数据上明显更差，简单提高回放损失权重也没有消除差异，说明曝光强度存在非单调效应。

## 批判性小综述

对该研究的证据边界判断：这是两页学生摘要，机制分析和控制变量有限，持续学习的数据分布也不同于 Stage1 的 i.i.d. 基础训练。 反向约束：不能从该实验推得 Stage1 的最佳比例，也不能把小批量优势写成普遍规律。
