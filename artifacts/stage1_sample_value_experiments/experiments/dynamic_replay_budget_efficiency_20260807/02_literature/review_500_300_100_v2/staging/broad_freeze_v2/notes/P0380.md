# P0380 - Not All Data Matters: An End-to-End Adaptive Dataset Pruning Framework for Enhancing Model Performance and Efficiency

## 独立中文摘要

问题：人工设计单一 scalar pruning score 难跨模型和数据集泛化，真实数据的冗余与偏差也会使全量训练低效。 方法：AdaPruner 联合迭代数据剪枝和模型微调，以 performance controller 直接围绕任务目标调整剪枝决策至指定比例。 结论：作者报告剪除百分之十至三十仍可提高模型表现并节省存储计算，超过所列 pruning 方法。

## 批判性小综述

对该研究的证据边界判断：端到端控制器与模型共同适配，可能过拟合开发目标；剪枝比例、训练计算和随机基线需要细查。 反向约束：不能把 controller 选择概率当作可解释 utility，也不能在没有独立 val_target/study 时用于方法选择。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ5,RQ6,RQ7；其可迁移链条是：可支持样本价值是状态条件且需由干预反馈更新，但 Stage1 第一版应采用可审计规则而非黑盒 controller。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可支持样本价值是状态条件且需由干预反馈更新，但 Stage1 第一版应采用可审计规则而非黑盒 controller。 禁止外推：不能把 controller 选择概率当作可解释 utility，也不能在没有独立 val_target/study 时用于方法选择。
