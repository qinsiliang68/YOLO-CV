# P0358 - Non-splitting Neyman-Pearson Classifiers

## 独立中文摘要

问题：Neyman-Pearson 分类要求高概率控制较严重一类错误，同时最小化另一类错误；传统阈值构造需要留出样本，降低训练效率。 方法：论文在典范 LDA 假设下推导逆样本协方差二次型函数的定量中心极限定理，据此构造不拆分训练样本的 NP 分类器。 结论：作者通过数值实验报告非拆分参数方法相对既有样本拆分 NP 分类器有优势。

## 批判性小综述

对该研究的证据边界判断：它强化了受约束错误必须带有限样本概率保证，而不是看一条经验 ROC；LDA 假设与深网分数不匹配。 反向约束：不能由非拆分 LDA 方法取消 Stage1 的独立验证角色，也不能从 NP 理论得到样本 replay 排名。

## Stage1 直接相关链

该研究直接映射到 RQ8；其可迁移链条是：Stage1 可报告 FN95 阈值的不确定性、违约概率和保守区间，并保持 val_target、val_op 与 test 角色隔离。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可报告 FN95 阈值的不确定性、违约概率和保守区间，并保持 val_target、val_op 与 test 角色隔离。 禁止外推：不能由非拆分 LDA 方法取消 Stage1 的独立验证角色，也不能从 NP 理论得到样本 replay 排名。
