# P0409 - Training data selection based on context-dependent state matching

## 独立中文摘要

问题：半监督语音只选高置信转写会牺牲音素/状态覆盖，使数据集虽干净却狭窄。 方法：方法在高置信候选上增加 context-dependent state 分布匹配，使选择集接近人工 curated development set。 结论：大规模 Voice Search 实验中，分布匹配选择优于随机选择的高置信 utterances。

## 批判性小综述

对该研究的证据边界判断：比较基线是在高置信池内随机而非全局随机；ASR 状态分布是特定结构先验。 反向约束：不能把语音状态分布或结果直接用于视频图像，也不能忽略全局 R1。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ4,RQ5；其可迁移链条是：Stage1 可构造 method-matched random：在相同 Q/R 候选池内匹配难度后比较 D 覆盖。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可构造 method-matched random：在相同 Q/R 候选池内匹配难度后比较 D 覆盖。 禁止外推：不能把语音状态分布或结果直接用于视频图像，也不能忽略全局 R1。
