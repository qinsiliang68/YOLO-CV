# P0105 - Smart Cuts: Enhance Active Learning for Vulnerability Detection by Pruning Hard-to-Learn Data

## 独立中文摘要

问题：按单一难度删数据容易保留噪声或删掉有用覆盖，需要利用训练动态地图识别不同样本区域。 方法：方法使用 confidence 与 variability 等 dataset-map 属性进行策略性 pruning，并比较随机和其他数据选择基线。 结论：作者报告过滤 hard-to-learn 区域可在减少数据时保持或改善性能。

## 批判性小综述

对该研究的证据边界判断：pruning 与 replay 的干预方向相反，且结果依赖预算和数据集；hard-to-learn 也不等于标签错误。 反向约束：不能从 pruning 成功推出被删除样本永远无价值，也不能将 map 区域当固定标签。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ3,RQ4,RQ7；其可迁移链条是：Stage1 可把长期不可学区域作为 Q 门控候选，并直接测试排除它是否使 RHO/A 选择稳定胜过随机。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把长期不可学区域作为 Q 门控候选，并直接测试排除它是否使 RHO/A 选择稳定胜过随机。 禁止外推：不能从 pruning 成功推出被删除样本永远无价值，也不能将 map 区域当固定标签。
