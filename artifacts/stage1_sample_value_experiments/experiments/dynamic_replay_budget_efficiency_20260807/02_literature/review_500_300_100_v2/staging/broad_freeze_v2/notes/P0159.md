# P0159 - In-the-Wild Model Organisms: Mitigating Undesirable Emergent Behaviors in Production LLM Post-Training via Data Attribution

## 独立中文摘要

问题：论文研究生产级偏好训练中，如何从内部激活变化追溯造成不良行为的训练对，并通过真实数据干预验证归因。 方法：方法将训练对的激活差向量与目标行为变化向量做余弦相似度排序，比较 LESS 梯度归因、LLM 评审和随机，并执行过滤、标签交换及来源模型级删除后重训。 结论：小干预时梯度法和 LLM 评审更强，规模扩大后激活法持续改善；过滤三万对将有害率降低约六成三，标签交换降低约七成八，来源级删除约八成五。

## 批判性小综述

对该研究的证据边界判断：这是少见的因果重训证据和预算分层反转，但只研究一个模型家族和一种行为；区间主要由评估样本 bootstrap 得到，未报告独立训练 seed 重复。 反向约束：不能把激活相似度直接当图像 replay 价值，也不能把 bootstrap 评估区间误写成跨初始化稳定性证据。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7,RQ8；其可迁移链条是：Stage1 可迁移目标方向归因、不同预算分别比较、负随机基线以及来源组级干预，并重点检查小预算与大预算排序是否反转。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移目标方向归因、不同预算分别比较、负随机基线以及来源组级干预，并重点检查小预算与大预算排序是否反转。 禁止外推：不能把激活相似度直接当图像 replay 价值，也不能把 bootstrap 评估区间误写成跨初始化稳定性证据。
