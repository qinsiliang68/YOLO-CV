# P0368 - Training Data Selection to Improve Multi-class Instance Segmentation in Digital Pathology

## 独立中文摘要

问题：论文研究数字病理实例分割中，等规模训练子集应依据任务结构质量还是最低像素训练损失选择。 方法：作者从二万六千余张训练图中构造两个同为一万五千余张的清理集，一个按实例级检测分类正确性筛选，另一个按低像素损失筛选，再以相同模型重新训练比较。 结论：任务结构驱动的实例正确性选择改善了组合检测分类表现，而最低训练损失选择反而低于原始全量训练，说明容易或低损失并不等于有用。

## 批判性小综述

对该研究的证据边界判断：实验有等规模干预但缺少严格随机同预算对照和多 seed，且两种选择会改变类别与形态分布，无法单独归因于可学习性。 反向约束：不能由单一病理数据集推出高损失或低损失的普遍方向，也不能把实例分割质量代理直接映射到 FN95。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6；其可迁移链条是：可迁移的是将当前 loss 与任务相关可学结果分开，并为 Stage1 设置 current-loss 对照，检验 OOF 可约项是否真有增量。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是将当前 loss 与任务相关可学结果分开，并为 Stage1 设置 current-loss 对照，检验 OOF 可约项是否真有增量。 禁止外推：不能由单一病理数据集推出高损失或低损失的普遍方向，也不能把实例分割质量代理直接映射到 FN95。
