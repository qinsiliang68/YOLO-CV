# P0190 - Coreset Selection via LLM-based Concept Bottlenecks

## 独立中文摘要

问题：训练动态剪枝需要先用全量数据训练下游模型，成本高且难解释样本究竟普遍难还是只对特定模型难。 方法：方法由大语言模型产生可解释视觉概念，训练线性 concept bottleneck 衡量图像与概念对齐难度，再按该分数分层抽样。 结论：作者报告无需先训练目标模型即可在 CIFAR 和 ImageNet 上形成优于随机、可比或优于动态方法的 coreset。

## 批判性小综述

对该研究的证据边界判断：它提供 model-agnostic difficulty 与 stratified coverage 对照，但依赖外部概念先验，概念质量和跨模型泛化需全文核验。 反向约束：不能把 LLM 概念分数称作剩余可学习性，也不能假定外部语义与 FN95 缺陷尾部一致。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5；其可迁移链条是：Stage1 可把纯 OOF 动态与冻结语义 embedding 分层并列，测试价值来自当前状态还是稳定覆盖。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把纯 OOF 动态与冻结语义 embedding 分层并列，测试价值来自当前状态还是稳定覆盖。 禁止外推：不能把 LLM 概念分数称作剩余可学习性，也不能假定外部语义与 FN95 缺陷尾部一致。
