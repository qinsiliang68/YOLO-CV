# P0012 - Beta Shapley: a Unified and Noise-reduced Data Valuation Framework for Machine Learning

## 独立中文摘要

问题：经典 Data Shapley 估值成本高且受效用噪声影响，效率公理未必适合机器学习数据估值。 方法：Beta Shapley 放松效率公理，用 Beta 权重统一一族估值规则并设计更高效、低噪估计。 结论：作者报告在错标检测、子集学习及识别增删影响最大的点上超过数据估值基线。

## 批判性小综述

对该研究的证据边界判断：估值取决于所选效用函数、训练算法和子集分布，并非照片固有属性；计算仍远高于动态在线 replay。 反向约束：不能把 Beta 参数任意调成 Stage1 权重，也不能以 Shapley 估计替代未见 seed 干预。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ7；其可迁移链条是：可用于定义小规模组级边际效用审计，并比较有益/有害样本的估计稳定性。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。
