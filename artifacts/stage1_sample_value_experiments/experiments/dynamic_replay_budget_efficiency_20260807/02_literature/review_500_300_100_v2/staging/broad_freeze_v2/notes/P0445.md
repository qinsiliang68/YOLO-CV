# P0445 - Adversarial Coreset Selection for Efficient Robust Training

## 独立中文摘要

问题：对全部样本生成 adversarial example 成本很高，需要用小子集近似完整鲁棒训练梯度。 方法：方法推导 coreset 的收敛界与全数据 adversarial gradient approximation error 的关系，再把 CRAIG/GradMatch 式目标适配到 TRADES、PGD 和 perceptual adversarial training。 结论：多种鲁棒训练中获得约 2 至 3 倍加速并仅有轻微 clean/robust accuracy 下降；相同 coreset size 下 adversarial GradMatch 的 robust error 低于 random。

## 批判性小综述

对该研究的证据边界判断：它优化的是接近全梯度而非业务验证梯度，且允许轻微性能下降换效率；文献本身不能证明 gradient matching 等于泛化价值。 反向约束：不能由 robust-gradient 近似推出普通分类 replay 的方向正确，也不能省略真实 T/R1/R2 干预。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：Stage1 可把 Grad-Match 作为 A 的对照，但关键比较应是 FN95 val_target 梯度而非全训练梯度，并同时报告选择成本。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 Grad-Match 作为 A 的对照，但关键比较应是 FN95 val_target 梯度而非全训练梯度，并同时报告选择成本。 禁止外推：不能由 robust-gradient 近似推出普通分类 replay 的方向正确，也不能省略真实 T/R1/R2 干预。
