# P0030 - GAC: Stabilizing Asynchronous RL Training for LLMs via Gradient Alignment Control

## 独立中文摘要

问题：论文研究异步强化学习中陈旧 rollout 如何改变更新几何并导致训练崩溃，重点分析连续梯度方向的时间相关性。 方法：作者以相邻策略梯度余弦监测陈旧更新，在安全、投影和违规三个区间分别放行、削弱平行分量或跳过更新，并给出有界陈旧条件下的偏差分析。 结论：在多种 Qwen 与 Llama 模型及数学推理任务中，作者报告高梯度连续对齐先于崩溃出现，GAC 在多个陈旧水平下恢复接近同步训练的稳定性。

## 批判性小综述

对该研究的证据边界判断：本文控制的是相邻优化步骤的梯度对齐，不是训练样本与独立 FN95 目标梯度的对齐；正文也未报告清晰的独立 seed 重复，因此不能把两类余弦直接等同。 反向约束：不能由该研究推出某张图值得回流，也不能推出样本对目标梯度的正对齐越大越好；其 RL 陈旧梯度机制需在 Stage1 另行干预验证。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ8；其可迁移链条是：可迁移的是记录跨 epoch 或跨更新的梯度方向持续性，并把过度同向更新视为 replay 集中过强的风险信号，而不是把正余弦一概当作价值。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。
