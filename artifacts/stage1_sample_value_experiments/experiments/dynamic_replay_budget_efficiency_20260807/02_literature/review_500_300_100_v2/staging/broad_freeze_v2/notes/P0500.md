# P0500 - Label-Efficient Dataset Pruning via Semi-Supervised Pseudo-Labeling

## 独立中文摘要

问题：论文研究在只标注少量样本时，怎样估计全数据训练动态并选择固定大小的高质量 coreset。 方法：SemiPrune 先随机标注小子集并用半监督模型生成伪标签，再计算 AUM 或 DUAL 动态分数，采用中间窗口双端剪枝和分层随机抽样。 结论：多数据集与多剪枝预算结果显示该方案可超过随机和既有无标签剪枝方法，且极端 Top-k 会产生明显分布偏置。

## 批判性小综述

对该研究的证据边界判断：研究是一次性子集训练而非追加 replay，选择超参数、伪标签质量和最终训练预算需与 Stage1 重新配平。 反向约束：不能推出 AUM 或 DUAL 单分数就是 Stage1 价值，也不能省略独立 seed 和严格匹配随机对照。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6；其可迁移链条是：可直接支持 Q 后去除不可学极端尾部，再以难度分层和随机覆盖形成集合，而不是确定性最高分 Top-k。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可直接支持 Q 后去除不可学极端尾部，再以难度分层和随机覆盖形成集合，而不是确定性最高分 Top-k。 禁止外推：不能推出 AUM 或 DUAL 单分数就是 Stage1 价值，也不能省略独立 seed 和严格匹配随机对照。
