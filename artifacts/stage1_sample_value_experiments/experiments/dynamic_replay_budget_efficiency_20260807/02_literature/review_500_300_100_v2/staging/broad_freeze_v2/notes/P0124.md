# P0124 - Learning to Detect Noisy Labels Using Model-Based Features

## 独立中文摘要

问题：单一 sample loss 噪声检测不够灵活，元学习选择器又难优化。 方法：SENT 将噪声分布迁移到干净集，用多个 model-based features 训练噪声检测器，再增强 noisy-label training。 结论：作者在文本分类与语音识别的自训练和标签污染设置中优于强基线。

## 批判性小综述

对该研究的证据边界判断：依赖可构造噪声与干净参照，且跨模态模型特征未必校准；检测准确率仍不等于 replay 效用。 反向约束：不能直接迁移 SENT 检测器，也不能把判为 clean 的样本自动判为值得重复训练。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4；其可迁移链条是：Stage1 Q 层应保留多动态字段而非只有 loss，并通过 OOF/人工子集校准，但不能将 Q 写进任意加权总分。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 Q 层应保留多动态字段而非只有 loss，并通过 OOF/人工子集校准，但不能将 Q 写进任意加权总分。 禁止外推：不能直接迁移 SENT 检测器，也不能把判为 clean 的样本自动判为值得重复训练。
