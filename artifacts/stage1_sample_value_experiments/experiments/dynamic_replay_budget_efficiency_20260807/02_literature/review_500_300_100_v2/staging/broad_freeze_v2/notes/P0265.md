# P0265 - Concept-skill Transferability-based Data Selection for Large Vision-Language Models

## 独立中文摘要

问题：视觉语言指令数据庞大且昂贵，单纯难度或密度选择会忽略概念技能组合的覆盖和跨组合迁移。 方法：COINCIDE 用小模型内部激活聚类概念技能组合，再依据簇密度和 transferability 从多样簇抽样。 结论：作者报告相对八个强基线提升选择效率，在 LLaVA-1.5 用百分之二十数据接近全量性能并减少约百分之七十运行时间。

## 批判性小综述

对该研究的证据边界判断：它支持 reference model、覆盖和迁移能力联合，但小模型表征与目标模型状态可能错配，跨 seed 与严格随机匹配需筛读。 反向约束：不能把小模型 transferability 直接解释为当前 YOLO run 的 R，也不能把墙钟节省当作业务效用。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5；其可迁移链条是：Stage1 可用 OOF 模型产生簇和 reference predictability，再测试簇密度与跨簇迁移是否解释随机组优势。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可用 OOF 模型产生簇和 reference predictability，再测试簇密度与跨簇迁移是否解释随机组优势。 禁止外推：不能把小模型 transferability 直接解释为当前 YOLO run 的 R，也不能把墙钟节省当作业务效用。
