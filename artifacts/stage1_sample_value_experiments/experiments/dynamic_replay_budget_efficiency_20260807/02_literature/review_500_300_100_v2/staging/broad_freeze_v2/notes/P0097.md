# P0097 - Investigating Active Learning based on Dynamic Data Selection techniques for Image Classification

## 独立中文摘要

问题：图像主动学习需要在有限标注预算内动态挑选信息样本，减少人工标注同时保持分类性能。 方法：研究用微调 VGG16，在阿拉伯手语数据上比较随机、entropy 和 margin 三种迭代选样策略。 结论：作者报告 margin 主动选择以较少标注达到百分之九十五点三的 32 类手势识别准确率。

## 批判性小综述

对该研究的证据边界判断：单数据集、单模型且摘要未说明独立 seed、候选池匹配和训练预算；主动标注收益不能等同已标注 replay 边际收益。 反向约束：不能将一次 margin 优胜推广为阈值附近 normal 跨 seed 稳压 random，也不能据此设计任意固定权重。
