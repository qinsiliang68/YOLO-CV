# P0235 - Deep Generative Dual Memory Network for Continual Learning

## 独立中文摘要

问题：顺序任务训练会遗忘，单一网络与有限容量难同时快速吸收新知识和长期保存旧知识。 方法：方法构建模仿海马与新皮层的双 memory，并通过生成 replay 做记忆巩固。 结论：作者报告在低容量和多任务下改善旧任务性能保持。

## 批判性小综述

对该研究的证据边界判断：它支持 replay 的功能可能是保持边界而非提高当前样本难度，但生成器与架构是主要混杂。 反向约束：不能把生物记忆类比当机制证明，也不能由生成 replay 选择真实训练帧。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ6；其可迁移链条是：Stage1 可将 weak-defect 轨迹视为需保护的旧知识，比较 replay 与无额外样本的约束损失。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将 weak-defect 轨迹视为需保护的旧知识，比较 replay 与无额外样本的约束损失。 禁止外推：不能把生物记忆类比当机制证明，也不能由生成 replay 选择真实训练帧。
