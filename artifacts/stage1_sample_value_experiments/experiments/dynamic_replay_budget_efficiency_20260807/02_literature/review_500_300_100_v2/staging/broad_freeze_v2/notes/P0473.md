# P0473 - Generic and Trend-aware Curriculum Learning for Relation Extraction

## 独立中文摘要

问题：单时点 loss 难以稳定区分样本难易，因为相同当前损失可以对应正在改善、停滞或恶化的轨迹。 方法：方法把样本级 loss trend 纳入通用 curriculum，在文本图关系抽取中估计难度并调度训练顺序。 结论：作者报告其难度估计更稳健，并在多个数据集上较现有关系抽取方法取得明显改进。

## 批判性小综述

对该研究的证据边界判断：它直接支持斜率和趋势比终点 loss 多一层信息，但趋势窗口、刷新频率、随机基线和 seed 证据需方法实验筛读。 反向约束：不能由 loss 下降趋势推断 FN95 目标方向，也不能默认所有慢降样本都应增加曝光。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6；其可迁移链条是：Stage1 可把 current loss 与 early/mid/late slope 分开做析因，用前一 epoch 轨迹决定下一 epoch 队列。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 current loss 与 early/mid/late slope 分开做析因，用前一 epoch 轨迹决定下一 epoch 队列。 禁止外推：不能由 loss 下降趋势推断 FN95 目标方向，也不能默认所有慢降样本都应增加曝光。
