# P0150 - Data-Efficient Training by Evolved Sampling

## 独立中文摘要

问题：现有动态选样常只用当前 loss 或历史 loss，既丢失变化频率信息又增加参考模型、存储和反向计算开销。 方法：Evolved Sampling 在 batch 级联合零阶 loss 与一阶增强 loss difference 动态采样，可调高低频成分，并可叠加 set-level pruning 形成 ESWP。 结论：作者报告跨预训练和后训练任务保持性能并最高节省近百分之四十五墙钟时间。

## 批判性小综述

对该研究的证据边界判断：它直接把 loss 差分、刷新频率和集合剪枝分离，接近 Stage1 训练动态问题；lossless 的统计、随机对照和预算需精读。 反向约束：不能把墙钟节省等同业务指标提升，也不能由高频 loss 信号推断 FN95 目标方向。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6,RQ7；其可迁移链条是：Stage1 可比较 current loss、相邻 loss difference、长窗 trend 和 OOF-reducible 差，并固定 optimizer-visible exposure。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可比较 current loss、相邻 loss difference、长窗 trend 和 OOF-reducible 差，并固定 optimizer-visible exposure。 禁止外推：不能把墙钟节省等同业务指标提升，也不能由高频 loss 信号推断 FN95 目标方向。
