# P0016 - Domain Adaptation Using Class-Balanced Self-Paced Learning for Soil Classification With LIBS

## 独立中文摘要

问题：目标域伪标签分布会被容易类别逐渐主导，统一置信阈值又无法处理类别难度差异。 方法：方法在自训练中按类别定制选择比例和增量，暂时忽略预测占比过大的容易类别，并由验证集调节自步过程。 结论：EMSLIBS 土壤光谱实验报告 90.2% 测试准确率，在分布变化下达到与竞赛方案相近的水平。

## 批判性小综述

对该研究的证据边界判断：类别比例和增量经验证调参，域适配、伪标签与 pacing 同时变化，摘要结果不能单独归因于样本选择。 反向约束：不能把 90.2% 准确率迁移成 FN95 收益，也不能据此指定某个固定 confidence 门槛。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6,RQ7；其可迁移链条是：Stage1 的动态候选池应按 normal/defect 分开定义，并把每类实际入选比例和阈值轨迹完整记录。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的动态候选池应按 normal/defect 分开定义，并把每类实际入选比例和阈值轨迹完整记录。 禁止外推：不能把 90.2% 准确率迁移成 FN95 收益，也不能据此指定某个固定 confidence 门槛。
