# P0252 - Logistic push: a regression framework for partial AUC optimization

## 独立中文摘要

问题：完整 AUC 忽略不同假阳性与假阴性代价，pAUC 更贴临床区域但直接优化复杂且高维建模困难。 方法：Logistic push 用带权 logistic 回归近似 P-norm push 的局部排序效果，可结合现成惩罚回归完成变量选择和模型拟合。 结论：论文主张该方法在高维临床预测中以较简单计算优化目标 pAUC 区域。

## 批判性小综述

对该研究的证据边界判断：它是线性回归与标志物选择，不是训练样本 replay；pAUC 区域的定义也未必等同 FN=0至95整数前沿。 反向约束：不能用 logistic push 的系数或样本权重直接构造 replay 排名，也不能声称其已验证 TN_at_FN95。

## Stage1 直接相关链

该研究直接映射到 RQ8；其可迁移链条是：可支持 Stage1 使用局部而非完整 ROC 目标，并为 critical pairwise loss 提供统计学旁证。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可支持 Stage1 使用局部而非完整 ROC 目标，并为 critical pairwise loss 提供统计学旁证。 禁止外推：不能用 logistic push 的系数或样本权重直接构造 replay 排名，也不能声称其已验证 TN_at_FN95。
