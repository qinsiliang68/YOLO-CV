# P0312 - Open set label noise learning with robust sample selection and margin-guided module

## 独立中文摘要

问题：开放集与闭合集噪声机制不同，单一小损失或高置信选择会遗漏干净样本并混淆两类噪声。 方法：RSS-MGM 联合 small-loss 和 high-confidence 扩展干净候选，再用 margin 模块区分开放/闭合集噪声并差异处理。 结论：作者在合成和真实噪声数据集上报告优于多种 noisy-label 方法。

## 批判性小综述

对该研究的证据边界判断：多个启发式和处理分支共同变化；margin 仍受当前模型状态影响，真实 Stage1 是否含开放集噪声未知。 反向约束：不能在无人工/多模型证据时给样本定性为错标，也不能由噪声学习精度推出 replay 效用。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ5；其可迁移链条是：Stage1 可将疑似标签错、OOD、hard-clean 分成不同 Q 类型，而不是用一个 noise penalty 连续加权。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将疑似标签错、OOD、hard-clean 分成不同 Q 类型，而不是用一个 noise penalty 连续加权。 禁止外推：不能在无人工/多模型证据时给样本定性为错标，也不能由噪声学习精度推出 replay 效用。
