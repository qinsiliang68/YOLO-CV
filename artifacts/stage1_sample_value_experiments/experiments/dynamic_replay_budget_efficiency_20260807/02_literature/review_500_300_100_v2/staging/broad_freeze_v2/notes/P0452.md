# P0452 - Bootstrap Neyman-Pearson test for knowing the value of misclassification probability

## 独立中文摘要

问题：二分类应用有时要求显式控制某类误分类概率，而普通平均准确率不提供这种约束保证。 方法：论文将 bootstrap 与 Neyman-Pearson 检验结合，用潜变量混合模型近似检验统计量，并以 bootstrap 经验分位数满足 NP 约束。 结论：作者在合成和真实数据上报告该分类器可以估计并控制目标误分类概率。

## 批判性小综述

对该研究的证据边界判断：它支持把 Stage1 写成受约束风险而非平均 CE，但方法较早且依赖密度模型，有限样本覆盖和现代深网适用性需筛读。 反向约束：不能由 bootstrap NP 分类器推出某个 replay 样本有价值，也不能把其分布假设直接套到 score tail。

## Stage1 直接相关链

该研究直接映射到 RQ8；其可迁移链条是：Stage1 应分别冻结 FN 约束阈值和 TN 约束阈值，并报告阈值不确定性或置信界，而不是复用一套 confusion matrix。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应分别冻结 FN 约束阈值和 TN 约束阈值，并报告阈值不确定性或置信界，而不是复用一套 confusion matrix。 禁止外推：不能由 bootstrap NP 分类器推出某个 replay 样本有价值，也不能把其分布假设直接套到 score tail。
