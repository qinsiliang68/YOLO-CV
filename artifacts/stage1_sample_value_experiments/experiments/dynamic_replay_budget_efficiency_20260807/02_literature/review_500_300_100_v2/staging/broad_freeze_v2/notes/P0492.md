# P0492 - Self-Paced Learning Based Graph Convolutional Neural Network for Mixed Integer Programming (Student Abstract)

## 独立中文摘要

问题：混合整数规划实例结构差异使固定训练集难以泛化，需要决定不同训练阶段先学习哪些实例。 方法：SPGCN 用当前训练损失度量实例难度，并随迭代动态构造由易到难的训练集，与预定义 curriculum 比较。 结论：作者在四类 NP-hard 数据上报告自步策略改善泛化与收敛，优于固定课程。

## 批判性小综述

对该研究的证据边界判断：这是学生摘要，方法和消融细节有限；当前 loss 同时受噪声、模型状态和可学习性影响，不能被视为真实效用。 反向约束：不能从求解分支变量任务推导 FN95 提升，也不能证明 loss Top-K 稳定胜过严格随机回流。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6；其可迁移链条是：Stage1 可把 loss curriculum 作为 HN/current-loss 对照，并单独检验动态时机，而不能把它当最终价值定义。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 loss curriculum 作为 HN/current-loss 对照，并单独检验动态时机，而不能把它当最终价值定义。 禁止外推：不能从求解分支变量任务推导 FN95 提升，也不能证明 loss Top-K 稳定胜过严格随机回流。
