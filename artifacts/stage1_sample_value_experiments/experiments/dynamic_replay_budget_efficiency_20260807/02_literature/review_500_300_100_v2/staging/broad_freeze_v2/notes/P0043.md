# P0043 - Online Class-Incremental Continual Learning with Adversarial Shapley Value

## 独立中文摘要

问题：在线持续学习的有限 buffer 需要同时保留旧类边界和适应新类，单一相似度或 loss 难兼顾稳定性与塑性。 方法：ASER 用对抗 Shapley 分数衡量 buffer 样本保护旧边界及干扰当前边界的联合贡献，并据此选 replay。 结论：作者在多种在线类增量数据上报告相对 replay 基线有竞争力或更好。

## 批判性小综述

对该研究的证据边界判断：Shapley 近似成本和结果依赖当前 batch 与 buffer 上下文，正好说明价值不是照片固有标量。 反向约束：不能直接计算精确 Shapley 覆盖 12 万图，也不能把持续学习遗忘等同于固定数据过采样。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ3,RQ5,RQ6,RQ7；其可迁移链条是：Stage1 可把集合条件价值写成对 weak-defect 稳定与 hard-normal 塑性的双目标，并做组级边际干预。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把集合条件价值写成对 weak-defect 稳定与 hard-normal 塑性的双目标，并做组级边际干预。 禁止外推：不能直接计算精确 Shapley 覆盖 12 万图，也不能把持续学习遗忘等同于固定数据过采样。
