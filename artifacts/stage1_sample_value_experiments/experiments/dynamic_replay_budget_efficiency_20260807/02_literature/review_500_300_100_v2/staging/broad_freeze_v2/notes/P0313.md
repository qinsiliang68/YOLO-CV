# P0313 - Extracting In-domain Training Corpora for Neural Machine Translation Using Data Selection Methods

## 独立中文摘要

问题：跨域机器翻译全语料训练昂贵且域不匹配，选择目标域相关子集可能更高效。 方法：论文比较 TF-IDF、cross-entropy difference 和 feature decay 三种选择法，在 NMT 上训练选中语料。 结论：作者报告三种选择可改善 NMT，但增益小于统计机器翻译。

## 批判性小综述

对该研究的证据边界判断：结果显示方法收益依学习器而变，且域相关性不是样本可学习性；随机预算与 seed 细节需核对。 反向约束：不能将 cross-entropy difference 直接等同 OOF reducible loss，也不能由域适配结果推断 FN95。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5,RQ7；其可迁移链条是：Stage1 应测试 selection×model/seed 交互并把来源域覆盖列为 set feature，而非假定统一排名。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应测试 selection×model/seed 交互并把来源域覆盖列为 set feature，而非假定统一排名。 禁止外推：不能将 cross-entropy difference 直接等同 OOF reducible loss，也不能由域适配结果推断 FN95。
