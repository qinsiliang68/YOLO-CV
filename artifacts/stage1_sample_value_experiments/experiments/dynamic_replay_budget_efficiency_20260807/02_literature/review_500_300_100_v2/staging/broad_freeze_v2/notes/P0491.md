# P0491 - Enhancing Autism Detection Through Gaze Analysis Using Eye Tracking Sensors and Data Attribution with Distillation in Deep Neural Networks

## 独立中文摘要

问题：眼动自闭症分类数据可能含噪声或异常训练样本，全量训练未必兼顾精度和计算效率。 方法：GBAC 使用 TracIn 自影响分数做训练数据归因，过滤疑似噪声或异常样本后再训练分类器，并与全量及随机删减比较。 结论：作者报告使用百分之七十七数据达到百分之九十四点三五测试准确率，并优于同模型全量训练与随机样本减少。

## 批判性小综述

对该研究的证据边界判断：该研究提供 attribution 筛样与随机删减的直接干预，但样本量、拆分泄漏、seed 和多重尝试风险需全文筛读后才能评价可信度。 反向约束：不能由单一医疗数据结果证明自影响高就是有害，也不能把测试集精度筛选方式搬入 Stage1。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ4,RQ7；其可迁移链条是：Stage1 可将 TracIn 或 checkpoint 梯度点积作为 A 的候选 proxy，并要求和等预算随机及 no-replay 配对。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将 TracIn 或 checkpoint 梯度点积作为 A 的候选 proxy，并要求和等预算随机及 no-replay 配对。 禁止外推：不能由单一医疗数据结果证明自影响高就是有害，也不能把测试集精度筛选方式搬入 Stage1。
