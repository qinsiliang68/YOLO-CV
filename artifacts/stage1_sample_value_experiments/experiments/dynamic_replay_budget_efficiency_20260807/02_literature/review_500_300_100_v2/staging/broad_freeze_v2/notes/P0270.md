# P0270 - Improved Hard Example Mining Approach for Single Shot Object Detectors

## 独立中文摘要

问题：单阶段检测器的前景背景与难易样本极不平衡，普通 loss 会被大量容易负样本主导。 方法：论文把 loss-rank mining 与 focal loss 适配到 YOLOv5，并组合为 balanced focal/hard-mining 方案，对 Anti-UAV 数据进行逐组件比较。 结论：组合方法相对原损失提高约 3% mAP，相对单独 LRM 或 focal 提高约 1% 至 2%；消融也显示普通 focal 在部分设置可退化。

## 批判性小综述

对该研究的证据边界判断：方法改变 anchor/目标级损失而非图片 replay，并且 mAP 平均化了高召回尾部；缺少同计算量随机 hard-anchor 对照。 反向约束：不能由检测 mAP 提升推出最难图片值得重复，也不能证明 loss-rank 在跨 seed 上稳定。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ6；其可迁移链条是：Stage1 可把它保留为 hardness reweighting 的正向历史证据，同时必须用 current-loss 和 random 暴露对照检验其外推边界。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把它保留为 hardness reweighting 的正向历史证据，同时必须用 current-loss 和 random 暴露对照检验其外推边界。 禁止外推：不能由检测 mAP 提升推出最难图片值得重复，也不能证明 loss-rank 在跨 seed 上稳定。
