# P0171 - Efficient Adversarial Contrastive Learning via Robustness-Aware Coreset Selection

## 独立中文摘要

问题：论文研究对抗对比学习计算昂贵时，如何选择能保持鲁棒表征的有限训练子集。 方法：RCS 将集合选择写成最小化对抗表征差异的子模近似目标，并用贪心策略在固定子集比例下选择 coreset。 结论：在多个数据集、子集比例和下游任务中，RCS 相对同规模随机子集提高鲁棒表现并接近全量训练。

## 批判性小综述

对该研究的证据边界判断：该方法目标是对抗表征而非 FN95，且 coreset 从头训练与 Stage1 基础数据加 replay 的干预结构不同。 反向约束：不能认为表征差异最小的子集必然降低 normal 高尾且保护 weak defect 低尾。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ4,RQ6；其可迁移链条是：可迁移的是在 D 层按集合边际覆盖而非独立样本分数选取，并保留同预算随机集合对照。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是在 D 层按集合边际覆盖而非独立样本分数选取，并保留同预算随机集合对照。 禁止外推：不能认为表征差异最小的子集必然降低 normal 高尾且保护 weak defect 低尾。
