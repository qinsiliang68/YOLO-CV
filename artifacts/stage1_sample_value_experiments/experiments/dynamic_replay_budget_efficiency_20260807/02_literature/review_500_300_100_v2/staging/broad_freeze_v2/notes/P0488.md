# P0488 - Learning to Reweight Examples for Robust Deep Learning

## 独立中文摘要

问题：基于单样本 loss 的固定重权需要人工调超参数，并会在类别偏差或标签噪声下放大错误方向。 方法：方法把当前 mini-batch 样本权重从零初始化，做一步元梯度更新，使小型干净无偏验证集损失下降，再据此更新模型。 结论：作者报告无需额外重权超参数即可在类别不平衡和标签污染任务上取得较好鲁棒性。

## 批判性小综述

对该研究的证据边界判断：它是一阶公式中 g_val 点乘 g_i 决定正负方向的核心来源，但依赖干净代表性验证集，计算和短视偏差需精读。 反向约束：不能把 clean-validation CE 方向直接等同 FN95 方向，也不能由 meta-weight 数值称样本具有永久价值。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ3,RQ4,RQ6；其可迁移链条是：Stage1 的 A 必须来自独立 val_target 的 FN95 局部目标，并单独报告正、负和近零对齐，而非只看梯度范数。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 A 必须来自独立 val_target 的 FN95 局部目标，并单独报告正、负和近零对齐，而非只看梯度范数。 禁止外推：不能把 clean-validation CE 方向直接等同 FN95 方向，也不能由 meta-weight 数值称样本具有永久价值。
