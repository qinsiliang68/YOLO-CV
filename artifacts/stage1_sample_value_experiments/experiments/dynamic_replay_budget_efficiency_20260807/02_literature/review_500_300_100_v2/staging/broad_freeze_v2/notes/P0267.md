# P0267 - Efficient Active Learning for Image Classification and Segmentation\n using a Sample Selection and Conditional Generative Adversarial Network

## 独立中文摘要

问题：医学影像标注昂贵，需要在有限预算下选择信息样本并扩充训练数据。 方法：方法用贝叶斯不确定性选择影像，再以条件生成对抗网络生成补充样本，联合用于分类和分割。 结论：摘要报告约使用完整数据 35% 即达到有竞争力或当时先进表现。

## 批判性小综述

对该研究的证据边界判断：选样和生成被同时改变，收益无法归因于 uncertainty；生成数据质量与真实样本 replay 也不是同一干预。 反向约束：不能由联合方法结果推出 uncertainty 样本会胜随机回流，也不能把生成样本等同原图额外曝光。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ5,RQ7；其可迁移链条是：可保留 uncertainty-only 作为 Stage1 负或基线 arm，并把生成式扩增明确排除在当前 replay 合同外。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可保留 uncertainty-only 作为 Stage1 负或基线 arm，并把生成式扩增明确排除在当前 replay 合同外。 禁止外推：不能由联合方法结果推出 uncertainty 样本会胜随机回流，也不能把生成样本等同原图额外曝光。
