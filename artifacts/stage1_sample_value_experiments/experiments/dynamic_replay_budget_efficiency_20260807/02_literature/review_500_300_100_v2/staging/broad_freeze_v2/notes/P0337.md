# P0337 - Dynamic Data Selection for Curriculum Learning via Ability Estimation

## 独立中文摘要

问题：课程学习常用固定难度和能力启发式，不能反映每个 epoch 的模型状态。 方法：DDaCLAE 学习样本难度参数，并在每个 epoch 探测模型能力，只选择当前适合的训练样本。 结论：作者报告 learned difficulty 和/或 ability 在 GLUE 分类上优于启发式课程。

## 批判性小综述

对该研究的证据边界判断：动态选择自由度高且每轮训练集大小变化；NLP ability 参数未必可识别可约损失或方向。 反向约束：不能把能力匹配等同 FN95 正向效用，也不能忽略选择器自身的开发集过拟合。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5,RQ6,RQ7；其可迁移链条是：Stage1 可把是否进入当前 replay pool 定义为 V(x|theta_t)，但必须保留 lag、预算和随机探索合同。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把是否进入当前 replay pool 定义为 V(x|theta_t)，但必须保留 lag、预算和随机探索合同。 禁止外推：不能把能力匹配等同 FN95 正向效用，也不能忽略选择器自身的开发集过拟合。
