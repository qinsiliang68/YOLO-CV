# P0253 - From Quantity to Quality: Boosting LLM Performance with Self-Guided Data Selection for Instruction Tuning

## 独立中文摘要

问题：指令微调数据数量大但质量异质，需要识别既能被模型利用又提供增量监督的样本。 方法：IFD 比较给定指令与不给指令时生成回答的难度差异，由模型自身筛选所谓 cherry samples。 结论：作者报告仅用原数据约 10% 仍能提高多个指令数据集上的结果。

## 批判性小综述

对该研究的证据边界判断：IFD 是语言条件化难度，不是严格的可约损失；需检查模型、随机子集、token 预算和 seed 是否对齐。 反向约束：不能把 LLM 的 10% 比例或 IFD 阈值直接用于图像 replay，也不能据此保证跨 seed。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5,RQ7；其可迁移链条是：Stage1 可借鉴 current-vs-reference 的条件差分思路，但应使用 OOF reference、current-loss 对照和固定曝光预算。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴 current-vs-reference 的条件差分思路，但应使用 OOF reference、current-loss 对照和固定曝光预算。 禁止外推：不能把 LLM 的 10% 比例或 IFD 阈值直接用于图像 replay，也不能据此保证跨 seed。
