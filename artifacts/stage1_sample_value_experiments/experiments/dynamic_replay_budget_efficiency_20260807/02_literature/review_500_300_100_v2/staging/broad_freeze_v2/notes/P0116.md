# P0116 - Hybrid Knowledge Transfer for Improved Cross-Lingual Event Detection via Hierarchical Sample Selection

## 独立中文摘要

问题：跨语言 teacher 产生的目标语言伪标签含噪，直接用全部伪标样本训练 student 会传播不可靠监督。 方法：方法先用 optimal transport 评估源域与目标域样本的全局对齐，再用 CSLS 降低 hubness 并做局部相似度筛选，形成两级候选集训练 student。 结论：多语言事件检测实验及消融显示两级选择优于不选样和去掉任一层的版本，并分析保留比例的影响。

## 批判性小综述

对该研究的证据边界判断：OT/CSLS 衡量跨语言域对齐，不等于标签可靠性或训练边际效用；teacher、student 与筛选比例共同决定结果。 反向约束：不能把文本表示距离直接迁移到 CCTV embedding，也不能由伪标签筛选结果推出 FN95-local 方向正确。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ5；其可迁移链条是：Stage1 可借鉴先做来源/域覆盖再做局部代表性的层级 D 门控，并显式报告 hubness、近重复率和各层放宽。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴先做来源/域覆盖再做局部代表性的层级 D 门控，并显式报告 hubness、近重复率和各层放宽。 禁止外推：不能把文本表示距离直接迁移到 CCTV embedding，也不能由伪标签筛选结果推出 FN95-local 方向正确。
