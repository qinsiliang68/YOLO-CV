# P0363 - Curriculum Learning for Heterogeneous Star Network Embedding via Deep Reinforcement Learning

## 独立中文摘要

问题：论文研究异构星形网络嵌入中，不同边类型应以什么顺序和停止时点进入训练，避免固定课程忽略当前模型状态。 方法：作者把边类型选择写成马尔可夫决策过程，状态是已选课程序列，动作是下一边类型或停止，奖励由留出任务性能增益减去动作成本构成，并结合规划与 LSTM 学习策略。 结论：在同等每动作一百万条边的预算下，学习课程相对随机、贪心、打乱和静态加权基线取得更好下游表现，说明顺序和停止均可能改变有限预算收益。

## 批判性小综述

对该研究的证据边界判断：选择单位是边类型而非单样本，奖励直接依赖留出任务，且未建立跨初始化的稳定效用；若把 val_op 用作奖励会造成与 Stage1 相同的开发集泄漏。 反向约束：不能推出强化学习调度器有必要，也不能推出论文中的边类型顺序适用于图像 replay 或 FN95 安全前沿。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ8；其可迁移链条是：可迁移的是把 replay 时序与停止视为一等变量，并只允许用独立 val_target 或训练内信息驱动动态控制。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是把 replay 时序与停止视为一等变量，并只允许用独立 val_target 或训练内信息驱动动态控制。 禁止外推：不能推出强化学习调度器有必要，也不能推出论文中的边类型顺序适用于图像 replay 或 FN95 安全前沿。
