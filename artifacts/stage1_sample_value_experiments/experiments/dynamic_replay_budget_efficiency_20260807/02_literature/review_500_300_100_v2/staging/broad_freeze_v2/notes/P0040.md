# P0040 - BRIEF: Bi-Level Coreset Selection for Efficient Instruction Tuning in LLMs

## 独立中文摘要

问题：指令微调预算有限时，单纯按 loss 或语义相似度选样不能同时覆盖知识学习和指令遵循两类目标。 方法：BRIEF 将指令损失拆成知识与指令遵循分量，在双层优化中以复合梯度距离构造 coreset，并用 submodular 结构求近似选择。 结论：四个数据集、九个任务的实验报告约三倍训练成本降低且平均性能提高约 5%，并比较随机与多种 coreset 方法。

## 批判性小综述

对该研究的证据边界判断：损失分解和 LLM 指令任务特有，双层目标与集合选择耦合；论文结果仍不能证明单个梯度距离是通用价值。 反向约束：不能照搬其复合梯度权重，也不能把 submodular 近似保证解释为非凸训练后的 FN95 泛化保证。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：Stage1 可借鉴把 normal-high-tail 与 weak-defect-tail 目标分开后做无权重约束或字典序集合优化，并与同预算随机配对。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴把 normal-high-tail 与 weak-defect-tail 目标分开后做无权重约束或字典序集合优化，并与同预算随机配对。 禁止外推：不能照搬其复合梯度权重，也不能把 submodular 近似保证解释为非凸训练后的 FN95 泛化保证。
