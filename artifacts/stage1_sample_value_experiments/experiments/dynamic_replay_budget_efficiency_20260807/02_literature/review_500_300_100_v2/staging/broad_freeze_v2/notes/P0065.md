# P0065 - Class-Incremental Learning Using Generative Experience Replay Based on Time-aware Regularization

## 独立中文摘要

问题：严格类增量学习不能保存旧数据且模型大小固定，生成 replay 的监督、潜变量和重构目标随阶段的重要性不同。 方法：方法生成旧任务伪样本，并以 time-aware regularization 动态调节三项训练目标，在新旧任务并行训练。 结论：作者在主要持续学习基准上报告改善记忆保持和平均性能。

## 批判性小综述

对该研究的证据边界判断：它支持 replay 强度与保护项应随时间变化，但生成样本质量和正则调度混合，不能归因于样本选择。 反向约束：不能把生成旧类伪样本用于真实缺陷标签，也不能由持续学习平均性能确定 Stage1 衰减点。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ6；其可迁移链条是：Stage1 可将 replay envelope 与 weak-defect 保护分开析因，并记录每轮累计曝光和基础训练不变。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将 replay envelope 与 weak-defect 保护分开析因，并记录每轮累计曝光和基础训练不变。 禁止外推：不能把生成旧类伪样本用于真实缺陷标签，也不能由持续学习平均性能确定 Stage1 衰减点。
