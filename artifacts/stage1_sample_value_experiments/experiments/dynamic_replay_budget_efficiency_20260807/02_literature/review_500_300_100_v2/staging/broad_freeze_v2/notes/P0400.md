# P0400 - Non-Intrusive Load Monitoring of Household Devices Using a Hybrid Deep Learning Model through Convex Hull-Based Data Selection

## 独立中文摘要

问题：负荷监测连续信号冗余高，需要从大量窗口中保留能覆盖几何边界的信息点。 方法：方法用随机近似凸包选择真实凸包顶点，再训练 CNN 分类与双向 LSTM 回归混合架构。 结论：四种设备上报告较高 F1 与估计准确率并优于若干已有方案。

## 批判性小综述

对该研究的证据边界判断：凸包选择和混合模型同时变化，几何极点可能也是噪声；没有严格同规模随机重训信息。 反向约束：不能把凸包顶点称为高价值样本，也不能从时序回归结果推断 FN95 效用。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ5,RQ7；其可迁移链条是：Stage1 可把 embedding 边界覆盖作为 D 层候选，并与聚类中心和随机覆盖并列消融。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 embedding 边界覆盖作为 D 层候选，并与聚类中心和随机覆盖并列消融。 禁止外推：不能把凸包顶点称为高价值样本，也不能从时序回归结果推断 FN95 效用。
