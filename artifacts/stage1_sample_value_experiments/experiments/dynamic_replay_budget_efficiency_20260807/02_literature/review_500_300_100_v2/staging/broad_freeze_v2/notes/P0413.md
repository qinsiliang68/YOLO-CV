# P0413 - A Novel Text Sample Selection Model for Scene Text Detection via Bootstrap Learning

## 独立中文摘要

问题：场景文字检测依赖外部数据集，目标是在当前图像内自动构造可靠文字训练样本以适应复杂背景和多语言。 方法：TSSM 结合 MSER 与显著图生成双阈值样本参考图，再用所选样本训练多核 boosting SVM。 结论：标准数据实验报告对复杂背景和多语言具有稳定鲁棒表现。

## 批判性小综述

对该研究的证据边界判断：样本来自待测图像本身，存在转导式适配，且不是深网多 epoch replay；多个视觉启发式共同贡献。 反向约束：不能用待测图像自举结果支持从 val_op 直接选训练样本，也不能推断显著区域代表高价值。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ5；其可迁移链条是：可作为双阈值可靠性筛选与 bootstrap 更新的旁证，但 Stage1 必须保持 val/test 身份隔离。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可作为双阈值可靠性筛选与 bootstrap 更新的旁证，但 Stage1 必须保持 val/test 身份隔离。 禁止外推：不能用待测图像自举结果支持从 val_op 直接选训练样本，也不能推断显著区域代表高价值。
