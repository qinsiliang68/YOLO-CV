# P0078 - An assessment of data-centric methods for label noise identification in remote sensing data sets

## 独立中文摘要

问题：论文系统考察遥感数据中不同类型和比例标签噪声时，数据中心方法识别错误标签及保护任务性能的能力。 方法：作者向两个基准注入百分之十至七十的多类噪声，比较三种噪声识别方法的过滤准确性和下游分类影响。 结论：不同方法的优劣随噪声假设、比例和目标改变，没有一个识别器在所有设置统一最好，过滤质量与任务收益相关但不等价。

## 批判性小综述

对该研究的证据边界判断：合成噪声便于得到真值，却弱于真实 CCTV 标签争议；过滤后的训练流程也不同于额外 replay。 反向约束：不能由遥感基准选择某个唯一 Q 阈值，也不能推断噪声识别准确就必然改善 FN95。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ7；其可迁移链条是：Stage1 应将 Q 指标在人工复核子集上评估 precision/recall，并按噪声类型分层，不把低 AUM 等 proxy 当真值。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应将 Q 指标在人工复核子集上评估 precision/recall，并按噪声类型分层，不把低 AUM 等 proxy 当真值。 禁止外推：不能由遥感基准选择某个唯一 Q 阈值，也不能推断噪声识别准确就必然改善 FN95。
