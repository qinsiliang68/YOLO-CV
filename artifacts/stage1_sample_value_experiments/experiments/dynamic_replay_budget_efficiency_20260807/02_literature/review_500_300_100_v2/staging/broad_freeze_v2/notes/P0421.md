# P0421 - DONOD: Efficient and Generalizable Instruction Fine-Tuning for LLMs via Model-Intrinsic Dataset Pruning

## 独立中文摘要

问题：论文研究指令微调数据中噪声、不可学和伤害跨域泛化的样本能否由模型自身参数变化识别并剪除。 方法：DON 衡量训练期间参数范数的累计变化，NOD 衡量样本诱发的权重不稳定，再用 TOPSIS 联合排序并剪除数据。 结论：数学任务实验声称删除多数数据仍改善域内和跨域准确率，并报告小模型所得选择可迁移到更大模型。

## 批判性小综述

对该研究的证据边界判断：参数范数是模型内生 proxy，TOPSIS 本身含人为多指标决策；LLM 微调和数据剪枝也不等于固定基础集上的额外 replay。 反向约束：不能将 DON 或 NOD 直接称为有益梯度方向，也不能用其跨模型结果替代 T 对 R1/R2 的多 seed 干预。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ4,RQ5；其可迁移链条是：Stage1 可把跨 epoch 更新幅度与不稳定性作为候选诊断字段，并单独测试稳定高影响与离群高影响两类。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把跨 epoch 更新幅度与不稳定性作为候选诊断字段，并单独测试稳定高影响与离群高影响两类。 禁止外推：不能将 DON 或 NOD 直接称为有益梯度方向，也不能用其跨模型结果替代 T 对 R1/R2 的多 seed 干预。
