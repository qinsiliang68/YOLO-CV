# P0158 - PICore: Physics-Informed Unsupervised Coreset Selection for Data Efficient Neural Operator Training

## 独立中文摘要

问题：神经算子训练的标签来自昂贵 PDE 求解器，因而需要在获取标签前用无监督信号选出有信息的输入子集。 方法：PICore 以物理残差和最后层梯度相关代理建立 coreset，在 warm start 后挑选未标注输入，再只对被选子集运行昂贵求解和训练。 结论：多个 PDE 数据上相对随机和聚类基线显著减少标注与训练成本，作者报告最高约 78% 效率收益且精度变化很小，并消融 warm-start 时机。

## 批判性小综述

对该研究的证据边界判断：物理残差是可验证的方程约束，Stage1 不存在同等强的无标签 oracle；成本改善也不是严格 replay 后优于随机的业务收益。 反向约束：不能把 PDE residual 当作分类 loss 的等价物，也不能由节省求解成本推出额外曝光会提升 TN_at_FN95。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：Stage1 可迁移 warm-start、选择开销单列、最后层梯度 proxy 和随机 coreset 对照，但必须用真实 val_target 方向而非物理残差。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移 warm-start、选择开销单列、最后层梯度 proxy 和随机 coreset 对照，但必须用真实 val_target 方向而非物理残差。 禁止外推：不能把 PDE residual 当作分类 loss 的等价物，也不能由节省求解成本推出额外曝光会提升 TN_at_FN95。
