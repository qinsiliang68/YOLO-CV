# P0433 - Measuring Fine-Grained Relatedness in Multitask Learning via Data Attribution

## 独立中文摘要

问题：多任务整体 relatedness 掩盖单实例正负迁移，导致共享参数中的负迁移难定位。 方法：MTIF 将 influence function 扩展到硬或软参数共享，估计实例对任务的细粒度相关性并据此选数据。 结论：作者报告 MTIF 能近似子集重训性能，启用的数据选择持续改善多任务模型。

## 批判性小综述

对该研究的证据边界判断：多任务 influence 与单任务 tail 目标不同，近似的随机稳定性、预算与 seed 需筛读。 反向约束：不能把 task relatedness 直接等同样本 utility，也不能省略真实重训验证。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：可支持 A 是目标条件的 signed effect，并专门记录 normal 更新对 defect tail 的负迁移。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可支持 A 是目标条件的 signed effect，并专门记录 normal 更新对 defect tail 的负迁移。 禁止外推：不能把 task relatedness 直接等同样本 utility，也不能省略真实重训验证。
