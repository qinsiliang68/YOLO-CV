# P0087 - Adaptive Dataset Pruning Based on Spatiotemporal Characteristics

## 独立中文摘要

问题：静态重要性分数忽略样本贡献随训练变化，并对预设 pruning 比例敏感。 方法：方法结合相似度网络、梯度时间变化、跨 epoch 持续重要性和瞬时关键样本保留，动态更新子集。 结论：CIFAR-10/100 上在中等与高 pruning 比例报告优于比较方法。

## 批判性小综述

对该研究的证据边界判断：四组件同时变化且来源为摘要级，持续重要性和瞬时关键的定义需精读，不能直接接受。 反向约束：不能把动态刷新收益归因于梯度一项，也不能从 pruning 比例推出 replay cap。

## Stage1 直接相关链
