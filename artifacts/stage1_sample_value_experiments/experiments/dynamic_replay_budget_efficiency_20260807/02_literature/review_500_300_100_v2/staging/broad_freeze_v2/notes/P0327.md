# P0327 - Initial training data selection for active learning

## 独立中文摘要

问题：主动学习的初始少量标签若随机抽得不具代表性，后续不确定性查询可能从错误边界起步。 方法：论文基于模糊聚类比较簇中心、簇边界和二者混合的初始样本选择。 结论：多套 UCI 数据上，作者报告 hybrid initial selection 比随机初始化提升主动学习表现。

## 批判性小综述

对该研究的证据边界判断：初始标注选择与 replay 不同，UCI 小数据结论和随机重复数需筛读；中心与边界混合比例可能数据依赖。 反向约束：不能由 hybrid 胜随机确定视频簇 quota，也不能把初始化敏感性当作当前模型 RHO。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ7；其可迁移链条是：Stage1 可把 D 设计为 prototype 与 boundary 的分层组合，并设置随机探索，而非只取一个极端。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 D 设计为 prototype 与 boundary 的分层组合，并设置随机探索，而非只取一个极端。 禁止外推：不能由 hybrid 胜随机确定视频簇 quota，也不能把初始化敏感性当作当前模型 RHO。
