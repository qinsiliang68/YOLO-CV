# P0248 - Class-Incremental Experience Replay for Continual Learning under Concept Drift

## 独立中文摘要

问题：连续学习要保留旧知识，而数据流挖掘要丢弃过时概念，两者在概念漂移下存在保留与遗忘冲突。 方法：方法用质心驱动 memory 保存多样类别实例，并以反应式子空间 buffer 检测漂移、调整旧类簇。 结论：作者称该架构能够同时学习新增类别、保存仍有效知识并遗忘过时信息。

## 批判性小综述

对该研究的证据边界判断：主要目标是非平稳数据流，不提供静态基础训练集上同 selection 跨 seed 的效用；多样性与漂移检测联合。 反向约束：不能把旧样本遗忘等同训练噪声，也不能从质心 buffer 推出 nearest-prototype 样本应回流。

## Stage1 直接相关链

该研究直接映射到 RQ5,RQ6；其可迁移链条是：Stage1 可将样本年龄、来源簇和概念漂移字段纳入 D/时序审计，但当前固定分布实验不应伪造漂移机制。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可将样本年龄、来源簇和概念漂移字段纳入 D/时序审计，但当前固定分布实验不应伪造漂移机制。 禁止外推：不能把旧样本遗忘等同训练噪声，也不能从质心 buffer 推出 nearest-prototype 样本应回流。
