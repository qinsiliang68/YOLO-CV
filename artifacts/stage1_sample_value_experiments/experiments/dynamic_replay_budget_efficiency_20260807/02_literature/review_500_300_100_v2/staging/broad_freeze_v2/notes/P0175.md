# P0175 - Distill Gold from Massive Ores: Bi-level Data Pruning towards Efficient Dataset Distillation

## 独立中文摘要

问题：论文研究数据集蒸馏前如何动态删去对元目标无益或有害的真实样本，以降低计算同时保持合成集质量。 方法：方法先按经验损失静态预删，再用样本存在与否造成的元梯度差定义 ITE，并在蒸馏训练中惰性更新；选择时同时去掉最低和最高 ITE，保留中间贡献区。 结论：多数据集五次试验显示该策略可降低蒸馏成本并保持或改善精度；关键消融表明极高 ITE 可能是离群或高方差来源，中等 ITE 比最大尾部更可靠。

## 批判性小综述

对该研究的证据边界判断：场景是双层数据集蒸馏而非标准 replay，ITE 计算依赖元梯度；作者也承认单样本标准忽略高阶多样性，在高 IPC 时静态剪枝会失效。 反向约束：不能推出中间 ITE 区间在 FN95 中必胜，也不能把元梯度差当成当前 Stage1 已采集字段。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ4,RQ5,RQ6；其可迁移链条是：可迁移的是设置 gradient magnitude Top、positive target alignment、negative alignment 和中间区间的析因对照，并随训练阶段刷新。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是设置 gradient magnitude Top、positive target alignment、negative alignment 和中间区间的析因对照，并随训练阶段刷新。 禁止外推：不能推出中间 ITE 区间在 FN95 中必胜，也不能把元梯度差当成当前 Stage1 已采集字段。
