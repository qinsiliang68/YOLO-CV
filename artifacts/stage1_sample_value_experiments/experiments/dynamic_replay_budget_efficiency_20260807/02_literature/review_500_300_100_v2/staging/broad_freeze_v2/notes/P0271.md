# P0271 - Interpretability-Driven Sample Selection Using Self Supervised Learning for Disease Classification and Segmentation

## 独立中文摘要

问题：医学主动学习需要少量专家交互选出信息样本，但无标签时普通 uncertainty 难判断显著区域是否真的有用。 方法：IDEAL 从解释 saliency map 提取信息，比较观察式、radiomics 和自监督数据驱动模型来选择 batch 中最有信息样本。 结论：作者在胸片分类和病理分割上报告用更少样本达到较优性能。

## 批判性小综述

对该研究的证据边界判断：它支持视觉解释区域可作为 selection feature，但 saliency 稳定性与标签泄漏风险大，主动标注也不同于 replay。 反向约束：不能把 saliency 强度直接叫可学习性或目标对齐，也不能用 test 解释图选训练样本。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5；其可迁移链条是：Stage1 可把 defect 区域显著图或局部 embedding 仅作为 D/Q 分层，并用同预算随机干预验证。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 defect 区域显著图或局部 embedding 仅作为 D/Q 分层，并用同预算随机干预验证。 禁止外推：不能把 saliency 强度直接叫可学习性或目标对齐，也不能用 test 解释图选训练样本。
