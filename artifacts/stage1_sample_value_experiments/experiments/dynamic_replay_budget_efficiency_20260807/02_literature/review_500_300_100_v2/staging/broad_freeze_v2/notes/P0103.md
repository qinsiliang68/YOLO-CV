# P0103 - Machine Learning for Security and Beyond: From Threat Detection to Coreset Selection for Efficient Learning

## 独立中文摘要

问题：通用 coreset 在样本难度与类别身份相关时会产生选择偏差，无标签选择又会受伪标签错误影响。 方法：论文集成多个工作，核心数据效率部分提出 class-aware coreset 变体，并以无监督聚类估计难度、通过 pruning 缓解伪标签偏差。 结论：学位论文摘要称类别感知方法提升鲁棒性和泛化，无标签 coreset 在缺少真标签时仍能有效选择数据。
