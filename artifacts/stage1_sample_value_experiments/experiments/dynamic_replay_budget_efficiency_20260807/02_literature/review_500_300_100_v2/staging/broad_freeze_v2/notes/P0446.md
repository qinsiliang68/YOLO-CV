# P0446 - Adaptive Integration of Partial Label Learning and Negative Learning for Enhanced Noisy Label Learning

## 独立中文摘要

问题：噪声标签学习常依赖预设噪声率或小型干净集，遇到不同噪声来源时假设容易失效。 方法：NPN 自适应拆分候选与互补标签，联合部分标签学习和负学习，并用多增强一致性维持后期标签可靠性。 结论：合成噪声和真实噪声数据实验摘要报告优于多种噪声标签方法。

## 批判性小综述

对该研究的证据边界判断：它主要重构监督信号而非选择有限 replay 集；性能可能来自标签空间处理与一致性正则。 反向约束：不能从 noisy-label accuracy 推出某个 reliability 阈值，也不能把间接监督收益算成样本选择收益。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6,RQ7；其可迁移链条是：Stage1 的 Q 层可记录增强一致性和候选标签可靠性，但本轮不得把标签修复和 replay 选择同时改变。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 Q 层可记录增强一致性和候选标签可靠性，但本轮不得把标签修复和 replay 选择同时改变。 禁止外推：不能从 noisy-label accuracy 推出某个 reliability 阈值，也不能把间接监督收益算成样本选择收益。
