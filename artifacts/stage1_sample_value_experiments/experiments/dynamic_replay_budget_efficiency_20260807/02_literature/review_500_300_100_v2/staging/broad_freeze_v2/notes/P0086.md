# P0086 - Towards High Supervised Learning Utility Training Data Generation: Data Pruning and Column Reordering

## 独立中文摘要

问题：合成表格数据常放大类别不平衡并忽略监督变量关系，使其训练效用低于原始数据。 方法：PRRO 先剪枝引导生成器聚焦高信噪样本并保持类分布，再重排列顺序使生成结构贴近监督模型。 结论：二十二套公开数据上报告合成替代或追加训练的平均效用提升，六套不平衡数据类分布相似度也提高。

## 批判性小综述

对该研究的证据边界判断：pruning、生成器和列顺序同时改变，极大百分比提升可能来自低基线；2025 预印本需核验随机与 seed。 反向约束：不能把所谓高信噪样本直接定义为高 utility，也不能把表格列重排迁移到图像 replay。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ5,RQ7；其可迁移链条是：可支持 Q 与类别构成必须先于生成/回流，并要求合成或增强样本与真实样本分开记账。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可支持 Q 与类别构成必须先于生成/回流，并要求合成或增强样本与真实样本分开记账。 禁止外推：不能把所谓高信噪样本直接定义为高 utility，也不能把表格列重排迁移到图像 replay。
