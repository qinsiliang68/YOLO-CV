# P0356 - Neyman-Pearson Multi-class Classification via Cost-sensitive Learning

## 独立中文摘要

问题：多分类各类错误后果不对称，NP 约束的可行性本身未知，普通 cost-sensitive 加权缺少约束保证。 方法：论文以强对偶连接多分类 NP 与成本敏感问题，提出算法、NP oracle 性质及可行性诊断。 结论：作者报告模拟和真实数据支持，并提供 R 包实现。

## 批判性小综述

对该研究的证据边界判断：它说明约束不可行必须显式报告而非用加权损失掩盖；Stage1 是二分类但同样可能某 run 无 FN95 可行点。 反向约束：不能由 cost-sensitive 对偶给出 replay 价值，也不能把代价权重当综合分。
