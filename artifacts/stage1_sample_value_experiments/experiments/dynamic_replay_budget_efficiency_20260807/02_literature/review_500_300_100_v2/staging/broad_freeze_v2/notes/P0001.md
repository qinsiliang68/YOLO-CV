# P0001 - Selecting Demonstrations for Many-Shot In-Context Learning via Gradient Matching

## 独立中文摘要

问题：many-shot ICL 的上下文预算有限，逐实例检索不适合大示例集合。 方法：方法在小模型上匹配候选示例子集与目标任务全训练集的微调梯度，再把所选 demonstrations 用于更大模型。 结论：九个数据集、4 至 128 shot 中报告持续优于随机，并可跨模型规模迁移。

## 批判性小综述

对该研究的证据边界判断：示例进入上下文而非 SGD replay，梯度由小代理模型计算；可能存在跨模型和任务泄漏。 反向约束：不能把 ICL 上下文选择结果当训练样本因果价值，也不能声称全梯度匹配已被复现。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ6,RQ7；其可迁移链条是：Stage1 可检验小模型或 head-gradient 作为 A/D 候选是否能迁移到 yolo11l，但必须与真实重训校准。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可检验小模型或 head-gradient 作为 A/D 候选是否能迁移到 yolo11l，但必须与真实重训校准。 禁止外推：不能把 ICL 上下文选择结果当训练样本因果价值，也不能声称全梯度匹配已被复现。
