# P0390 - Weakly Supervised AUC Optimization: A Unified Partial AUC Approach

## 独立中文摘要

问题：弱监督中的标签污染会使普通 AUC 风险有偏，整体 AUC 又平均了与业务无关的 ROC 区域。 方法：WSAUC 把噪声、正未标注、多实例和半监督 AUC 写成污染集风险，并提出 reversed partial AUC 作为鲁棒局部目标。 结论：作者给出一致性分析，并在多种弱监督设定中报告理论和实验支持。

## 批判性小综述

对该研究的证据边界判断：该工作支持同时限定正负尾部的局部 pairwise 目标，但 rpAUC 的方向、污染假设和 surrogate 必须精读后才能映射 FN95。 反向约束：不能把 rpAUC 直接等同 FN=0至95 raw frontier AUC，也不能用同一 val_op 既构造目标又评价方法。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ8；其可迁移链条是：Stage1 的 A 可由独立 val_target 上 weak-defect 与 dangerous-normal 成对损失构造，并与全局 CE 对齐做消融。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 A 可由独立 val_target 上 weak-defect 与 dangerous-normal 成对损失构造，并与全局 CE 对齐做消融。 禁止外推：不能把 rpAUC 直接等同 FN=0至95 raw frontier AUC，也不能用同一 val_op 既构造目标又评价方法。
