# P0462 - Self-Paced Curriculum Learning for Visual Question Answering on Remote Sensing Data

## 独立中文摘要

问题：论文研究遥感视觉问答中问题难度差异是否应通过训练阶段课程和自步权重处理。 方法：方法把问题类型先验和长度作为初始难度，再依据上一 epoch 的损失范围更新年龄阈值，比较硬权重、软权重和联合课程。 结论：两套数据与三次训练显示软 SPCL 总体改善，但部分问题类型或设置中基线及其他变体更好。

## 批判性小综述

对该研究的证据边界判断：没有同预算随机样本对照，且课程只在早期十五轮初始化权重，增益不能归因于持续动态 replay。 反向约束：不能推出从易到难适合 Stage1，也不能把三次运行视为跨 seed 稳定确认。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ5,RQ8；其可迁移链条是：可迁移的是 epoch lag、先验与当前状态分离、软权重消融，以及训练早期 loss 尚不可靠这一风险。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是 epoch lag、先验与当前状态分离、软权重消融，以及训练早期 loss 尚不可靠这一风险。 禁止外推：不能推出从易到难适合 Stage1，也不能把三次运行视为跨 seed 稳定确认。
