# P0003 - GRAD-MATCH: Gradient Matching based Data Subset Selection for Efficient Deep Model Training

## 独立中文摘要

问题：需要在有限计算下找出能近似全训练集或验证集更新方向的子集。 方法：GRAD-MATCH 用正交匹配追踪选择加权子集，使其梯度逼近训练或验证目标梯度，并给出收敛保证。 结论：作者报告在真实数据上优于多种选择算法并取得较好精度-效率权衡。

## 批判性小综述

对该研究的证据边界判断：后续严格研究指出最后层梯度匹配在公平预算和多 seed 下未必优于随机；匹配全梯度也不等于匹配 FN95 效用。 反向约束：不能把原论文正结果视为跨 seed 稳压结论，也不能用最后层近似冒充完整 influence。
