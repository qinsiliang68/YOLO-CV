# P0024 - Toward improving global rice yield reference dataset compilation through machine learning: Insights from training data selection and random forest analysis

## 独立中文摘要

问题：全球产量模型的可预测范围受训练数据覆盖的产量区间和地理范围限制。 方法：研究用不同产量范围、地域覆盖和变量集合构建随机森林训练集，再在验证区域比较外推误差。 结论：训练集未覆盖的产量范围无法可靠复现；覆盖目标区间比单纯增加变量更关键。

## 批判性小综述

对该研究的证据边界判断：随机森林回归与图像 replay 不同，但明确展示覆盖支持集是泛化的必要条件。 反向约束：不能把地理坐标重要性迁移为图像来源捷径，也不能推断均匀覆盖一定优于目标方向选择。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ5,RQ7；其可迁移链条是：Stage1 的 D 层应报告危险 normal 与弱 defect 的来源、分数区间和视觉簇覆盖，避免只追极端尾部。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 D 层应报告危险 normal 与弱 defect 的来源、分数区间和视觉簇覆盖，避免只追极端尾部。 禁止外推：不能把地理坐标重要性迁移为图像来源捷径，也不能推断均匀覆盖一定优于目标方向选择。
