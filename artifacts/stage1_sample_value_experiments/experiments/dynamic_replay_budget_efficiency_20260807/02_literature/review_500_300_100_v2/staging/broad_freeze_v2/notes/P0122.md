# P0122 - Inter-domain curriculum learning for domain generalization

## 独立中文摘要

问题：多个源域随机混合训练时，域间冲突梯度会使优化不稳定并削弱对未见目标域的泛化。 方法：IDCL 按域复杂度安排暴露顺序，让模型从较简单源域逐步进入较复杂源域，并与随机混合域训练比较。 结论：PACS 与 Office-Home 上报告显著改善，并相对当时方法提高 1.08%。

## 批判性小综述

对该研究的证据边界判断：本批只有 DOI 元数据与摘要；研究操纵的是域顺序而非样本 replay，且域难度与梯度冲突没有逐样本因果分解。 反向约束：不能由域课程推出某个样本的 alignment，也不能把 1.08% 平均准确率解释为 FN95-tail 效用。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ6；其可迁移链条是：Stage1 可据此把 source/video block 的顺序与混合方式列为 draw-plan 因子，并记录跨来源梯度冲突。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可据此把 source/video block 的顺序与混合方式列为 draw-plan 因子，并记录跨来源梯度冲突。 禁止外推：不能由域课程推出某个样本的 alignment，也不能把 1.08% 平均准确率解释为 FN95-tail 效用。
