# P0193 - Language Model-Driven Data Pruning Enables Efficient Active Learning

## 独立中文摘要

问题：论文研究主动学习每轮扫描巨大未标注池成本过高时，怎样先过滤噪声并持续覆盖未代表区域，再交给任意 acquisition function。 方法：ActivePrune 先用廉价 n-gram perplexity保留常规样本，再用量化 LLM 审核高困惑样本的任务质量，并依据新标注样本的困惑度距离动态重权以促进后续覆盖。 结论：四类 NLP 任务、四种主动学习策略和三个 seed 中，方法多数优于随机池剪枝及其他质量筛选，同时将池剪枝时间降低约九成七、端到端时间最多降低约七成四。

## 批判性小综述

对该研究的证据边界判断：它同时使用外部语言模型质量先验和主动标注，重权距离只在一维困惑度空间；部分分类设置与无剪枝或随机差距很小，公平与子群风险未评估。 反向约束：不能把低 perplexity 或 LLM 质量分数迁移到图像任务，也不能据此证明动态覆盖后的已标注 replay 能跨 seed 稳压随机。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ5,RQ6,RQ7；其可迁移链条是：Stage1 可迁移两阶段 Q 门控、每轮覆盖刷新和欠代表样本探索，但应改用图像与视频身份特征，并精确匹配实际 replay 曝光。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移两阶段 Q 门控、每轮覆盖刷新和欠代表样本探索，但应改用图像与视频身份特征，并精确匹配实际 replay 曝光。 禁止外推：不能把低 perplexity 或 LLM 质量分数迁移到图像任务，也不能据此证明动态覆盖后的已标注 replay 能跨 seed 稳压随机。
