# P0230 - GORACS: Group-level Optimal Transport-guided Coreset Selection for LLM-based Recommender Systems

## 独立中文摘要

问题：逐样本重要性选择可能偏离下游微调目标，并因忽略群组结构而损害泛化。 方法：GORACS 用最优传输与梯度信息构造测试损失代理上界，再通过初始化和细化两阶段做群组级选择。 结论：多个推荐数据集与任务的摘要结果报告其降低 LLM 微调成本，并优于选择基线和全数据训练。

## 批判性小综述

对该研究的证据边界判断：代理目标使用测试损失表述，实际数据角色必须查全文；推荐任务和群组定义也与 CCTV 不同。 反向约束：不能照搬其最优传输系数，也不能在数据角色未核清前把结果视为无泄漏证据。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ3,RQ5,RQ7；其可迁移链条是：Stage1 的选择单位应比较单帧与视频群组，并要求 A 目标来自独立 val_target 而非 val_op 或 test。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的选择单位应比较单帧与视频群组，并要求 A 目标来自独立 val_target 而非 val_op 或 test。 禁止外推：不能照搬其最优传输系数，也不能在数据角色未核清前把结果视为无泄漏证据。
