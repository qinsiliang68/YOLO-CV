# P0148 - CLIPCleaner: Cleaning Noisy Labels with CLIP

## 独立中文摘要

问题：论文指出由在训模型自身的小损失或高置信选择干净样本会产生 self-confirmation bias，且相近类别间 hard noise 更难识别。 方法：CLIPCleaner 用与当前训练过程解耦的 CLIP 零样本分类器做一次性离线干净样本选择，并利用视觉语言语义关系处理 hard noise。 结论：理论分析与多个噪声标签基准显示该简单离线选择可达到竞争性或更好结果，减少了在训模型循环自证。

## 批判性小综述

对该研究的证据边界判断：外部大模型携带额外数据和语义先验，比较并非只改变选择规则；工业缺陷类别也未必有可用文本语义。 反向约束：不能把 CLIP 置信度当作真实标签，也不能将外部预训练优势归因于 replay 样本本身。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ7；其可迁移链条是：Stage1 可设置独立 OOF reference 以减少 current-model self-confirmation，并检查 Q 判断与当前 run 是否解耦。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可设置独立 OOF reference 以减少 current-model self-confirmation，并检查 Q 判断与当前 run 是否解耦。 禁止外推：不能把 CLIP 置信度当作真实标签，也不能将外部预训练优势归因于 replay 样本本身。
