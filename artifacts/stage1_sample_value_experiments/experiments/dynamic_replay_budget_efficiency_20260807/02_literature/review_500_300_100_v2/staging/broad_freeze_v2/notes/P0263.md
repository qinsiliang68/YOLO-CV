# P0263 - Automatic Lecture Transcription Based on Discriminative Data Selection for Lightly Supervised Acoustic Model Training

## 独立中文摘要

问题：轻监督语音训练用演讲字幕产生自动标签，但字幕与识别片段错配会使新增数据有害，必须区分可用和不可用样本。 方法：方法对齐字幕和自动语音识别假设，用判别分类器选择可靠配对，并拒绝两种文本都不能可靠匹配的片段，再将筛选数据用于声学模型训练。 结论：实验表明判别选样后的轻监督数据能改善自动讲座转写，并优于简单文本匹配式筛选。

## 批判性小综述

对该研究的证据边界判断：该方法依赖语音文本对齐特征且没有 Stage1 的高召回尾部目标；不过它提供了先做可靠性判别、再用同预算增量训练验证的直接干预范式。 反向约束：不能由 ASR 的词错误率结果推断图片 OOF 可靠性阈值，也不能声称其分类器可区分 hard-clean 与 weak defect。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ7；其可迁移链条是：Stage1 可迁移双重一致性门控思想：照片必须同时通过标签可靠性和跨轨迹一致性检查，极端高 loss 不能自动获得 replay 资格。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移双重一致性门控思想：照片必须同时通过标签可靠性和跨轨迹一致性检查，极端高 loss 不能自动获得 replay 资格。 禁止外推：不能由 ASR 的词错误率结果推断图片 OOF 可靠性阈值，也不能声称其分类器可区分 hard-clean 与 weak defect。
