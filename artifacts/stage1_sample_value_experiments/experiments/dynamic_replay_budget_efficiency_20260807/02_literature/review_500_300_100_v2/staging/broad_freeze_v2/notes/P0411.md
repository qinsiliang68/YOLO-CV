# P0411 - Imbalanced Sample Selection With Deep Reinforcement Learning for Fault Diagnosis

## 独立中文摘要

问题：工业故障与正常样本极度不平衡，固定采样比例可能损害诊断性能。 方法：DiagSelect 把训练样本选择写成多臂老虎机/MDP，用验证集反馈和 REINFORCE 学习选择策略。 结论：作者在合成和工业过程数据上报告有效、稳定并可迁移。

## 批判性小综述

对该研究的证据边界判断：强化学习选择器自由度高且可能过拟合验证集；来源目前只有 DOI 级方法证据，需核对 random 与 seed。 反向约束：不能直接迁移 learned policy，也不能由故障 accuracy 推出 FN95 安全收益。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ3,RQ5；其可迁移链条是：Stage1 可借鉴验证目标驱动的条件策略，但首轮应使用少自由度可证伪规则，避免 controller 搜索吞噬十机预算。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴验证目标驱动的条件策略，但首轮应使用少自由度可证伪规则，避免 controller 搜索吞噬十机预算。 禁止外推：不能直接迁移 learned policy，也不能由故障 accuracy 推出 FN95 安全收益。
