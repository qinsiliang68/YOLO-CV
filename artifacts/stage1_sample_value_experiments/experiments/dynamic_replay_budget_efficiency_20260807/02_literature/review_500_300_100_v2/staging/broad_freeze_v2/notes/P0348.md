# P0348 - Learning from Long-Tailed Noisy Data with Sample Selection and Balanced Loss

## 独立中文摘要

问题：长尾与标签噪声同时存在时，小损失选择会偏向多数类，普通 balanced loss 又可能放大噪声。 方法：方法先将噪声训练集选择成 clean labeled 与 unlabeled 两部分，再用基于模型偏差的 balanced loss 做半监督训练。 结论：作者在长尾噪声基准上报告优于既有方法。

## 批判性小综述

对该研究的证据边界判断：它说明 Q 门控必须做类别条件校准，不能用全局 loss 阈值；选择和 balanced loss 的贡献需筛读。 反向约束：不能由长尾平均准确率确定 weak-defect guard，也不能把 unlabeled 机制套到已确认标签。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ5；其可迁移链条是：Stage1 可在 normal/defect 内独立标准化 Q/R，并把类别重权与 replay 身份分开。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可在 normal/defect 内独立标准化 Q/R，并把类别重权与 replay 身份分开。 禁止外推：不能由长尾平均准确率确定 weak-defect guard，也不能把 unlabeled 机制套到已确认标签。
