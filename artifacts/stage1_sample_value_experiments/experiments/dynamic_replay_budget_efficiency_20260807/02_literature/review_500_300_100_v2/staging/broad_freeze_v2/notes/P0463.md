# P0463 - Optimizing partial receiver operating characteristic curve via curriculum learning and Neyman–Pearson criterion for robust underwater acoustic target detection

## 独立中文摘要

问题：稀有水下目标检测在低信噪与类别不平衡下以 ROC 局部区域评价，普通 BCE 优化平均准确率与业务目标错位。 方法：论文提出直接 AUC 损失，再引入 Neyman-Pearson 准则，以课程方式逐步优化 pAUC，并结合空中到水下的跨域迁移。 结论：作者报告 AUC/pAUC 损失在低信噪和失配条件下优于 BCE 并达到所述先进性能。

## 批判性小综述

对该研究的证据边界判断：课程、局部目标和跨域预训练共同改变；摘要未隔离各自贡献，也没有研究训练样本 replay 选择。 反向约束：不能由声学 pAUC 结果决定 defect tail 比例、margin 或课程周期，也不能替代真实样本回流干预。

## Stage1 直接相关链

该研究直接映射到 RQ6,RQ8；其可迁移链条是：Stage1 的 A 应由独立 FN95 局部 pairwise 目标定义，且可比较 BCE 目标梯度与局部目标梯度的方向差异。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 A 应由独立 FN95 局部 pairwise 目标定义，且可比较 BCE 目标梯度与局部目标梯度的方向差异。 禁止外推：不能由声学 pAUC 结果决定 defect tail 比例、margin 或课程周期，也不能替代真实样本回流干预。
