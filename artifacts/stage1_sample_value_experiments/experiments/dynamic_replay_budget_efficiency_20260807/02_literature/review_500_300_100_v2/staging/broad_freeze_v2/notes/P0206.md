# P0206 - Intentional control of type I error over unconscious data distortion: a Neyman-Pearson classification approach

## 独立中文摘要

问题：审查或非代表性抽样会以未知方式改变类别比例，使经典分类和总体指标产生数据扭曲。 方法：论文推导含两类扭曲率的 after-distortion oracle，证明 NP oracle 在一般条件下对扭曲机制不变，并结合 NP umbrella 与主题模型。 结论：作者在微博敏感事件检测中展示即使经典框架 type I error 很高，也可将其控制在目标上界。

## 批判性小综述

对该研究的证据边界判断：它提示固定错误约束可能比类别比例更稳健，但独立同分布和扭曲假设需精读，不能掩盖 covariate shift。 反向约束：不能由 NP 不变性断言选择偏差无害，也不能从社交文本得到 replay 样本排序。
