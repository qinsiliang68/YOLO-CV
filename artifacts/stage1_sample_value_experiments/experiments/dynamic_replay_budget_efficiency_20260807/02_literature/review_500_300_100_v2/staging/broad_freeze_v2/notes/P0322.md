# P0322 - MHD-Protonet: Margin-Aware Hard Example Mining for SAR Few-Shot Learning via Dual-Loss Optimization

## 独立中文摘要

问题：SAR 少样本分类同时受类间散射相似和类内噪声、姿态与俯角变化影响，普通 prototype 难以拉开混淆类。 方法：MHD-ProtoNet 结合 margin-aware hard example mining 与双损失优化，对混淆样本施加 prototype 距离间隔并改善噪声鲁棒表征。 结论：作者在 MSTAR 五路一样本任务上报告百分之七十六点八准确率，高于所列 prototype、图模型及 HIN 基线。

## 批判性小综述

对该研究的证据边界判断：这是 hardness 有时有效的支持证据，但选样、margin 和双损失同时变化，且单一数据集与 seed 无法证明 hard-only utility。 反向约束：不能由 few-shot meta-learning 的准确率断言极端 normal HN 应回流，也不能把多组件收益归给 hard mining。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ6；其可迁移链条是：Stage1 应保留旧 HN 作为正当对照，同时通过固定 loss 和 sampler 分离 margin、Q 与 replay 的贡献。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应保留旧 HN 作为正当对照，同时通过固定 loss 和 sampler 分离 margin、Q 与 replay 的贡献。 禁止外推：不能由 few-shot meta-learning 的准确率断言极端 normal HN 应回流，也不能把多组件收益归给 hard mining。
