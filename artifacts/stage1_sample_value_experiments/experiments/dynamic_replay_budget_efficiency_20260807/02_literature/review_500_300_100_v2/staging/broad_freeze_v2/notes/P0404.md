# P0404 - Sample Selection Approach with Number of False Predictions for Learning with Noisy Labels

## 独立中文摘要

问题：单次 loss 无法稳定区分干净与错标样本，而模型在记忆噪声前后的错误预测历史包含可利用的时间信息。 方法：SSFP 周期记录每个样本最近窗口中的错误预测次数，用双成分 GMM 选低错误计数样本，再用更新后的训练集继续训练并反复刷新。 结论：CIFAR-10 和 CIFAR-100 合成噪声实验达到或超过当时多种噪声学习方法，并对记录频率、选择频率和窗口长度做了消融。

## 批判性小综述

对该研究的证据边界判断：错误预测计数仍以给定标签为参照且主要识别 clean，而不是估计额外 replay 的正向边际效用；随机基线和高召回局部目标也不充分。 反向约束：不能由低错误次数推出样本值得重复学习，也不能把合成标签噪声的 GMM 分界迁移成固定生产阈值。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6；其可迁移链条是：Stage1 应保留 rolling false-prediction count、窗口长度和身份转换历史，作为 Q 可靠性分型，而不是直接当作最终价值排名。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应保留 rolling false-prediction count、窗口长度和身份转换历史，作为 Q 可靠性分型，而不是直接当作最终价值排名。 禁止外推：不能由低错误次数推出样本值得重复学习，也不能把合成标签噪声的 GMM 分界迁移成固定生产阈值。
