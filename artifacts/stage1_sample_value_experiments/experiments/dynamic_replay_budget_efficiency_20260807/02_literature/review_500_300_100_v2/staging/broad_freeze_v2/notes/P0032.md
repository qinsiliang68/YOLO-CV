# P0032 - DsDm: Model-Aware Dataset Selection with Datamodels

## 独立中文摘要

问题：论文把数据选择定义为：在给定学习算法随机性和目标分布下，选择能最小化目标损失的子集，而非按样本自身难度排序。 方法：方法用多个随机子集训练结果拟合线性 datamodel，并借助 TRAK 近似每个样本对目标集合损失的贡献，再按预测贡献选择数据。 结论：在语言模型预训练中，DsDm 在等 token 计算下常优于随机、DSIR 和分类器筛选；反向选择的有害集合显著更差，但针对单一任务优化也会伤害其他任务。

## 批判性小综述

对该研究的证据边界判断：随机基线很强，目标集合构成决定结果，且方法需大量子集训练来拟合 datamodel；这说明价值是目标和训练过程条件化的，不是廉价静态属性。 反向约束：不能据此声称 TRAK 分数就是因果价值，也不能将某一目标上的优选集合外推为所有预算、seed 或业务尾部都有效。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5,RQ7,RQ8；其可迁移链条是：Stage1 可迁移独立 val_target、目标特异贡献、anti-selection 负对照和集合级真实干预，同时必须让 test 与方法构造完全隔离。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移独立 val_target、目标特异贡献、anti-selection 负对照和集合级真实干预，同时必须让 test 与方法构造完全隔离。 禁止外推：不能据此声称 TRAK 分数就是因果价值，也不能将某一目标上的优选集合外推为所有预算、seed 或业务尾部都有效。
