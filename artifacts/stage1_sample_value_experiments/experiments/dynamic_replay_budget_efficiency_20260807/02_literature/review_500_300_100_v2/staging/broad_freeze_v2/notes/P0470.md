# P0470 - $\gamma$<i>-Razor</i>: Hardness-Aware Dataset Pruning for Efficient Neural Network Training

## 独立中文摘要

问题：大规模训练含有大量低边际信息样本，但只保留最难样本会破坏类别和类内代表性。 方法：gamma-Razor 先用 inverse self-paced 策略按各类有效样本频率自适应学习困难样本，再在类内用 hardness-aware clustering 下采样容易样本。 结论：三个大规模图像分类数据上，裁剪集在鲁棒性与效率上接近或优于全量，并报告更快收敛和更低能耗。

## 批判性小综述

对该研究的证据边界判断：本批只取得 DOI 注册元数据与摘要，不能声称已核对全文公式、随机 seed 或完整消融；hardness 与 clustering 也同时变化。 反向约束：不能据此确认极难样本被排除的阈值，也不能声称该方法已严格超过 matched random。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5；其可迁移链条是：Stage1 可把中高难度保留与类内/视频覆盖做成两步 selector，但应把 hardness-only 与 hardness+D 分开。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把中高难度保留与类内/视频覆盖做成两步 selector，但应把 hardness-only 与 hardness+D 分开。 禁止外推：不能据此确认极难样本被排除的阈值，也不能声称该方法已严格超过 matched random。
