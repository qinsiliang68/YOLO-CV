# P0129 - Pre-training a BERT with Curriculum Learning by Increasing Block-Size of Input Text

## 独立中文摘要

问题：BERT 预训练成本高，固定长序列会在早期浪费大量 self-attention 计算。 方法：课程逐步增加输入文本 block size，并使用当前阶段允许的最大 batch size。 结论：低资源实验报告收敛更快且下游性能优于固定策略。

## 批判性小综述

对该研究的证据边界判断：它调整输入长度、batch size 和计算量，不是选择具体样本；混杂因素很强。 反向约束：不能从 block-size 课程推断图片难度顺序，也不能把速度收益当样本价值。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ6,RQ7；其可迁移链条是：Stage1 可借鉴先便宜后昂贵的阶段预算思想，但 replay 样本、batch 和基础曝光必须保持可比。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴先便宜后昂贵的阶段预算思想，但 replay 样本、batch 和基础曝光必须保持可比。 禁止外推：不能从 block-size 课程推断图片难度顺序，也不能把速度收益当样本价值。
