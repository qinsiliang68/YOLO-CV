# P0429 - Airport Detection Using End-to-End Convolutional Neural Network with Hard Example Mining

## 独立中文摘要

问题：论文研究机场与复杂背景严重不平衡时，在线高损失正负样本挖掘能否改善检测。 方法：HEM 层在每次迭代按分类与定位损失联合选择正负候选，并配合正负类分别归一化的 weight-balanced loss。 结论：五折数据划分下，HEM 的最终 AP 高于随机、启发式和仅困难负例挖掘，并改善精确率召回率折中。

## 批判性小综述

对该研究的证据边界判断：HEM 与平衡损失、检测架构耦合，表格没有报告跨初始化方差，因而无法确认样本规则本身的稳定因果效应。 反向约束：不能据此推翻旧 Stage1 的随机结果，也不能认为高 loss 在所有二分类任务中都正向。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ6,RQ7；其可迁移链条是：可保留为 hardness 可能有用的正例，但必须拆开正负方向、同预算随机和业务局部前沿后再迁移。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可保留为 hardness 可能有用的正例，但必须拆开正负方向、同预算随机和业务局部前沿后再迁移。 禁止外推：不能据此推翻旧 Stage1 的随机结果，也不能认为高 loss 在所有二分类任务中都正向。
