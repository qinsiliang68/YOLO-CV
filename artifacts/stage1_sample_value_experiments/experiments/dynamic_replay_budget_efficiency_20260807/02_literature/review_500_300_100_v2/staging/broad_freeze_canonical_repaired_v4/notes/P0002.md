# P0002 - Agree to Disagree: Robust Anomaly Detection with Noisy Labels

## 独立中文摘要

问题：异常类稀少且标签噪声高，纯 clean selection 找不到足够异常，纯 label refurbishment 又会错误修改边缘但真实的干净样本。 方法：Unity 用双异常网络按预测一致性选 clean，再用 disagreement resolution 找回边缘 clean，剩余样本经 anomaly-centric contrastive learning 修复标签，下一轮迭代训练。 结论：十个真实异常检测数据上，相对多种噪声学习方法最高将 F1 从 0.52 提到 0.83，并强调最终 clean set 的多样性。

## 批判性小综述

对该研究的证据边界判断：本批只核验 DOI 元数据和正式摘要；选择、修标、双网络和对比学习耦合，不能把提升归因于 disagreement 样本。 反向约束：不能由异常检测 F1 推出 defect replay 比例，也不能在未全文筛读前声称其随机对照、seed 或消融足够。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ5,RQ6；其可迁移链条是：Stage1 的 weak defect 不应被 Q 门控一刀切掉；应记录 agreement/disagreement，并把边缘可靠样本作为单独 guard 候选或人工审查层。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 weak defect 不应被 Q 门控一刀切掉；应记录 agreement/disagreement，并把边缘可靠样本作为单独 guard 候选或人工审查层。 禁止外推：不能由异常检测 F1 推出 defect replay 比例，也不能在未全文筛读前声称其随机对照、seed 或消融足够。
