# P0354 - Combination of Active Learning and Self-Paced Learning for Deep Answer Selection with Bayesian Neural Network

## 独立中文摘要

问题：主动学习依赖可靠 uncertainty，而半监督 self-paced 又会受错误伪标签影响，单独使用任一策略都可能浪费标注或放大噪声。 方法：框架用 Bayesian neural network 估计 uncertainty，在同一迭代流程中让低置信候选进入主动标注、较可靠伪标签进入 self-paced 学习。 结论：YahooCQA 与 SemEvalCQA 的两类深度 answer-selection 模型上，作者报告在保持性能时显著减少所需标注样本。

## 批判性小综述

对该研究的证据边界判断：它优化标注预算而非额外训练曝光，且人工标签反馈改变了信息条件；只有出版页面摘要，不能声称核验全部算法细节。 反向约束：不能把 Bayesian uncertainty 当作价值，也不能由少标注结果推出同预算 replay 超过 random。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6；其可迁移链条是：Stage1 可借鉴 exploration 与 exploitation 分流：不可靠高影响样本进入人工复核，可靠且可约样本才进入 replay。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴 exploration 与 exploitation 分流：不可靠高影响样本进入人工复核，可靠且可约样本才进入 replay。 禁止外推：不能把 Bayesian uncertainty 当作价值，也不能由少标注结果推出同预算 replay 超过 random。
