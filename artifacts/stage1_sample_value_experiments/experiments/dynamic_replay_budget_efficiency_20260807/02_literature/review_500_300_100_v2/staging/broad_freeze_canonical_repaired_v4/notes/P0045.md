# P0045 - Task-Free Continual Learning via Online Discrepancy Distance Learning

## 独立中文摘要

问题：无任务边界的非平稳数据流中，memory buffer 与累积知识分布失配会造成遗忘。 方法：ODDL 用 discrepancy distance 触发混合模型动态扩展，并按与累积知识的相关性选择样本存入 buffer。 结论：作者给出基于 discrepancy 的泛化分析，并报告多项 TFCL 实验达到较好性能。

## 批判性小综述

对该研究的证据边界判断：网络扩展与 buffer 选择同时改变，continual stream 也不同于固定训练集追加曝光。 反向约束：不能把最相关 memory 等同高价值图片，也不能由抗遗忘结果推出 FN95 改善。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5,RQ6；其可迁移链条是：Stage1 可把当前 replay 集与 base/target 分布的 discrepancy 作为 D/set 特征，并记录随 epoch 演化。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把当前 replay 集与 base/target 分布的 discrepancy 作为 D/set 特征，并记录随 epoch 演化。 禁止外推：不能把最相关 memory 等同高价值图片，也不能由抗遗忘结果推出 FN95 改善。
