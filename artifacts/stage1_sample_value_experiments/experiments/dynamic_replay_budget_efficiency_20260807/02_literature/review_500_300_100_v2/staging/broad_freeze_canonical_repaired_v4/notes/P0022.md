# P0022 - Class-Independent Regularization for Learning with Noisy Labels

## 独立中文摘要

问题：论文研究类别相关 softmax 在噪声标签下产生选择偏差的问题，试图区分干净难样本与错误标签。 方法：方法并行训练类别相关分类器和逐类二元分类器，先由类别自适应阈值选高置信样本训练二元模型，再由两类预测一致性筛干净集并将其余样本作半监督处理。 结论：作者在合成与真实噪声基准上报告更好的干净样本识别 F1 和分类精度，消融支持类别自适应阈值、半监督处理及负类掩码的作用。

## 批判性小综述

对该研究的证据边界判断：选择可靠性依赖双分类器结构和动态类别阈值；正文没有给出与有限预算 replay、累计曝光和 FN95 目标相配的因果证据。 反向约束：不能把预测一致性直接视为标签真值，也不能推出通过 Q 门控后的样本一定比随机回流更有价值。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ8；其可迁移链条是：可迁移的是将高损失拆成 hard-clean 与 noisy-risk，并把类别条件阈值和跨模型一致性作为 Q 门控候选字段。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是将高损失拆成 hard-clean 与 noisy-risk，并把类别条件阈值和跨模型一致性作为 Q 门控候选字段。 禁止外推：不能把预测一致性直接视为标签真值，也不能推出通过 Q 门控后的样本一定比随机回流更有价值。
