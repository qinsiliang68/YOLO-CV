# P0441 - Neyman-Pearson multiclass classification under label noise via empirical likelihood

## 独立中文摘要

问题：论文研究存在标签噪声时，如何在多分类 Neyman-Pearson 约束下控制指定类别错误并优化其余错误。 方法：方法使用经验似然和 EM 思路估计噪声转移与约束分类器，并给出可识别条件、误差控制和 oracle 型理论结果。 结论：模拟重复和真实数据实验显示，在假设成立时方法可接近使用真实噪声信息的 oracle 错误控制。

## 批判性小综述

对该研究的证据边界判断：这是约束分类目标研究而非训练样本 replay 研究，且其噪声模型与有限样本尾部误差控制假设需要单独核验。 反向约束：不能据此选择任何具体训练照片，也不能证明某种 Q、R、A 或 D 代理能够优于随机回流。
