# P0200 - DeepCore: A Comprehensive Library for Coreset Selection in Deep Learning

## 独立中文摘要

问题：各 coreset 方法使用不同模型、数据和预算，缺少统一实现与公平横向比较。 方法：DeepCore 统一实现并在 CIFAR-10 与 ImageNet 上比较多类几何、损失、梯度和训练动态选样方法。 结论：多种方法只在特定设置占优，随机选择仍是强基线。

## 批判性小综述

对该研究的证据边界判断：该基准支持方法与预算交互而非全局赢家，但 pruning 训练和 Stage1 额外 replay 的估计量不同。 反向约束：不能由某个基准的随机优势断言所有定向 replay 无效。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ5,RQ6,RQ7；其可迁移链条是：Stage1 应用统一后端、严格预算和多 seed 比较 Q/R/A/D 各层，而非用单次 top-k 结果定案。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应用统一后端、严格预算和多 seed 比较 Q/R/A/D 各层，而非用单次 top-k 结果定案。 禁止外推：不能由某个基准的随机优势断言所有定向 replay 无效。
