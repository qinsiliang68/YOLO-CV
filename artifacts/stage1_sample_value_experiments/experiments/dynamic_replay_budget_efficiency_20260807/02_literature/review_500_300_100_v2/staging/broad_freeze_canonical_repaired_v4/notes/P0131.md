# P0131 - A Distributional Framework for Data Valuation

## 独立中文摘要

问题：固定数据集 Shapley 只评价集合内点，无法表达样本相对总体分布的价值或对新样本的外推。 方法：Distributional Shapley 在底层数据分布上下文中定义样本价值，给出扰动稳定性性质和更快估计算法。 结论：论文摘要报告估计比既有非分布式 Shapley 快两个数量级，并在数据市场任务展示用途。

## 批判性小综述

对该研究的证据边界判断：价值仍依赖所选 utility、训练算法和参考分布，稳定性定理不等于深网 replay 的因果稳定性。 反向约束：不能由 Shapley 公理得到 Q/R/A/D 权重，也不能把静态估值当作动态回流成功率。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：Stage1 应把价值写成集合与训练状态条件量，并把全训练分布及来源 support 写入 D 层。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应把价值写成集合与训练状态条件量，并把全训练分布及来源 support 写入 D 层。 禁止外推：不能由 Shapley 公理得到 Q/R/A/D 权重，也不能把静态估值当作动态回流成功率。
