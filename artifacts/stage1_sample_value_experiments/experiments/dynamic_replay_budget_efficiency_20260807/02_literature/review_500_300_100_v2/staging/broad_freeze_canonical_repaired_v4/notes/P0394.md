# P0394 - Data Banzhaf: A Robust Data Valuation Framework for Machine Learning

## 独立中文摘要

问题：论文研究 SGD 随机性导致数据 Shapley 和 LOO 价值排名跨运行不稳定的问题。 方法：作者以集合效用的平均边际贡献定义 Banzhaf 值，证明其 semivalue 安全裕度最大，并用最大样本复用 Monte Carlo 估计。 结论：五 seed 稳定性和十三数据集加权训练显示 Banzhaf 排名更稳且常优于均匀权重，但并非每个数据集都取得最佳结果。

## 批判性小综述

对该研究的证据边界判断：效用计算需要反复训练大量子集，部分实验用 held-out test accuracy 构造效用，不适合直接作为 Stage1 开发协议。 反向约束：不能把 Banzhaf 分值直接算在十二万图上作为最终排名，也不能用测试集参与价值构造。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ4,RQ6,RQ8；其可迁移链条是：可迁移的是价值必须相对已选集合和随机训练取期望，并把跨 seed 排名稳定性独立于最终干预效用报告。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是价值必须相对已选集合和随机训练取期望，并把跨 seed 排名稳定性独立于最终干预效用报告。 禁止外推：不能把 Banzhaf 分值直接算在十二万图上作为最终排名，也不能用测试集参与价值构造。
