# P0176 - Competence-based Curriculum Learning for Neural Machine Translation

## 独立中文摘要

问题：统一随机训练忽略模型当前能力，困难样本过早进入可能使优化陷入坏局部区域。 方法：方法估计样本难度与模型 competence，用 pacing function 决定每个阶段可见的难度范围。 结论：作者在 RNN 与 Transformer NMT 上报告训练时间最多减少 70%、BLEU 最多提高 2.2。

## 批判性小综述

对该研究的证据边界判断：difficulty 与 competence 都是任务代理，课程改变样本可见次数；若不匹配累计曝光，无法归因时机。 反向约束：不能直接采用其 competence 曲线，也不能由翻译结果断言 hardest 样本有害。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6；其可迁移链条是：Stage1 可把 current-state 条件和 envelope 分开，并在相同累计曝光下比较持续、衰减和阶段刷新。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 current-state 条件和 envelope 分开，并在相同累计曝光下比较持续、衰减和阶段刷新。 禁止外推：不能直接采用其 competence 曲线，也不能由翻译结果断言 hardest 样本有害。
