# P0234 - Adaptive Hard Example Mining for Image Captioning

## 独立中文摘要

问题：图像描述的 RL 指标优化对低于模型期望的困难图像处理不足。 方法：方法用 beam search 估计每张图的描述得分期望，自动选择低于期望的样本，并对其高分 caption 加额外奖励。 结论：MSCOCO 实验报告该无额外调参的 hard mining 有效。

## 批判性小综述

对该研究的证据边界判断：所谓 hard 是相对自身期望而非绝对低分，但奖励与选样同时改变，且来源为摘要级。 反向约束：不能把 caption 奖励残差直接当分类可约损失，也不能忽略目标方向。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ6,RQ7；其可迁移链条是：Stage1 可比较绝对 current loss 与相对 OOF reference 的 RHO，验证减去参考难度是否真正增加价值。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可比较绝对 current loss 与相对 OOF reference 的 RHO，验证减去参考难度是否真正增加价值。 禁止外推：不能把 caption 奖励残差直接当分类可约损失，也不能忽略目标方向。
