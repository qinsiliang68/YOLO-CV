# P0250 - Self-Paced Learning with Adaptive Deep Visual Embeddings

## 独立中文摘要

问题：固定或随机呈现训练样本可能忽略不同训练阶段的可学习性，而只按交叉熵容易选择重复的简单样本。 方法：SPL-ADVisE 联合深度度量学习与自步学习，用 CE 衡量易度、用学习到的视觉 embedding 衡量真实多样性，动态组成 mini-batch。 结论：作者在多个粗粒度和细粒度视觉分类数据集上报告比其他自步方法收敛更快、最终准确率更高。

## 批判性小综述

对该研究的证据边界判断：它直接联合阶段性难度和覆盖度，但 easy-first 的收益可能来自优化稳定性而非样本长期 utility；严格随机基线和曝光预算需筛读。 反向约束：不能把低 CE 当作剩余可学习性，也不能由视觉分类平均准确率决定最优 replay 比例或 FN95 方向。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5,RQ6；其可迁移链条是：Stage1 可把 R 与 D 分开消融，采用 warm-up 后动态选择，并保留随机探索以避免早期表征误导。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 R 与 D 分开消融，采用 warm-up 后动态选择，并保留随机探索以避免早期表征误导。 禁止外推：不能把低 CE 当作剩余可学习性，也不能由视觉分类平均准确率决定最优 replay 比例或 FN95 方向。
