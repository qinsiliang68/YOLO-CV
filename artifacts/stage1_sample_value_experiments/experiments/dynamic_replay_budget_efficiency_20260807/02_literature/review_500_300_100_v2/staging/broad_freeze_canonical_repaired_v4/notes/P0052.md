# P0052 - Data Pruning for Efficient Model Pruning in Neural Machine Translation

## 独立中文摘要

问题：语言模型 movement pruning 需反复训练，使用全量机器翻译数据代价高。 方法：方法先在全量数据训练记录单实例交叉熵，再选 hard-to-learn Top-K，与随机、容易和分层数据剪枝比较后执行模型剪枝。 结论：作者报告两个翻译方向中困难样本取得更好 BLEU、减少收敛步数，并保留更多词汇。

## 批判性小综述

对该研究的证据边界判断：这是 hard Top-K 胜随机的直接反证，说明 hardness 不能先验否定；其收益可能来自长尾词覆盖和模型剪枝交互，需精读。 反向约束：不能由 NMT 词汇覆盖证明极端视觉难样本可学，也不能把模型剪枝交互效果归给通用样本价值。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5；其可迁移链条是：Stage1 应保留 HN 与 HN加覆盖两臂，并检查候选集合的视频/模式熵是否解释成败。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应保留 HN 与 HN加覆盖两臂，并检查候选集合的视频/模式熵是否解释成败。 禁止外推：不能由 NMT 词汇覆盖证明极端视觉难样本可学，也不能把模型剪枝交互效果归给通用样本价值。
