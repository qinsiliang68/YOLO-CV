# P0430 - Estimating Training Data Influence by Tracing Gradient Descent

## 独立中文摘要

问题：论文研究如何沿真实训练轨迹估计某个训练样本对特定测试预测的促进或反对作用，而不求逆 Hessian。 方法：TracIn 将多个保存检查点上的学习率加权梯度内积求和，用正负贡献区分 proponents 与 opponents。 结论：实验表明中期检查点能提供末轮模型没有的归因信息，并可用于错标检测和相似训练样本检索。

## 批判性小综述

对该研究的证据边界判断：该值是针对测试点与既有训练轨迹的归因近似，受检查点选择和最后一层近似影响，不等同于重训因果效用。 反向约束：不能由正 TracIn 分数断言 replay 一定改善安全前沿，也不能使用最终 test 探针构造训练选择。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ3,RQ4,RQ7,RQ8；其可迁移链条是：Stage1 可在关键 checkpoint 记录候选梯度与独立 FN95 探针梯度的点积、余弦和跨时点方向一致性。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可在关键 checkpoint 记录候选梯度与独立 FN95 探针梯度的点积、余弦和跨时点方向一致性。 禁止外推：不能由正 TracIn 分数断言 replay 一定改善安全前沿，也不能使用最终 test 探针构造训练选择。
