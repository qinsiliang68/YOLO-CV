# P0347 - Optimizing Two-Way Partial AUC With an End-to-End Framework

## 独立中文摘要

问题：普通 AUC 和单向 pAUC 不能同时聚焦高 TPR 与低 FPR 的 ROC 左上局部区域。 方法：论文定义 TPR≥alpha、FPR≤beta 的 two-way partial AUC，并构造可随机端到端训练的 surrogate，上界原目标且给出泛化分析。 结论：作者称这是首个 TPAUC 端到端优化框架，并在多数据集上验证有效。

## 批判性小综述

对该研究的证据边界判断：TPAUC 区域与 Stage1 的离散 FN≤95/FN=0..95 前沿近似相关但不完全等价；surrogate 参数仍需独立验证集。 反向约束：不能把 TPAUC loss 直接用于最终 test 选样，也不能让 val_op 同时承担目标构造和阈值冻结。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ8；其可迁移链条是：Stage1 可用 val_target 构造 weak-defect 与 dangerous-normal pairwise critical loss，作为 A 的目标梯度。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可用 val_target 构造 weak-defect 与 dangerous-normal pairwise critical loss，作为 A 的目标梯度。 禁止外推：不能把 TPAUC loss 直接用于最终 test 选样，也不能让 val_op 同时承担目标构造和阈值冻结。
