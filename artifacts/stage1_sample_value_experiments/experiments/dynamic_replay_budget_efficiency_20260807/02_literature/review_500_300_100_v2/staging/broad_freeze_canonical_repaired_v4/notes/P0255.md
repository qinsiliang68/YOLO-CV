# P0255 - Impact of Data Pruning on Machine Learning Algorithm Performance

## 独立中文摘要

问题：数据 pruning 是否会改变不同算法的相对排名并不清楚。 方法：论文在 IMDb 子集上迭代删去所谓次优元组，比较多种算法在原始和剪枝数据上的分类表现。 结论：原数据上较好的算法在剪枝后仍较好，未观察到算法排序反转。

## 批判性小综述

对该研究的证据边界判断：数据集与实验范围单一，pruning 定义和随机基线较弱，因此只能作为低强度证据。 反向约束：不能据此认为 pruning 对所有模型影响相同，也不能支持具体样本评分。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ6,RQ7；其可迁移链条是：Stage1 的算法和超参数必须冻结，避免把 selector 效果与模型选择交互混淆。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的算法和超参数必须冻结，避免把 selector 效果与模型选择交互混淆。 禁止外推：不能据此认为 pruning 对所有模型影响相同，也不能支持具体样本评分。
