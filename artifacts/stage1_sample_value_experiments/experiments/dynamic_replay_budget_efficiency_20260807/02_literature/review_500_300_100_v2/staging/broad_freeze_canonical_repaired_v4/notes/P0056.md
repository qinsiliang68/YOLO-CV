# P0056 - PADP: progressive and adaptive data pruning for efficient incremental learning

## 独立中文摘要

问题：静态 pruning 的固定比例和单次分数无法适应增量任务中不断变化的数据分布与模型状态。 方法：PADP 计算即时难度 IDS 与区间难度变化 VDS，经归一化和超参数加权后在多个 pruning 点逐步提高裁剪率，并设置每类 Top-K 保留门槛。 结论：CIFAR-100 和 Tiny-ImageNet 的多种增量框架中报告最多减少 52.9% 训练时间而保持或提高准确率；消融支持动态变化与类平衡组件。

## 批判性小综述

对该研究的证据边界判断：它正面支持动态状态，但最终分数含任意 alpha 加权，且递归裁剪会造成不可逆路径依赖；没有证明这两个指标对应 replay utility。 反向约束：不能由 pruning 成功推出 replay 成功，也不能把其线性裁剪比例或 alpha 作为 Stage1 科学常数。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ5,RQ6；其可迁移链条是：Stage1 可借鉴逐轮刷新、类保留和 difficulty-change 单独 arm，但不得照搬加权总分；所有被排除与重新进入状态都应留账。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴逐轮刷新、类保留和 difficulty-change 单独 arm，但不得照搬加权总分；所有被排除与重新进入状态都应留账。 禁止外推：不能由 pruning 成功推出 replay 成功，也不能把其线性裁剪比例或 alpha 作为 Stage1 科学常数。
