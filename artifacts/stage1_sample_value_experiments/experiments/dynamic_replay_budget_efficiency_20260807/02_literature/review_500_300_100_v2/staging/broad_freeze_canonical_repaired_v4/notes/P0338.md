# P0338 - Gradient Episodic Memory for Continual Learning

## 独立中文摘要

问题：连续任务更新会遗忘旧任务，需要约束当前梯度不伤害 episodic memory，同时允许正迁移。 方法：GEM 保存旧任务样本并将当前梯度投影到不增加旧任务损失的可行区域，同时定义遗忘和迁移指标。 结论：MNIST 与 CIFAR-100 连续学习实验报告相对当时方法的强表现。

## 批判性小综述

对该研究的证据边界判断：GEM 约束聚合旧任务损失，不选择同分布样本；memory 构成和计算成本与 Stage1 不同。 反向约束：不能由 GEM 投影保证样本级正效用，也不能把旧任务 memory 等同 defect guard。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ6,RQ7；其可迁移链条是：它为 A 的 harm constraint 提供清晰原理：normal replay 更新不得提高弱 defect 目标损失。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：它为 A 的 harm constraint 提供清晰原理：normal replay 更新不得提高弱 defect 目标损失。 禁止外推：不能由 GEM 投影保证样本级正效用，也不能把旧任务 memory 等同 defect guard。
