# P0436 - Focal Loss for Dense Object Detection

## 独立中文摘要

问题：论文针对密集检测中约十万容易负锚点主导梯度的问题，研究连续降权是否优于硬筛选。 方法：Focal Loss 用真实类概率的调制因子乘交叉熵，平滑降低易分类样本贡献，同时保留全部锚点参与训练。 结论：COCO 消融中合适聚焦参数明显优于交叉熵和多个 OHEM 配置，说明软权重可比硬丢弃更稳健。

## 批判性小综述

对该研究的证据边界判断：收益与极端前景背景不平衡、初始化和 RetinaNet 结构共同相关，焦点损失仍是困难度函数而非样本效用证明。 反向约束：不能推出最大 focal 权重样本就值得回流，也不能把检测 AP 改善直接换算成 FN95 安全前沿改善。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ6；其可迁移链条是：Stage1 可设置软概率 replay 或平滑权重对照，检验硬 Top-K 的不连续性是否导致跨 seed 反转。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可设置软概率 replay 或平滑权重对照，检验硬 Top-K 的不连续性是否导致跨 seed 反转。 禁止外推：不能推出最大 focal 权重样本就值得回流，也不能把检测 AP 改善直接换算成 FN95 安全前沿改善。
