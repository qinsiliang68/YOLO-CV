# P0223 - NLU on Data Diets: Dynamic Data Subset Selection for NLP Classification Tasks

## 独立中文摘要

问题：论文研究 NLP 微调时，EL2N 重要性应一次静态计算还是随训练周期动态刷新，以及计算节省能否保持精度。 方法：方法先在全数据 burn-in，再每个周期对全部样本计算 EL2N 的指数移动平均，保留最高分比例；比较全量、静态、单次、动态 EL2N 与逐周期动态随机删减。 结论：十个 NLP 数据集的五次不同 seed 运行显示动态 EL2N 常有较好时间精度折中，但动态随机意外强势，极端百分之九十删减时在两个数据集超过动态 EL2N。

## 批判性小综述

对该研究的证据边界判断：高 EL2N 尾部包含误标样本，且同一 ambiguous 样本在不同初始化下入选次数变化；研究是删减训练而非额外 replay。 反向约束：不能推出 EL2N 或其 EMA 会稳压随机，也不能把节省训练时间的结论当成 FN95 效用提升。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ5,RQ6,RQ8；其可迁移链条是：可迁移的是记录每轮入选次数、动态刷新与 random 对照，并把高变异、误标和训练阶段作为条件，而不是永久冻结一维难度排名。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可迁移的是记录每轮入选次数、动态刷新与 random 对照，并把高变异、误标和训练阶段作为条件，而不是永久冻结一维难度排名。 禁止外推：不能推出 EL2N 或其 EMA 会稳压随机，也不能把节省训练时间的结论当成 FN95 效用提升。
