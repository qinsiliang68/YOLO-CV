# P0098 - Influence Dynamics and Stagewise Data Attribution

## 独立中文摘要

问题：静态训练数据归因忽略神经网络分阶段学习，因而会把随模型状态改变的影响压成一个永久分数。 方法：论文以奇异学习理论构建阶段性归因框架，预测影响在发展转折点出现非单调变化、尖峰甚至符号翻转，并以 toy model 与语言模型验证。 结论：作者报告动态影响变化与语义层级逐步学习相对应，且大模型 token 影响变化对齐已知发展阶段。

## 批判性小综述

对该研究的证据边界判断：这是 Value(x|theta_t,stage) 的直接理论线索，但论文年份新、归因定义和真实干预一致性必须全文精读和复现。 反向约束：不能由理论和语言模型案例直接断言 Stage1 的 150 至 160 epoch 是相变点，也不能用静态平均掩盖翻转。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ7；其可迁移链条是：Stage1 应在固定 checkpoint 比较同一样本 A 的符号与幅度，并把跨 seed、跨阶段符号翻转作为主要统计对象。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应在固定 checkpoint 比较同一样本 A 的符号与幅度，并把跨 seed、跨阶段符号翻转作为主要统计对象。 禁止外推：不能由理论和语言模型案例直接断言 Stage1 的 150 至 160 epoch 是相变点，也不能用静态平均掩盖翻转。
