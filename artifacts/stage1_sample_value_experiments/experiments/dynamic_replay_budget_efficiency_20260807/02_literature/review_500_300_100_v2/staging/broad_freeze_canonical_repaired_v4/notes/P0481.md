# P0481 - Learning With Noisy Labels Over Imbalanced Subpopulations

## 独立中文摘要

问题：small-loss 假设在样本量或识别难度不均衡的子群上失效，会把困难或尾部但信息丰富的干净样本误当噪声。 方法：方法用特征相关性估计 clean probability 并修复标签，再用 distributionally robust optimization 抵抗子群不平衡。 结论：广泛合成和真实噪声基准上，作者报告在不平衡子群条件下持续改善稳健学习方法。

## 批判性小综述

对该研究的证据边界判断：标签修复、相关性和 DRO 联合变化；少数子群保护是平均泛化目标，不等于 FN95 的弱 defect 保护。 反向约束：不能把低频簇全部视为 clean valuable，也不能从噪声分类直接确定 defect guard 比例。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ5；其可迁移链条是：Stage1 的 Q 必须按来源/簇/类别分层校准，防止用全局 AUM 或 loss 门限删掉稀有有效模式。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 Q 必须按来源/簇/类别分层校准，防止用全局 AUM 或 loss 门限删掉稀有有效模式。 禁止外推：不能把低频簇全部视为 clean valuable，也不能从噪声分类直接确定 defect guard 比例。
