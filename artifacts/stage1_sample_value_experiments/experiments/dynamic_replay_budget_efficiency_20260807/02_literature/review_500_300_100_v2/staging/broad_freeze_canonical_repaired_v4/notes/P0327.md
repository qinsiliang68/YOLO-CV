# P0327 - DRIFT: Refining Instruction Data via On-Policy Data Attribution

## 独立中文摘要

问题：离线 influence 用外部验证目标时存在参数邻域差距，并容易被样本梯度范数支配，难预测提升最终模型上限的数据。 方法：DRIFT 用当前模型 on-policy rollout 作为验证锚，按轨迹正确性赋有符号权重，并对 gradient-norm hacking 去偏后归因全训练集。 结论：七十亿参数指令与推理模型实验报告持续超过既有数据策划基线并提高能力上限。

## 批判性小综述

对该研究的证据边界判断：on-policy 目标减少邻域差但可能形成自我确认；指令微调与二分类不同，2026 预印本的跨 seed 和外部复现需核验。 反向约束：不能把 DRIFT 分数直接称照片 utility，也不能由 LLM 平均基准提升推出 FN95 局部安全收益。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ7；其可迁移链条是：它直接支持 A 不能只看梯度大小，目标探针应贴近当前策略且带正负方向；Stage1 则必须使用独立 val_target 防泄漏。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：它直接支持 A 不能只看梯度大小，目标探针应贴近当前策略且带正负方向；Stage1 则必须使用独立 val_target 防泄漏。 禁止外推：不能把 DRIFT 分数直接称照片 utility，也不能由 LLM 平均基准提升推出 FN95 局部安全收益。
