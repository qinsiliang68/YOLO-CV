# P0433 - Batch and online learning algorithms for nonconvex neyman-pearson classification

## 独立中文摘要

问题：二分类任务可能要求直接限制 false negative rate，而非最大化无约束平均准确率。 方法：论文把 NP 分类写成带 FN 约束的非凸问题，分别提出 DC programming 批算法和适合大数据的随机梯度算法。 结论：实验显示两类方法具有处理 NP 约束分类的潜力。

## 批判性小综述

对该研究的证据边界判断：该工作优化分类器，不研究哪些训练样本值得 replay；约束估计的有限样本不确定性仍需另行处理。 反向约束：不能从 NP 优化算法推导 Q/R/A/D 选择规则，也不能用总体 AUC 替代固定约束比较。

## Stage1 直接相关链

该研究直接映射到 RQ8；其可迁移链条是：Stage1 主终点应保持 TN 最大化且 FN≤95 的显式可行域，并报告完整安全前沿。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 主终点应保持 TN 最大化且 FN≤95 的显式可行域，并报告完整安全前沿。 禁止外推：不能从 NP 优化算法推导 Q/R/A/D 选择规则，也不能用总体 AUC 替代固定约束比较。
