# P0032 - Identifying Noise in Human-Created Datasets using Training Dynamics from Generative Models

## 独立中文摘要

问题：自动编码模型上的噪声检测轨迹不能直接迁移到自回归模型，说明训练动态特征依赖模型族。 方法：TDRANKER 利用生成模型训练动态把样本由易到难排序，用于识别人造数据中的标签和文本噪声。 结论：作者报告跨 GPT-2、BERT、LaMini 等架构和噪声率较稳健，去噪至少快两倍并改善真实任务数据质量。

## 批判性小综述

对该研究的证据边界判断：它支持 Q 必须在当前模型族重新验证，hard-to-learn 可用于风险排序但不是 utility；随机删除对照需筛读。 反向约束：不能把高难排序直接判成噪声，也不能由数据质量提升推断 FN95 方向。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4；其可迁移链条是：Stage1 可用 YOLO OOF 轨迹训练 Q 分型器，不借用其他架构阈值，并把 filtered 与 unfiltered replay 配对。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可用 YOLO OOF 轨迹训练 Q 分型器，不借用其他架构阈值，并把 filtered 与 unfiltered replay 配对。 禁止外推：不能把高难排序直接判成噪声，也不能由数据质量提升推断 FN95 方向。
