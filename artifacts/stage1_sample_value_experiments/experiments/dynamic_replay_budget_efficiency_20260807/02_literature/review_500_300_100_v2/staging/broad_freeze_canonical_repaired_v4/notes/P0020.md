# P0020 - GLISTER: Generalization based Data Subset Selection for Efficient and Robust Learning

## 独立中文摘要

问题：论文把数据子集选择写成双层优化，使训练子集更新后能够直接提高独立验证集上的目标表现。 方法：GLISTER 用验证似然的一阶 Taylor 近似形成近似次模目标，周期刷新子集，并加入随机或 facility-location 正则。 结论：多个分类任务中该方法通常以较少数据接近全量训练，并在部分噪声和不平衡设置优于随机与已有 coreset。

## 批判性小综述

对该研究的证据边界判断：选择过程反复使用验证集，作者也讨论潜在验证过拟合；其目标是平均验证似然而非 Stage1 的局部安全前沿。 反向约束：不能将 GLISTER 的验证增益直接解释为照片固有价值，也不能让 val_op 或 test 参与 A 的构造。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：Stage1 可借鉴训练梯度与独立目标梯度的方向检验，并用覆盖正则抑制同方向重复，而非追求大梯度。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。
