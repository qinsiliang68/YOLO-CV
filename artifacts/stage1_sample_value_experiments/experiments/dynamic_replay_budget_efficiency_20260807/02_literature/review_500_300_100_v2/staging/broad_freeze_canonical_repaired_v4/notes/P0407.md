# P0407 - Rethinking the Value of Labels for Improving Class-Imbalanced Learning

## 独立中文摘要

问题：长尾标签既提供监督又造成多数类边界偏置，标签价值不是单向正面。 方法：论文理论和实验比较半监督利用不平衡标签与先自监督再训练的策略，分析 label bias。 结论：作者报告两类策略均可改善大规模不平衡识别，并强调标签并非始终有益。

## 批判性小综述

对该研究的证据边界判断：它支持类别标签、表示学习和采样效应分开，避免 normal 数量优势扭曲 Q/R；但没有直接 replay 选择。 反向约束：不能由 label bias 直接确定 guard 比例，也不能把自监督预训练收益称样本价值。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ7,RQ8；其可迁移链条是：Stage1 的 base 数据保持 1比1，normal replay 增加的类别曝光必须与 weak-defect 风险一起审计。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 base 数据保持 1比1，normal replay 增加的类别曝光必须与 weak-defect 风险一起审计。 禁止外推：不能由 label bias 直接确定 guard 比例，也不能把自监督预训练收益称样本价值。
