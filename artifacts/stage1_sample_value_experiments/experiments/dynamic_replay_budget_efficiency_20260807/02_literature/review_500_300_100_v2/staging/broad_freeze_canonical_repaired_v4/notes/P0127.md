# P0127 - Optimal Bandwidths Selection for Nonparametric Neyman-Pearson Classifiers

## 独立中文摘要

问题：高风险分类既要严格控制一类错误，又要调节核带宽获得另一类性能，普通整体风险调参不能保证有限样本约束。 方法：学位论文分别用渐近修正和留出样本顺序统计控制 Type-I error，再构造 NP 专用风险和 bootstrap 选择带宽。 结论：模拟显示方法能达到目标错误控制，bootstrap 带宽比非 NP 调参风险更低。

## 批判性小综述

对该研究的证据边界判断：它研究核分类器超参数而非数据 replay；Type-I 与 Stage1 FN 类别映射必须明确，渐近与有限样本保证不同。 反向约束：不能用 NP 带宽选择确定样本价值，也不能在同一 val_target 上构造方法又冻结阈值。

## Stage1 直接相关链

该研究直接映射到 RQ7,RQ8；其可迁移链条是：Stage1 应用独立 val_op 顺序统计冻结阈值，并将约束违反概率与效用分开报告。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应用独立 val_op 顺序统计冻结阈值，并将约束违反概率与效用分开报告。 禁止外推：不能用 NP 带宽选择确定样本价值，也不能在同一 val_target 上构造方法又冻结阈值。
