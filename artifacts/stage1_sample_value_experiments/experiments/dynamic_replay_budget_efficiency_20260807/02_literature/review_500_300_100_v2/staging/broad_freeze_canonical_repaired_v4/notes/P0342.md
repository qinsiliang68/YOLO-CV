# P0342 - Partial AUC Maximization via Nonlinear Scoring Functions

## 独立中文摘要

问题：类别先验偏斜的异常检测和诊断任务中，accuracy 不合适，线性 scoring 也限制直接优化局部 ROC。 方法：论文以生成模型和深网两类非线性 scoring function 直接最大化指定 ROC 区间的 pAUC。 结论：作者在 Subaru 望远镜真假目标二分类上报告非线性方法优于传统线性方法。

## 批判性小综述

对该研究的证据边界判断：它支持训练目标应聚焦业务 ROC 区域；普通单向 pAUC 与同时截取 weak-defect 和 dangerous-normal 的 two-way 局部目标不同。 反向约束：不能以 pAUC surrogate 值直接排序 replay 样本，也不能把模型训练目标与评价数据混用。

## Stage1 直接相关链

该研究直接映射到 RQ8；其可迁移链条是：Stage1 可把 FN95 邻域 pairwise loss 作为 A 的目标代理，并保留 raw frontier AUC 为最终干预指标。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 FN95 邻域 pairwise loss 作为 A 的目标代理，并保留 raw frontier AUC 为最终干预指标。 禁止外推：不能以 pAUC surrogate 值直接排序 replay 样本，也不能把模型训练目标与评价数据混用。
