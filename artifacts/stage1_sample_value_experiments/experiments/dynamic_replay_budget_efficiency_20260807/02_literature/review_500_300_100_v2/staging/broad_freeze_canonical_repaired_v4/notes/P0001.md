# P0001 - Competence-based Multimodal Curriculum Learning for Medical Report Generation

## 独立中文摘要

问题：论文研究医学报告生成中视觉和文本难度不同步时，怎样根据当前模型能力动态选择尚未学好的课程，而不是固定一个难度总分。 方法：作者构造四种视觉或文本难度排序，按 competence 函数逐步开放数据，并以各课程当前 perplexity 选择最未学好的课程继续训练。 结论：两个医学影像数据集和多个生成基线中，CMCL 在多数指标上改善；消融显示直接相加四个难度最差，动态选择通常优于随机或固定顺序路线。

## 批判性小综述

对该研究的证据边界判断：动态路线与样本难度、训练顺序同时改变，实验未报告独立 seed 和严格曝光匹配；任务是多模态生成而非二分类局部安全指标。 反向约束：不能据此认定 perplexity 最大的照片应回流，也不能把医学文本生成指标提升直接映射为 normal 与 defect 尾部同时改善。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ6,RQ8；其可迁移链条是：Stage1 可迁移按状态选择未学好的分层、避免任意相加困难度，并将路线随机、固定顺序和动态选择作为独立消融。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移按状态选择未学好的分层、避免任意相加困难度，并将路线随机、固定顺序和动态选择作为独立消融。 禁止外推：不能据此认定 perplexity 最大的照片应回流，也不能把医学文本生成指标提升直接映射为 normal 与 defect 尾部同时改善。
