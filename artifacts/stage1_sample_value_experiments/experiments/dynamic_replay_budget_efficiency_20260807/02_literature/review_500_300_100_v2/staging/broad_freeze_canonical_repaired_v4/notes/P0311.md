# P0311 - Reinforcement Learning-Based Path Generation Using Sequential Pattern Reduction and Self-Directed Curriculum Learning

## 独立中文摘要

问题：迁移学习中的固定课程不能随目标模型能力与训练阶段改变。 方法：方法由模型当前状态自行安排目标域样本的学习顺序，形成动态课程。 结论：作者报告相对固定课程或普通迁移训练的性能收益。

## 批判性小综述

对该研究的证据边界判断：任务是跨域迁移且课程目标不等于有限预算 replay；动态控制增加了策略自由度和选择偏倚风险。 反向约束：不能把迁移准确率收益直接等同于高召回尾部收益，也不能省略 matched random。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5,RQ6；其可迁移链条是：Stage1 可借鉴状态条件化与阶段刷新，但第一轮应冻结可证伪规则并保留 epoch lag。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴状态条件化与阶段刷新，但第一轮应冻结可证伪规则并保留 epoch lag。 禁止外推：不能把迁移准确率收益直接等同于高召回尾部收益，也不能省略 matched random。
