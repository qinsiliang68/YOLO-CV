# P0111 - SEED: Targeted Data Selection by Weighted Independent Set

## 独立中文摘要

问题：只按 target influence 取高分会选到彼此冗余样本，而全局相似阈值又会受不同域密度差异干扰。 方法：SEED 把训练样本作图节点，以跨 checkpoint trajectory influence 对目标集的作用作节点权重，以训练样本间正互影响作冲突边，再在互相显著的梯度子空间和局部密度尺度下近似求最大权独立集。 结论：指令、视觉指令和语义分割中，多预算下超过 random 与多种选择器；消融显示 influence、WIS、节点校准和边构造互补，最多节省约 2.5 倍 GPU 成本。

## 批判性小综述

对该研究的证据边界判断：2026 预印本且目标 influence 使用 max-over-target，可能放大单个异常目标；多个校准组件耦合，不能把结果归因于 alignment 或 diversity 单项。 反向约束：不能照搬其相似阈值、max 聚合或代理迁移结论，也不能用目标集同时选择方法和冻结工作阈值。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：Stage1 可把 A 定义为独立 val_target 尾部方向，把 D 定义为冲突图/局部密度覆盖，并分别做 A、A+D 和 anti-A 消融。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把 A 定义为独立 val_target 尾部方向，把 D 定义为冲突图/局部密度覆盖，并分别做 A、A+D 和 anti-A 消融。 禁止外推：不能照搬其相似阈值、max 聚合或代理迁移结论，也不能用目标集同时选择方法和冻结工作阈值。
