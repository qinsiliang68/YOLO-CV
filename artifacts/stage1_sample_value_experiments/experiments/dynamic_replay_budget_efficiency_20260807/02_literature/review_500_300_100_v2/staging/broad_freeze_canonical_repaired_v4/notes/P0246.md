# P0246 - Deep Self-Paced Learning for Semi-Supervised Person Re-Identification Using Multi-View Self-Paced Clustering

## 独立中文摘要

问题：半监督行人重识别中伪标签质量会随模型能力变化，一次性加入全部无标签样本会放大错误。 方法：方法以多异构 CNN 的多视角聚类生成伪标签，用 self-paced 正则先选少量可靠样本，模型增强后逐步纳入更多样本。 结论：作者在两个大规模 Re-ID 数据集上报告交替优化和逐步扩张优于比较方法。

## 批判性小综述

对该研究的证据边界判断：样本、伪标签和模型同时更新，收益不能只归因于课程；任务是半监督度量学习而非已标注 replay。 反向约束：不能把高伪标签置信度等同于可约损失，也不能直接迁移 Re-ID 的聚类阈值。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ5,RQ6；其可迁移链条是：Stage1 可借鉴 Q 门控加能力相关的逐步放宽，并记录每轮候选池、加入原因和错误放大风险。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴 Q 门控加能力相关的逐步放宽，并记录每轮候选池、加入原因和错误放大风险。 禁止外推：不能把高伪标签置信度等同于可约损失，也不能直接迁移 Re-ID 的聚类阈值。
