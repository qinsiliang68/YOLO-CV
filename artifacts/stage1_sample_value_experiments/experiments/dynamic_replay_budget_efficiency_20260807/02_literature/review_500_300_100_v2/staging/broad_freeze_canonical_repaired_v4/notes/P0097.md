# P0097 - Learn like a Pathologist: Curriculum Learning by Annotator Agreement for Histopathology Image Classification

## 独立中文摘要

问题：病理图像天然存在难度层次，多标注者分歧可提供独立于当前模型置信度的难度与可靠性线索。 方法：方法按标注者一致度把训练图像从容易到困难逐步加入课程，用同一分类任务比较普通训练和课程训练。 结论：作者在结直肠息肉分类中报告 AUC 从百分之八十三点七提高到百分之八十八点二。

## 批判性小综述

对该研究的证据边界判断：单数据集提升提示人工一致度有价值，但 AUC、标注者分歧与 Stage1 业务尾部不同，seed、预算和难度顺序消融必须筛读。 反向约束：不能由一个医学数据集的 AUC 提升证明难样本最终都应学习，也不能确定分歧来自噪声还是真实边界。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ6；其可迁移链条是：Stage1 若能获得人工复核或上下文一致标签，可建立独立 Q 分层，并检验课程时机而非把一致度塞入固定总分。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 若能获得人工复核或上下文一致标签，可建立独立 Q 分层，并检验课程时机而非把一致度塞入固定总分。 禁止外推：不能由一个医学数据集的 AUC 提升证明难样本最终都应学习，也不能确定分歧来自噪声还是真实边界。
