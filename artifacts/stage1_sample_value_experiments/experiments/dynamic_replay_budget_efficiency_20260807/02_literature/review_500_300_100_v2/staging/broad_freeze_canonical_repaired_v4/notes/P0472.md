# P0472 - Training Dynamics for Text Summarization Models

## 独立中文摘要

问题：生成模型微调中不同知识和错误在何时学会不清楚，平均终点指标掩盖早晚阶段差异。 方法：论文跨三套摘要数据跟踪复制、抽象性与 hallucination 动态，并分别尝试后期忽略高 loss 或已快速学会的低 loss token。 结论：发现复制倾向早学、事实幻觉较晚学；简单忽略不同 token 可调节事实性或抽象性目标。

## 批判性小综述

对该研究的证据边界判断：token 级干预与图像级 replay 不同，但直接证明同一 loss 在阶段和目标不同情况下含义相反。 反向约束：不能把高 loss token 应忽略推广为高 loss 图像无价值，也不能由生成事实性决定 FN95。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ6；其可迁移链条是：Stage1 应保存全 epoch 轨迹，并将 late high-loss、late low-loss 干预与目标方向分别验证。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应保存全 epoch 轨迹，并将 late high-loss、late low-loss 干预与目标方向分别验证。 禁止外推：不能把高 loss token 应忽略推广为高 loss 图像无价值，也不能由生成事实性决定 FN95。
