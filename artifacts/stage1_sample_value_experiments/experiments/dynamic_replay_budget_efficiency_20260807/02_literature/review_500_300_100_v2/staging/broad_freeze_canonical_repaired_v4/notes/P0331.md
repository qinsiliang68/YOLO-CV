# P0331 - Q-VGM: Q-Guided Value-Gradient Matching for Flow-Matching VLA Policies

## 独立中文摘要

问题：流匹配 VLA 策略难以稳定地把 critic 价值梯度穿过多步去噪过程，直接反传会数值不稳。 方法：Q-VGM 将 value gradient 转换成去噪时间的梯度场，在固定 replay buffer 上用 critic 指导策略更新。 结论：作者报告在模拟与真实机器人任务上显著提高成功率并优于同 backbone/critic 基线。

## 批判性小综述

对该研究的证据边界判断：这是 RL 策略更新而非训练样本选择；Q 值本身可有估计偏差，结果来自新损失而非 buffer ranking。 反向约束：不能把 critic value-gradient 当图像样本价值，也不能由同 buffer 更新结果推出选样胜随机。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ5,RQ7；其可迁移链条是：它支持 A 必须是目标价值方向而非梯度范数，但 Stage1 只应先采 head-gradient proxy 并做符号干预。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：它支持 A 必须是目标价值方向而非梯度范数，但 Stage1 只应先采 head-gradient proxy 并做符号干预。 禁止外推：不能把 critic value-gradient 当图像样本价值，也不能由同 buffer 更新结果推出选样胜随机。
