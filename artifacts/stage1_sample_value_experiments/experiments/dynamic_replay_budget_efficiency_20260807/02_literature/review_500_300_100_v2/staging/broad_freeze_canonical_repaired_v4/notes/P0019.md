# P0019 - Exploring Training Data Attribution under Limited Access Constraints

## 独立中文摘要

问题：梯度归因通常要求完整模型访问和高计算资源，实际训练管线往往只能使用 proxy 或冻结表征。 方法：论文系统比较不同模型访问和资源限制下的 TDA，并测试代理模型及未在目标数据上预训练的模型能否提供有信息的归因。 结论：作者报告即使模型未预先见过目标数据，其 attribution 在多种任务上仍有信息量，并给出部署建议。

## 批判性小综述

对该研究的证据边界判断：它支持最后一层或代理模型近似作为低成本候选，但 informative 不等于因果 utility，跨模型排序保真和符号需筛读。 反向约束：不能把 proxy attribution 当作全模型 influence，也不能因资源受限省略独立目标集或随机对照。

## Stage1 直接相关链

该研究直接映射到 RQ3,RQ7；其可迁移链条是：Stage1 可先在关键 checkpoint 和分层子集采 head-gradient proxy，并用真实 replay 校准其符号和稳定性。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可先在关键 checkpoint 和分层子集采 head-gradient proxy，并用真实 replay 校准其符号和稳定性。 禁止外推：不能把 proxy attribution 当作全模型 influence，也不能因资源受限省略独立目标集或随机对照。
