# P0009 - Open-set Label Noise Can Improve Robustness Against Inherent Label Noise

## 独立中文摘要

问题：通常把开放集错标一概视为有害，但其 SGD 扰动方向可能与干净模式不冲突并产生正则化。 方法：ODNL 主动加入开放集样本并动态赋予噪声标签，从 SGD noise 的方向、偏置和冲突分析其作用。 结论：作者报告开放集噪声可提升对固有标签噪声的鲁棒性并改善 OOD 检测。

## 批判性小综述

对该研究的证据边界判断：这是人为构造的动态噪声正则，不表示自然错标样本应被高倍率回流；收益依赖方向近似随机且不冲突。 反向约束：不能据此主张真实脏标签有价值，也不能把随机方向噪声与目标正对齐混为一谈。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ4；其可迁移链条是：Stage1 的 Q 门控不能把所有高 OOF loss 或 OOD 外观样本永久删除；应保留探索槽和被拒样本负对照。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 Q 门控不能把所有高 OOF loss 或 OOD 外观样本永久删除；应保留探索槽和被拒样本负对照。 禁止外推：不能据此主张真实脏标签有价值，也不能把随机方向噪声与目标正对齐混为一谈。
