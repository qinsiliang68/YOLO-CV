# P0168 - Using Deep Reinforcement Learning with Automatic Curriculum Learning for Mapless Navigation in Intralogistics

## 独立中文摘要

问题：仓库无地图导航存在稀疏成功样本、部分可观测和长训练周期，固定随机起点难以持续提供适合当前能力的任务。 方法：NavACL-Q 将自动课程学习与分布式 soft actor-critic 结合，动态调整起点或任务难度，并在不同仓库环境评估泛化。 结论：作者报告相对随机起点训练约百分之四十性能增益，预训练特征提取器另贡献约百分之六十。

## 批判性小综述

对该研究的证据边界判断：它给出 model-state-aware 课程对随机起点的干预证据，但课程单位是环境初始状态，且两个组件贡献不能混为样本 replay。 反向约束：不能从强化学习起点课程确定监督分类的样本分数、刷新频率或 replay cap。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6；其可迁移链条是：Stage1 可借鉴依据上一轮能力动态调整候选难度，并把随机探索作为显式对照与保底。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴依据上一轮能力动态调整候选难度，并把随机探索作为显式对照与保底。 禁止外推：不能从强化学习起点课程确定监督分类的样本分数、刷新频率或 replay cap。
