# P0473 - Bilingual Methods for Adaptive Training Data Selection for Machine Translation

## 独立中文摘要

问题：大规模双语语料混有与目标域无关或错配句对，NMT 对噪声比 SMT 更敏感，单语相似度筛选不足。 方法：Bi-SSCNN 用少量域内数据训练基于 bitoken 的半监督卷积选择器，利用双语对应信息给候选句对打分，再选子集训练翻译系统。 结论：中英、阿英和英法任务上超过三种数据选择方法，能更有效排除噪声句对；英法 NMT 报告超过 3 BLEU 提升。

## 批判性小综述

对该研究的证据边界判断：领域适配、噪声过滤和训练规模共同变化，且主要与其他 selector 比较而非严格 matched random；文本 bitoken 不可直接迁移。 反向约束：不能把域内相似度解释为剩余可学习性，也不能由 BLEU 提升推断视觉 replay utility。

## Stage1 直接相关链

该研究直接映射到 RQ4,RQ5,RQ7；其可迁移链条是：Stage1 可借鉴少量独立 target data 构造 Q/A 信号和双视角一致性，但必须避免让 val_op 同时参与方法构造与阈值冻结。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴少量独立 target data 构造 Q/A 信号和双视角一致性，但必须避免让 val_op 同时参与方法构造与阈值冻结。 禁止外推：不能把域内相似度解释为剩余可学习性，也不能由 BLEU 提升推断视觉 replay utility。
