# P0287 - SSR: An Efficient and Robust Framework for Learning with Unknown Label Noise

## 独立中文摘要

问题：论文研究噪声率未知时，如何动态区分干净样本和错误标签，避免固定 warm-up 或单次小损失筛选在不同噪声强度下失效。 方法：SSR 每轮依据邻域标签一致性并作类别平衡修正来选择干净样本，再用模型置信度重标记高可信噪声样本，并通过半监督与特征一致性利用剩余数据。 结论：多种合成和真实噪声实验显示动态选择与重标记优于多种噪声学习基线，干净样本选择的 F-score 在多数设置中较高且对阈值相对稳健。

## 批判性小综述

对该研究的证据边界判断：可靠性判断依赖表示邻域和标签一致性，性能增益同时包含重标记与半监督模块；它证明了门控的必要性，但没有测试被选样本作为额外 replay 是否优于随机。 反向约束：不能把 SSR 的 clean probability 当作 replay utility，也不能据此认定高置信重标记适用于未做人工复核的工业缺陷图像。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4；其可迁移链条是：Stage1 可迁移按类别和邻域一致性构造 Q 门控、记录每轮入池与移出原因，并把未通过门控者留作风险层而非直接删除。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移按类别和邻域一致性构造 Q 门控、记录每轮入池与移出原因，并把未通过门控者留作风险层而非直接删除。 禁止外推：不能把 SSR 的 clean probability 当作 replay utility，也不能据此认定高置信重标记适用于未做人工复核的工业缺陷图像。
