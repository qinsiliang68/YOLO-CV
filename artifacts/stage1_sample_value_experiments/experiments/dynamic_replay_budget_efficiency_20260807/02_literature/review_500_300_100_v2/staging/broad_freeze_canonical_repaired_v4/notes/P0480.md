# P0480 - Training Data Attribution via Approximate Unrolling

## 独立中文摘要

问题：端点 influence 或局部 Hessian 近似会忽略非收敛、多阶段训练和沿优化路径累积的样本作用。 方法：论文通过近似展开训练更新来估计训练数据归因，使影响沿多个优化步骤传播，而不是只在最终参数附近做局部近似。 结论：作者报告 approximate unrolling 在非收敛和多阶段设置中改善归因质量，并强调 checkpoint 路径与训练过程会改变样本影响估计。
