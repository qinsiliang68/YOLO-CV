# P0256 - Shapley Value-driven Data Pruning for Recommender Systems

## 独立中文摘要

问题：推荐交互看似噪声仍可能帮助训练，而看似干净也可能边际价值低，基于主观意图过滤会混淆可靠性与效用。 方法：SVV 实时近似 Shapley 值，以交互对降低训练损失的贡献做估值，再突出高值、弱化低值，并构造模拟噪声协议。 结论：作者在四个真实数据集报告准确率和鲁棒性优于去噪方法，并称可保留训练关键交互。

## 批判性小综述

对该研究的证据边界判断：它直接区分 Q 与 utility，但效用函数仍是训练 loss，实时 Shapley 近似与随机 seed 稳定性需筛读。 反向约束：不能把降低训练 loss 等同 FN95 改善，也不能把推荐交互 Shapley 直接用于图像。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ3,RQ4,RQ5；其可迁移链条是：Stage1 应把疑似噪声和正向干预价值做二维分型，避免把 Q 门控当最终排名。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 应把疑似噪声和正向干预价值做二维分型，避免把 Q 门控当最终排名。 禁止外推：不能把降低训练 loss 等同 FN95 改善，也不能把推荐交互 Shapley 直接用于图像。
