# P0389 - Self-Guided Curriculum Learning for Neural Machine Translation

## 独立中文摘要

问题：人工难度特征不一定反映 NMT 当前恢复训练例的能力，需要模型自身建立课程。 方法：方法以句级 BLEU 表示恢复程度，先让模型浏览语料，再据恢复度从易到难调度。 结论：作者在 WMT14 英德和 WMT17 中英任务报告持续改善翻译表现。

## 批判性小综述

对该研究的证据边界判断：它提供当前模型恢复度 proxy，但 BLEU 与 CE 相关且 browse 阶段已暴露全数据，预算公平性需筛读。 反向约束：不能把高恢复或低恢复直接叫剩余可学习性，也不能由翻译结果确定刷新频率。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6；其可迁移链条是：Stage1 可在 epoch1 不回流、从 epoch2 使用上一轮轨迹，避免同轮窥视和选择。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可在 epoch1 不回流、从 epoch2 使用上一轮轨迹，避免同轮窥视和选择。 禁止外推：不能把高恢复或低恢复直接叫剩余可学习性，也不能由翻译结果确定刷新频率。
