# P0075 - A Neyman-Pearson Approach to Statistical Learning

## 独立中文摘要

问题：论文建立从有限标注样本学习分类器时，一类错误受约束、另一类错误被优化的 Neyman-Pearson 学习框架。 方法：NP-ERM 在经验一类错误约束下最小化另一类错误，NP-SRM 再加入模型复杂度惩罚，并给出概率界与一致性。 结论：理论表明受约束错误和目标错误必须分别控制，有限样本下只能给高概率或期望保证，不能假装绝对约束。

## 批判性小综述

对该研究的证据边界判断：论文主要是理论和决策树实现，不涉及深网 replay、分位尾部训练或样本选择，类错误方向也需按业务重新映射。 反向约束：不能由 NP 理论得到具体候选样本，也不能用同一个阈值同时冒充 TN_at_FN95 与 FN_at_TN68253。

## Stage1 直接相关链

该研究直接映射到 RQ8；其可迁移链条是：Stage1 应把 FN 上限写成硬约束并独立优化 TN，用整数原始前沿和不确定性区间而非任意加权平均。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。
