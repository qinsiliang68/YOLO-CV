# P0274 - Accelerating Reinforcement Learning for Reaching Using Continuous Curriculum Learning

## 独立中文摘要

问题：固定训练要求日程可能不适合多目标机器人 reaching 的连续能力提升。 方法：PCCL 根据精度要求逐步调整任务难度，并比较不同连续衰减函数的课程日程。 结论：仿真和真实 UR5e 实验支持静态日程次优，合适衰减可更快达到更好表现。

## 批判性小综述

对该研究的证据边界判断：选择单位是任务要求而非样本，且 RL 交互数据随策略改变；时间表和数据分布不可完全分离。 反向约束：不能把某个 RL decay 函数直接迁移为 replay 衰减，也不能用速度替代终点安全性。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ6,RQ7；其可迁移链条是：Stage1 可借鉴连续而非阶梯 envelope，但必须冻结逐 epoch 公式和累计曝光。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴连续而非阶梯 envelope，但必须冻结逐 epoch 公式和累计曝光。 禁止外推：不能把某个 RL decay 函数直接迁移为 replay 衰减，也不能用速度替代终点安全性。
