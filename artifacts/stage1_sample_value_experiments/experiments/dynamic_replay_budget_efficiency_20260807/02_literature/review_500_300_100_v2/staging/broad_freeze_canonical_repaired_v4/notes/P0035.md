# P0035 - A CNN-Based Method of Vehicle Detection from Aerial Images Using Hard Example Mining

## 独立中文摘要

问题：稀疏航拍车辆训练数据中，均匀 SGD 可能把大部分计算花在低损失样本上。 方法：方法在每批 500 或 1000 个候选中按 loss 选 100 个训练，并消融正负样本比例。 结论：纽约航拍实验中 HEM 相对普通 SGD 的 F1 约提高 0.02。

## 批判性小综述

对该研究的证据边界判断：该工作证明 loss mining 在特定检测任务可有效，但样本选择发生在 batch 内且正负比例也是干预变量。 反向约束：不能把局部 F1 提升外推为 FN95 改善，也不能据此认为最高 loss 一定可学习。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ6,RQ7；其可迁移链条是：Stage1 可保留 current-loss arm 作为必要旧式基线，并严格匹配候选池和实际反向传播预算。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可保留 current-loss arm 作为必要旧式基线，并严格匹配候选池和实际反向传播预算。 禁止外推：不能把局部 F1 提升外推为 FN95 改善，也不能据此认为最高 loss 一定可学习。
