# P0443 - A Robust Pneumonia Classification Approach based on Self-Paced Learning

## 独立中文摘要

问题：论文研究少量有标签胸片条件下，能否按伪标签置信度分阶段把未标注样本加入训练，以改善肺炎分类。 方法：方法先在标签集训练模型，再对未标注池预测，按类别内置信度取前 5%、10%、20% 或全部样本加入并重新训练。 结论：论文报告中等比例优于全部加入，说明更多伪标签曝光不必然更好；但其最高结果来自把原 30% 测试划分当未标注训练数据后再评价。

## 批判性小综述

对该研究的证据边界判断：该数据角色设计构成明确泄漏，且没有同预算随机伪标签基线或多 seed，因此数值提升不能作为样本价值证据。 反向约束：不能引用其精度提升证明 self-paced 或高置信样本有效，也不能把泄漏结果用于 Stage1 方法优先级。
