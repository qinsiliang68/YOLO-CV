# P0218 - A Snapshot of Influence: A Local Data Attribution Framework for Online Reinforcement Learning

## 独立中文摘要

问题：在线 RL 中每条经验既更新策略又改变未来采样，固定数据集的静态归因假设失效。 方法：论文对近期 buffer 做 checkpoint-local attribution，以训练损失与动作或累计回报目标的梯度相似度衡量贡献，并迭代过滤经验。 结论：作者在控制、导航、运动和 RLHF 上报告 IIF 降低样本复杂度、加速训练并提高回报。

## 批判性小综述

对该研究的证据边界判断：它直接支持局部目标、阶段归因和干预闭环，但在线数据反馈会混入策略分布变化，监督 replay 更容易做严格对照。 反向约束：不能把 RL return gradient 直接映射 FN95，也不能由局部相似度称样本永久有价值。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ3,RQ6,RQ7；其可迁移链条是：Stage1 可在固定候选和 checkpoint 上算局部 A，并用下一阶段 replay 结果验证，而不跨阶段平均。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可在固定候选和 checkpoint 上算局部 A，并用下一阶段 replay 结果验证，而不跨阶段平均。 禁止外推：不能把 RL return gradient 直接映射 FN95，也不能由局部相似度称样本永久有价值。
