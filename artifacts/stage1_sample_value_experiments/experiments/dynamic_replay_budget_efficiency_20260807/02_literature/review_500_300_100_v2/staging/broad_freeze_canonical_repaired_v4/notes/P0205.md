# P0205 - Learning What Matters: Prioritized Concept Learning via Relative Error-driven Sample Selection

## 独立中文摘要

问题：大规模视觉语言指令微调昂贵，而最高误差样本可能过难、已经掌握样本又缺少边际收益。 方法：PROGRESS 跨阶段跟踪各技能相对误差与学习进展，优先选择尚未掌握、当前可学且改善最快的技能所对应样本，并维持概念多样性。 结论：作者报告在不同规模指令数据上以更少数据和监督优于比较基线，并具备跨架构及向大模型迁移能力。

## 批判性小综述

对该研究的证据边界判断：它最直接支持 Goldilocks 可学习区间和 progress 而非 hardness；技能级聚合、查询预算和随机基线细节必须进入深筛。 反向约束：不能把进展最快直接解释为 FN95 正方向，也不能把技能级结果当作单图永久价值。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ5,RQ6；其可迁移链条是：Stage1 的 R 可显式比较 current difficulty、OOF reference 与最近窗口改善率，并排除已学和持续不可学两端。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 R 可显式比较 current difficulty、OOF reference 与最近窗口改善率，并排除已学和持续不可学两端。 禁止外推：不能把进展最快直接解释为 FN95 正方向，也不能把技能级结果当作单图永久价值。
