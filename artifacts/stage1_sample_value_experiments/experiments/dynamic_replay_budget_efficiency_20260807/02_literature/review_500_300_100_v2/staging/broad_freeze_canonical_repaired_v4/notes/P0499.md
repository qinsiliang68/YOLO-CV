# P0499 - Tripartite: Tackle Noisy Labels by a More Precise Partition

## 独立中文摘要

问题：二分 clean/noisy 的 loss 门限无法处理 clean 与 noisy 中都可能出现的高损失 hard 样本。 方法：Tripartite 根据两网络预测不一致及预测与给定标签不一致，将数据分成 clean、hard、noisy；hard 低权训练，noisy 用不依赖原标签的自监督学习。 结论：五个合成和真实噪声基准上作者报告更准确分区并超过多数比较方法。

## 批判性小综述

对该研究的证据边界判断：三类分区依赖双网络和标签关系，低权与自监督同时改变训练；没有直接估计独立业务目标的 replay 边际效用。 反向约束：不能把 hard 类全部视为值得学，也不能由低权训练成功确定 replay repeat count。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4；其可迁移链条是：Stage1 的 Q 应输出分型而非二元删除，可为 hard-clean、疑似 noisy、persistent unlearnable 分别设干预臂。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 Q 应输出分型而非二元删除，可为 hard-clean、疑似 noisy、persistent unlearnable 分别设干预臂。 禁止外推：不能把 hard 类全部视为值得学，也不能由低权训练成功确定 replay repeat count。
