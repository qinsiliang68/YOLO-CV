# P0138 - Scheduled Dialog Policy Learning: An Automatic Curriculum Learning Framework for Task-oriented Dialog System

## 独立中文摘要

问题：对话用户复杂度差异大，随机交互可能使策略过早面对超出能力的会话。 方法：框架自动度量对话复杂度并从简单到复杂调度，同时优化 RL 对话策略。 结论：MultiWOZ 与订票数据上报告对话成功率准确性提高约 9.6% 和 10%。

## 批判性小综述

对该研究的证据边界判断：RL 用户环境随策略变化，复杂度度量和采样共同变化；并非固定图片池 replay。 反向约束：不能把对话复杂度公式迁移为图像难度，也不能省略随机同时间表对照。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ6,RQ7；其可迁移链条是：Stage1 可把状态依赖课程作为后续方向，但第一版需要确定性、滞后一轮和可审计 controller。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把状态依赖课程作为后续方向，但第一版需要确定性、滞后一轮和可审计 controller。 禁止外推：不能把对话复杂度公式迁移为图像难度，也不能省略随机同时间表对照。
