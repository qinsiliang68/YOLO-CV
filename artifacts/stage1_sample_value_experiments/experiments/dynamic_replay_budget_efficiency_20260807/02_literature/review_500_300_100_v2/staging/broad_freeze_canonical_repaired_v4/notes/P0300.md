# P0300 - Hard Example Mining-based Training Strategy for Pointly-Supervised Instance Segmentation

## 独立中文摘要

问题：点监督实例分割只有每目标少量标注点，对所有点无差别训练会浪费稀缺监督。 方法：方法集中训练挑战性标注点，以 hard-example mining 提高弱监督利用效率。 结论：作者报告在 COCO 上比普通训练策略显著提升。
