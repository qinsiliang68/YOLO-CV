# P0390 - DivideMix: Learning with Noisy Labels as Semi-Supervised Learning

## 独立中文摘要

问题：论文研究深网先学习干净模式再记忆噪声的现象，并尝试动态区分可信与不可信标注。 方法：每轮对逐样本归一化损失拟合双分量混合模型，两网络交叉划分 clean/noisy，再用标签修正与 MixMatch 联合训练。 结论：在多种合成噪声和真实噪声数据上，动态分割、双网络和半监督组件的组合显著提高噪声鲁棒性。

## 批判性小综述

对该研究的证据边界判断：低损失混合假设会受类别不平衡和困难干净样本影响，分割是概率门控而非标签真值，也未检验 replay 效用。 反向约束：不能由 DivideMix 推出低损失样本更有业务价值，也不能把其 clean 概率当成人工复核或因果价值标签。

## Stage1 直接相关链

该研究直接映射到 RQ4；其可迁移链条是：Stage1 的 Q 应保留多信号可靠性和不确定状态，候选被降权时记录原因，避免最高损失尾部被直接放大。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 的 Q 应保留多信号可靠性和不确定状态，候选被降权时记录原因，避免最高损失尾部被直接放大。 禁止外推：不能由 DivideMix 推出低损失样本更有业务价值，也不能把其 clean 概率当成人工复核或因果价值标签。
