# P0452 - Bridging Saliency Detection to Weakly Supervised Object Detection Based on Self-paced Curriculum Learning

## 独立中文摘要

问题：弱监督检测中，显著性模型可初始化单类别容易图，但多类别图存在高歧义，若直接混训会导致定位漂移。 方法：SPCL 先按任务先验从容易样本开始，再让模型按当前损失逐步纳入困难样本，并在 self-paced regularizer 中加入多样性项，防止候选集中到少量图像。 结论：在弱监督目标检测基准上，任务课程、自适应 pace 和 diversity 的组合优于对应基线；分析显示多样性项用于抑制选择漂移。

## 批判性小综述

对该研究的证据边界判断：难度定义依赖弱监督候选框和显著性，不等于图片分类可学习性；同时更新 detector 与选择集合，不能识别每个样本的独立效用。 反向约束：不能据此推出 easy-to-hard 顺序总是优于随机，也不能把低 current loss 视为值得额外 replay。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ5,RQ6；其可迁移链条是：Stage1 可迁移 warm-up、逐阶段纳入和集合多样性三个可拆消融，并明确观察确定性 Top-K 是否被近重复视频帧占满。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可迁移 warm-up、逐阶段纳入和集合多样性三个可拆消融，并明确观察确定性 Top-K 是否被近重复视频帧占满。 禁止外推：不能据此推出 easy-to-hard 顺序总是优于随机，也不能把低 current loss 视为值得额外 replay。
