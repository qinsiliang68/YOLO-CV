# P0393 - Cost-Sensitive Self-Paced Learning With Adaptive Regularization for Classification of Image Time Series

## 独立中文摘要

问题：遥感时序域迁移中样本错误代价不等且目标标签稀缺，错误传播会污染 self-paced 训练。 方法：CSSPL 先给不同错误类型设成本，再以 loss 驱动的自适应混合正则分配样本权重，偏向可靠样本。 结论：作者报告可形成可靠训练样本集合并提高时序图像分类准确率。

## 批判性小综述

对该研究的证据边界判断：它把成本约束、可靠性和阶段权重联合，但无法从摘要分离组件贡献，手工错误成本也不是样本价值。 反向约束：不能把 loss 权重直接设置成 FN 成本，也不能由域迁移结果确定 replay 的方向。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ4,RQ6；其可迁移链条是：Stage1 可用 FN 风险作为硬约束而非权重，并在可行集合中检验动态 Q/R 选择。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可用 FN 风险作为硬约束而非权重，并在可行集合中检验动态 Q/R 选择。 禁止外推：不能把 loss 权重直接设置成 FN 成本，也不能由域迁移结果确定 replay 的方向。
