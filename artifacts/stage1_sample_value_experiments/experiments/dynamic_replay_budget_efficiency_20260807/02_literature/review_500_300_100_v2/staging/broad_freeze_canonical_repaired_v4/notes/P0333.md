# P0333 - Robust Semi-Supervised Classification for Noisy Labels Based on Self-Paced Learning

## 独立中文摘要

问题：半监督学习既要利用大量无标签数据，又要避免少量错误标签通过流形正则传播并伤害分类器。 方法：方法把自步学习嵌入 manifold regularization，迭代选择较可靠的有标签样本，并用局部线性重构约束分类器在数据流形上的平滑性。 结论：作者报告替代优化所得显式多类分类器能抑制初始噪声标签影响，并在实验中优于比较方法。

## 批判性小综述

对该研究的证据边界判断：样本选择基于特定半监督流形目标，摘要来源不足以判断随机对照、seed 与选择时点；它不评估同一基础集上的额外 replay。 反向约束：不能由 self-paced 选择证明低 loss 样本有更高 FN95 utility，也不能推断高 loss 样本都应排除。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6；其可迁移链条是：可作为 Q 门控和课程时序联合的早期证据，但 Stage1 必须拆开可靠性、难度与曝光，不可照搬单一目标。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：可作为 Q 门控和课程时序联合的早期证据，但 Stage1 必须拆开可靠性、难度与曝光，不可照搬单一目标。 禁止外推：不能由 self-paced 选择证明低 loss 样本有更高 FN95 utility，也不能推断高 loss 样本都应排除。
