# P0076 - An End-to-End Curriculum Learning Approach for Autonomous Driving Scenarios

## 独立中文摘要

问题：端到端强化学习驾驶若直接面对完整复杂场景，奖励稀疏、梯度不稳且策略难以形成。 方法：方法把 CARLA 训练划成五个逐步增加难度的阶段，并结合 PPO、价值分解和保符号梯度归一化；同一 agent 与无课程版本比较。 结论：作者在多个 CARLA 城镇报告较一致的驾驶表现，课程 agent 在所列指标上优于标准训练，并给出定量和定性结果。

## 批判性小综述

对该研究的证据边界判断：这是场景级强化学习 curriculum，难度、奖励和可访问环境都随阶段改变；无法隔离样本顺序或额外曝光的作用。 反向约束：不能由驾驶课程推出 normal replay 的最佳 epoch，也不能把环境阶段当作逐样本可学习性。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ6；其可迁移链条是：Stage1 只可迁移分阶段逐步增加挑战和保持训练终点一致的实验思想，并把时间表与 selection identity 分开。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 只可迁移分阶段逐步增加挑战和保持训练终点一致的实验思想，并把时间表与 selection identity 分开。 禁止外推：不能由驾驶课程推出 normal replay 的最佳 epoch，也不能把环境阶段当作逐样本可学习性。
