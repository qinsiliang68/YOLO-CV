# P0392 - Unsupervised Fine-Tuning Data Selection for ASR Using Self-Supervised Speech Models

## 独立中文摘要

问题：论文研究固定十小时转写预算下，怎样从九百六十小时语音池选择微调子集并降低 WER 方差。 方法：作者比较预训练 loss 高低尾、PBPE 困惑度、时长、说话人和主题覆盖；每种规则生成八个随机子集并与纯随机十小时对照。 结论：单纯高 loss 或低 loss 与随机几乎持平，保证说话人、主题和词汇覆盖后 PBPE 才能在部分设置超过随机。

## 批判性小综述

对该研究的证据边界判断：各规则仍含随机抽样且按 dev-other 选最佳检查点，不能把差异完全归因于单一选样分数。 反向约束：不能把语音词汇困惑度直接迁移到图像，也不能声称 loss 高尾在任何任务都无用。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ4,RQ6；其可迁移链条是：强力支持 D：随机基线之所以难打败，可能是天然覆盖来源与内容；Stage1 必须报告视频和模式覆盖。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：强力支持 D：随机基线之所以难打败，可能是天然覆盖来源与内容；Stage1 必须报告视频和模式覆盖。 禁止外推：不能把语音词汇困惑度直接迁移到图像，也不能声称 loss 高尾在任何任务都无用。
