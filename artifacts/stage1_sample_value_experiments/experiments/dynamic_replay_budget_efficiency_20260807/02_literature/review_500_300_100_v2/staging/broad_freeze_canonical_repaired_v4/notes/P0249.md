# P0249 - Unlabeled data selection for active learning in image classification

## 独立中文摘要

问题：图像主动学习需要在小标签预算下估计样本训练价值，单一 acquisition function 可能不足。 方法：论文比较 similarity、prediction probability 和 competence-based 三种选择策略，在 CIFAR-10/100 上逐轮查询。 结论：作者报告所提方法优于随机和传统选择并减少所需训练数据。

## 批判性小综述

对该研究的证据边界判断：主动学习把标签信息增量与样本身份效应混在一起；需要核对多 seed、预算和 exact random protocol。 反向约束：不能从主动标注结果断言样本重复曝光有同样收益，也不能直接使用其预算。

## Stage1 直接相关链

该研究直接映射到 RQ2,RQ5,RQ7；其可迁移链条是：Stage1 可把相似度覆盖、概率和 competence 分成候选臂，但 replay 中标签已知，不能照搬 acquisition。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可把相似度覆盖、概率和 competence 分成候选臂，但 replay 中标签已知，不能照搬 acquisition。 禁止外推：不能从主动标注结果断言样本重复曝光有同样收益，也不能直接使用其预算。
