# P0214 - GRACE: A Dynamic Coreset Selection Framework for Large Language Model Optimization

## 独立中文摘要

问题：静态 coreset 不能跟随模型状态变化，频繁重算表示和梯度又难以扩展到大模型。 方法：GRACE 联合表示多样性与梯度重要性动态更新 coreset，并用 kNN 图传播和选择性刷新降低开销。 结论：作者在三个基准和多种 LLM 上报告训练效率与下游性能提升。

## 批判性小综述

对该研究的证据边界判断：这是与 Q/R/A/D 结构相近的新预印本，但目标、模型和预算定义不同，随机对照及 seed 稳定性必须精读。 反向约束：不能因联合梯度与多样性有效就直接接受固定权重，更不能省略各层独立消融。

## Stage1 直接相关链

该研究直接映射到 RQ1,RQ2,RQ3,RQ5,RQ6,RQ7；其可迁移链条是：Stage1 可借鉴分离 score、覆盖图和刷新策略，并只在预注册关键 epoch 更新而非每步全量重算。 最终 utility 仍须由固定累计曝光下的真实配对 replay 干预确认。

## 迁移边界

允许迁移：Stage1 可借鉴分离 score、覆盖图和刷新策略，并只在预注册关键 epoch 更新而非每步全量重算。 禁止外推：不能因联合梯度与多样性有效就直接接受固定权重，更不能省略各层独立消融。
